# 复试流程与分值结构

## 一、复试总体框架

### 1.1 复试组成

上海大学计算机工程与科学学院硕士研究生复试由三部分组成，**总分 300 分**：

| 组成部分 | 分值 | 占比 | 考核形式 | 时长 |
|---------|------|------|---------|------|
| **一、专业基础能力** | **150 分** | 50% | 上机编程测试（100 分）+ 编译原理笔试（50 分） | 机试 2-3 小时，笔试 1-2 小时 |
| **二、综合面试** | **100 分** | ~33% | 多对一面试 | 15-20 分钟 |
| **三、外语能力** | **50 分** | ~17% | 英语口语/听力测试 | 5-10 分钟 |
| **合计** | **300 分** | 100% | - | - |

### 1.2 及格规则

⚠️ **重要**：复试总分 **180 分以下为不及格**，不及格者**不予录取**。

| 判定 | 条件 | 结果 |
|------|------|------|
| ✅ 合格 | 复试总分 ≥ 180 分 | 参与总成绩排名，择优录取 |
| ❌ 不合格 | 复试总分 < 180 分 | **直接淘汰，不予录取** |

> 注意：部分年份可能对各单项设置最低分要求（如综合面试 60 分以下直接淘汰），以当年复试办法为准。

### 1.3 总成绩计算公式

$$\text{总成绩} = \frac{\text{初试总分}}{5} \times 50\% + \frac{\text{复试总分}}{3} \times 50\%$$

**公式解读**：

- 初试总分（500 分制）折合成 100 分制后，占总成绩的 **50%**
- 复试总分（300 分制）折合成 100 分制后，占总成绩的 **50%**
- 即：初试 **1 分** = 复试 **0.6 分**（初试权重更大，但复试占比不低）

**换算示例**：

| 考生 | 初试 | 复试 | 总成绩 |
|------|------|------|--------|
| A | 360 分 | 240 分 | 360/5×0.5 + 240/3×0.5 = 36 + 40 = **76 分** |
| B | 340 分 | 270 分 | 340/5×0.5 + 270/3×0.5 = 34 + 45 = **79 分** |

> 虽然 A 初试高 20 分，但 B 复试表现优秀（270 vs 240），总成绩反而更高。**复试逆袭完全可能！**

## 二、专业基础能力（150 分）

### 2.1 上机编程测试（100 分）

#### 基本信息

| 项目 | 说明 |
|------|------|
| **分值** | 100 分 |
| **编程语言** | **C++**（主要）/ C（可选，但不推荐） |
| **题目数量** | 通常 4-6 道编程大题（每题 15-25 分）|
| **考试时长** | 2.5 - 3 小时 |
| **判题方式** | OJ（Online Judge）在线评测系统 |
| **评分规则** | 根据通过的测试用例数量给分（部分得分制）|

#### 考试环境

- **操作系统**：Windows 或 Linux
- **IDE**：Dev-C++、Code::Blocks、Visual Studio Code、CLion 等（以实际通知为准）
- **编译器**：GCC / G++
- **提交方式**：在线提交代码，即时/延迟反馈评测结果

#### 题型分布

| 题型 | 出现频率 | 难度 | 备考优先级 |
|------|---------|------|-----------|
| **排序与查找** | ⭐⭐⭐⭐⭐ | 简单 | ⭐⭐⭐⭐⭐ |
| **字符串处理** | ⭐⭐⭐⭐⭐ | 简单-中等 | ⭐⭐⭐⭐⭐ |
| **模拟题** | ⭐⭐⭐⭐ | 简单-中等 | ⭐⭐⭐⭐ |
| **链表 / 栈 / 队列** | ⭐⭐⭐⭐ | 中等 | ⭐⭐⭐⭐ |
| **二叉树** | ⭐⭐⭐⭐ | 中等 | ⭐⭐⭐⭐ |
| **动态规划（DP）** | ⭐⭐⭐⭐ | 中等-困难 | ⭐⭐⭐⭐ |
| **图论** | ⭐⭐⭐ | 中等-困难 | ⭐⭐⭐⭐ |
| **数论 / 数学题** | ⭐⭐⭐ | 中等 | ⭐⭐⭐ |
| **贪心算法** | ⭐⭐⭐ | 中等 | ⭐⭐⭐ |

#### 备考建议

1. **语言基础**：熟练掌握 C++ 语法（STL 容器、输入输出、字符串处理）
2. **算法数据结构**：系统学习常见算法与数据结构
3. **刷题训练**：
   - LeetCode 前 200 题 + 高频题
   - 牛客网 OJ 专题训练
   - 本资料提供的历年真题精选
4. **限时训练**：模拟真实考试场景，在 3 小时内完成 4-6 道题
5. **错题回顾**：建立错题本，定期回顾易错点

### 2.2 编译原理笔试（50 分）

#### 基本信息

| 项目 | 说明 |
|------|------|
| **分值** | 50 分 |
| **考试时长** | 1 - 1.5 小时 |
| **考试形式** | 闭卷笔试 |
| **题型** | 选择题、填空题、简答题、综合题（DFA/NFA 构造、文法分析等）|

#### 考点分布

| 章节 | 内容 | 分值占比（估算）|
|------|------|----------------|
| 1. 编译概述 | 编译过程、编译程序结构 | ~10% |
| 2. 词法分析 | 正则表达式、DFA/NFA、Lex/Flex | ~20% |
| 3. 语法分析 | 上下文无关文法、LL(1)、LR(0)、SLR、LR(1)、LALR | ~30% |
| 4. 属性文法与语法制导翻译 | 综合属性、继承属性、S-属性、L-属性 | ~15% |
| 5. 中间代码生成 | 三地址码、四元式、抽象语法树 | ~15% |
| 6. 代码优化 | 基本块、数据流分析、常见优化技术 | ~5-10% |
| 7. 符号表与错误处理 | 符号表组织、错误检测与恢复 | ~5% |

#### 推荐教材

- 《编译原理》陈火旺、刘晋任等（国防工业出版社）- 经典教材
- 《编译原理（第 2 版）》Alfred V. Aho 等（机械工业出版社）- 龙书
- 《编译原理与实践》Kenneth C. Louden（机械工业出版社）- 实践导向

#### 备考建议

1. 重点掌握 DFA/NFA 构造、正规式转换
2. 熟练掌握 LL(1) 分析表构造、First/Follow 集合
3. 掌握 LR 分析方法（LR(0)、SLR、LR(1)）
4. 熟练进行三地址码生成
5. 多做历年真题和教材课后习题

## 三、综合面试（100 分）

### 3.1 基本信息

| 项目 | 说明 |
|------|------|
| **分值** | 100 分 |
| **形式** | 多对一面试（3-5 位老师 vs 1 位考生）|
| **时长** | 15-20 分钟 |
| **考察内容** | 专业知识、科研能力、综合素质 |

### 3.2 评分维度

| 维度 | 大致分值 | 考察要点 |
|------|---------|---------|
| 专业基础掌握 | ~30 分 | 本科核心课程知识掌握情况 |
| 编程与工程能力 | ~20 分 | 项目经验、编程水平、工具使用 |
| 科研潜力 | ~20 分 | 科研经历、对研究方向的理解 |
| 逻辑思维与表达 | ~15 分 | 回答问题的条理性与清晰度 |
| 综合素质 | ~15 分 | 仪表、态度、应变能力 |

### 3.3 常见面试问题类别

| 类别 | 典型问题示例 |
|------|------------|
| **本科专业问题** | 数据结构/操作系统/计网核心概念 |
| **项目经历** | 介绍你最熟悉的一个项目，你的角色和贡献 |
| **科研经历** | 是否有论文/竞赛/科研项目经历 |
| **研究兴趣** | 你对哪个研究方向感兴趣？为什么？ |
| **为什么报考上大** | 了解你的动机和信息获取 |
| **研究生规划** | 你的学习/研究/就业规划是什么？ |
| **时事热点** | 对 AI/大模型/云计算等热点的看法 |

### 3.4 面试准备建议

1. **简历准备**：准备 1-2 页中文简历，突出项目/科研/竞赛经历
2. **自我介绍**：准备 1-2 分钟的中文自我介绍
3. **本科课程回顾**：复习数据结构、操作系统、计算机网络、数据库等核心课程
4. **项目梳理**：对简历中每个项目进行深入了解，准备好细节
5. **研究方向了解**：了解上大计算机学院各位导师的研究方向
6. **模拟面试**：找同学或老师进行模拟面试，练习表达和应变

## 四、外语能力（50 分）

### 4.1 基本信息

| 项目 | 说明 |
|------|------|
| **分值** | 50 分 |
| **形式** | 英语口试（可能含听力）|
| **时长** | 5-10 分钟 |
| **语言** | 英语 |

### 4.2 考试形式

| 形式 | 说明 | 出现概率 |
|------|------|---------|
| 自我介绍 | 2-3 分钟英文自我介绍 | ⭐⭐⭐⭐⭐ |
| 问答对话 | 老师用英语提问，考生用英语回答 | ⭐⭐⭐⭐⭐ |
| 朗读 + 翻译 | 朗读英文段落并翻译（或口译）| ⭐⭐⭐⭐ |
| 话题讨论 | 就某一话题进行讨论 | ⭐⭐⭐ |
| 听力测试 | 听力选择题/简答题 | ⭐⭐⭐ |

### 4.3 常见英语问答话题

| 话题 | 典型问题 |
|------|---------|
| 自我介绍 | "Please introduce yourself briefly." |
| 本科学习 | "Tell me about your undergraduate studies." |
| 家乡/家庭 | "Where are you from? Tell me about your hometown." |
| 兴趣爱好 | "What are your hobbies?" |
| 为什么选择上大 | "Why did you choose Shanghai University?" |
| 研究兴趣 | "What research areas are you interested in?" |
| 项目经历 | "Please describe one of your projects." |
| 未来规划 | "What are your plans for graduate study and beyond?" |
| 专业相关 | "What do you know about artificial intelligence?" |
| 日常问题 | "What's your favorite programming language and why?" |

### 4.4 备考建议

1. 准备一份 2-3 分钟的英文自我介绍，背诵熟练
2. 准备 15-20 个常见问题的英文回答
3. 练习发音和流利度，不求语法完美但要能表达
4. 熟悉本专业基本术语的英文表达
5. 如时间允许，每日进行 15-30 分钟英语口语练习

## 八、录取原则

1. **差额复试**：通常按 1:1.2 - 1:1.5 的比例确定复试名单
2. **总成绩排名**：按总成绩（初试 50% + 复试 50%）从高到低排序
3. **复试及格线**：复试总分 < 180 分直接淘汰
4. **择优录取**：在合格考生中按总成绩排名录取
5. **调剂说明**：院内/校内调剂根据当年情况，名额有限

---

## 九、逆袭案例

**案例 A**：初试 345 分（专硕，排名靠后）→ 复试 275 分 → 总成绩 78 分 → 录取

**案例 B**：初试 320 分（学硕，刚好进复试）→ 复试 280 分 → 总成绩 78.7 分 → 录取

**启示**：
- 初试高分不保险，复试仍需认真准备
- 初试低分不代表没机会，**复试可大幅逆袭**
- 机试和编译原理笔试是拉开差距的关键，务必重视
