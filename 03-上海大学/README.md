# 上海大学计算机考研复试资料总览

## 一、学校简介

**上海大学**（Shanghai University，简称上大、SHU）是上海市属综合性研究型大学，由上海市人民政府与教育部、国防科工局共建，是**国家"211工程"重点建设高校**、**国家"双一流"建设高校**（世界一流学科建设）。

### 基本信息

- **学校代码**：10280
- **建校时间**：1983 年（原上海工业大学、上海科学技术大学等合并组建）
- **办学层次**：本科、硕士、博士
- **校区分布**：宝山校区（主校区，计算机学院所在地）、延长校区、嘉定校区
- **办学定位**：**上海市属旗舰大学**，上海唯一市属 211 高校

### 综合实力

- **QS 亚洲大学排名**：中国内地前 40
- **校友会/软科排名**：全国前 50
- **ESI 前 1% 学科**：工程学、化学、材料科学、数学、物理学、临床医学、环境科学与生态学、社会科学总论、计算机科学等

### 计算机学科评估

| 学科 | 评估等级 | 说明 |
|------|---------|------|
| 计算机科学与技术（0812） | **B** | 全国前 20%~30% |
| 软件工程（0835） | **B-** | 全国前 30%~40% |

## 二、计算机工程与科学学院介绍

### 学院概况

**上海大学计算机工程与科学学院**（School of Computer Engineering and Science, SCES）成立于 1988 年，是国内最早成立的计算机学院之一。学院位于宝山校区（校本部），拥有完整的本科-硕士-博士培养体系。

### 学科设置

| 学科层次 | 学位点 |
|---------|--------|
| **博士点** | 计算机科学与技术（一级学科博士点） |
| **博士后流动站** | 计算机科学与技术 |
| **学术型硕士** | 计算机科学与技术（081200） |
| **专业型硕士** | 电子信息（085400，含软件工程等方向） |

### 研究方向

- **人工智能与机器学习**
- **计算机视觉与图像处理**
- **大数据与云计算**
- **计算机网络与信息安全**
- **软件工程与系统软件**
- **物联网与嵌入式系统**

### 师资力量

- 专职教师 **150+ 人**
- 国家级人才 **10+ 人**（长江学者、国家杰出青年基金获得者等）
- 省部级人才 **30+ 人**
- 院士（双聘/兼职）若干

## 三、学制、学费与奖学金

### 学制

| 类型 | 学制 | 备注 |
|------|------|------|
| 学术型硕士（学硕） | **2.5 年** | 即通常 3 个完整学年，次年 3 月毕业 |
| 专业型硕士（专硕） | **2.5 年** | 电子信息-软件工程等方向 |

> **重要说明**：2.5 年制意味着入学后第 3 年 3 月毕业，实际上大多数时间相当于 3 年制（课程学习+论文写作）。

### 学费

| 类型 | 专业 | 学费标准 |
|------|------|---------|
| 学硕 | 计算机科学与技术（081200） | **8000 元/年** |
| 专硕 | 电子信息-软件工程方向 | **15000 元/年** |
| 专硕 | 其他电子信息方向（部分） | **15000 元/年** |

### 奖助学金体系

| 奖助类别 | 金额/比例 | 说明 |
|---------|----------|------|
| **国家助学金** | 6000 元/年 | 全日制硕士生（有工资收入者除外）全覆盖 |
| **学业奖学金** | 一等 12000 元/年（比例约 15%）<br>二等 8000 元/年（比例约 30%）<br>三等 5000 元/年（比例约 55%） | 按年级综合评定，覆盖率约 **100%**（新生按入学成绩评定） |
| **国家奖学金** | 20000 元/年 | 全校竞争，比例约 2% |
| **"三助"岗位津贴** | 助教/助研/助管，300-800 元/月 | 按岗位情况发放 |
| **社会/企业奖学金** | 多种，金额不等 | 宝钢奖学金、校长奖学金等 |

> **注意**：具体奖助政策以当年研究生院公告为准，以上为参考值。
