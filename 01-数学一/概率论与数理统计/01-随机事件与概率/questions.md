### 题 1

**题干**：对于任意两事件 $A$ 和 $B$，与 $A \cup B = B$ 不等价的是

**选项**：
(A) $A \subset B$
(B) $\bar{B} \subset \bar{A}$
(C) $A \bar{B} = \varnothing$
(D) $\bar{A} B = \varnothing$

**标准答案**：$\boxed{D}$

**答案解析**：

$A \cup B = B \iff A \subset B$

(A) 等价

(B) $\bar{B} \subset \bar{A} \iff A \subset B$，等价

(C) $A \bar{B} = \varnothing \iff A$ 与 $\bar{B}$ 不交 $\iff A \subset B$，等价

(D) $\bar{A} B = \varnothing \iff B \subset A$，不等价

**出处**：事件关系基础

### 题 2

**题干**：设 $A, B$ 为两个随机事件，且 $P(B) > 0$，则下列选项必成立的是

**选项**：
(A) $P(A) < P(A|B)$
(B) $P(A) > P(A|B)$
(C) $P(A) = P(A|B)$
(D) 以上三者未必成立

**标准答案**：$\boxed{D}$

**答案解析**：

$P(A|B) = \dfrac{P(AB)}{P(B)}$

$P(A)$ 与 $P(A|B)$ 的关系取决于 $A, B$ 的独立性：

- 若 $A, B$ 独立，$P(A|B) = P(A)$
- 若 $B \subset A$，则 $P(AB) = P(B)$，$P(A|B) = 1 \ge P(A)$
- 若 $A, B$ 互斥，$P(AB) = 0$，$P(A|B) = 0 \le P(A)$

故三者都可能成立

**出处**：条件概率性质

### 题 3

**题干**：将一枚硬币独立掷两次，引进事件：$A_1 = \{$掷第一次出现正面$\}$，$A_2 = \{$掷第二次出现正面$\}$，$A_3 = \{$正反面各出现一次$\}$，$A_4 = \{$正面出现两次$\}$，则事件

**选项**：
(A) $A_1, A_2, A_3$ 相互独立
(B) $A_2, A_3, A_4$ 相互独立
(C) $A_1, A_2, A_3$ 两两独立
(D) $A_2, A_3, A_4$ 两两独立

**标准答案**：$\boxed{C}$

**答案解析**：

样本空间：$HH, HT, TH, TT$，各概率 $1/4$

$A_1 = \{HH, HT\}, P(A_1) = 1/2$

$A_2 = \{HH, TH\}, P(A_2) = 1/2$

$A_3 = \{HT, TH\}, P(A_3) = 1/2$

$A_4 = \{HH\}, P(A_4) = 1/4$

两两验证：

$P(A_1 A_2) = P(HH) = 1/4 = P(A_1)P(A_2)$

$P(A_1 A_3) = P(HT) = 1/4 = P(A_1)P(A_3)$

$P(A_2 A_3) = P(TH) = 1/4 = P(A_2)P(A_3)$

故 $A_1, A_2, A_3$ 两两独立

但 $P(A_1 A_2 A_3) = P(\varnothing) = 0 \neq P(A_1)P(A_2)P(A_3) = 1/8$，不相互独立

$A_2 A_4 = \{HH\}, P(A_2 A_4) = 1/4 \neq P(A_2)P(A_4) = 1/8$，故 $A_2, A_4$ 不独立

选 (C)。

**出处**：事件独立性

### 题 4

**题干**：设事件 $A$ 与事件 $B$ 互不相容，则

**选项**：
(A) $P(\bar{A} \bar{B}) = 0$
(B) $P(AB) = P(A)P(B)$
(C) $P(A) = 1 - P(B)$
(D) $P(\bar{A} \cup \bar{B}) = 1$

**标准答案**：$\boxed{D}$

**答案解析**：

$A, B$ 互不相容即 $AB = \varnothing$

(A) $\bar{A} \bar{B} = \overline{A \cup B}$，不一定为空

(B) $P(AB) = 0$，仅当 $P(A)=0$ 或 $P(B)=0$ 时等于 $P(A)P(B)$，一般不成立

(C) 不成立

(D) $\bar{A} \cup \bar{B} = \overline{AB} = \bar{\varnothing} = \Omega$，故 $P(\bar{A} \cup \bar{B}) = 1$

**出处**：互不相容事件

### 题 5

**题干**：设 $A, B, C$ 三个事件两两独立，则 $A, B, C$ 相互独立的充分必要条件是

**选项**：
(A) $A$ 与 $BC$ 独立
(B) $AB$ 与 $A \cup C$ 独立
(C) $AB$ 与 $AC$ 独立
(D) $A \cup B$ 与 $A \cup C$ 独立

**标准答案**：$\boxed{A}$

**答案解析**：

两两独立需验证 $P(ABC) = P(A)P(B)P(C)$

(A) $A$ 与 $BC$ 独立：$P(A \cdot BC) = P(A)P(BC) = P(A)P(B)P(C)$（因 $B, C$ 独立），即 $P(ABC) = P(A)P(B)P(C)$，故相互独立

反之，若相互独立，则 $P(ABC) = P(A)P(B)P(C) = P(A)P(BC)$，即 $A$ 与 $BC$ 独立

(B)(C)(D) 均不保证

**出处**：事件独立性推广

### 题 6

**题干**：已知 $0 < P(B) < 1$，且 $P[(A_1 + A_2)|B] = P(A_1|B) + P(A_2|B)$，则

**选项**：
(A) $P[(A_1 + A_2)|\bar{B}] = P(A_1|\bar{B}) + P(A_2|\bar{B})$
(B) $P(A_1 B + A_2 B) = P(A_1 B) + P(A_2 B)$
(C) $P(A_1 + A_2) = P(A_1|B) + P(A_2|B)$
(D) $P(B) = P(A_1)P(B|A_1) + P(A_2)P(B|A_2)$

**标准答案**：$\boxed{B}$

**答案解析**：

条件 $P[(A_1 + A_2)|B] = P(A_1|B) + P(A_2|B)$

即 $\dfrac{P(A_1 B + A_2 B)}{P(B)} = \dfrac{P(A_1 B)}{P(B)} + \dfrac{P(A_2 B)}{P(B)}$

故 $P(A_1 B + A_2 B) = P(A_1 B) + P(A_2 B)$，即 $A_1 B$ 与 $A_2 B$ 互斥

即 (B) 成立

(A) 不保证（对 $\bar{B}$ 无此条件）

(C) 不成立

(D) 不成立（全概率公式要求 $A_1, A_2$ 为划分）

**出处**：条件概率的可加性

### 题 7

**题干**：袋中有 50 个乒乓球，其中 20 个黄球，30 个白球，今有两人依次随机地从袋中各取一球，取后不放回，则第二个人取得黄球的概率是 \_\_\_\_\_\_

**标准答案**：$\boxed{\dfrac{2}{5}}$

**答案解析**：

由抽签原则（对称性），每个人取得黄球概率相同，为 $\dfrac{20}{50} = \dfrac{2}{5}$

或用全概率公式：$P($第二人黄$) = P($第一人黄$) P($第二人黄|第一人黄$) + P($第一人白$) P($第二人黄|第一人白$)$

$= \dfrac{20}{50} \cdot \dfrac{19}{49} + \dfrac{30}{50} \cdot \dfrac{20}{49} = \dfrac{380 + 600}{50 \cdot 49} = \dfrac{980}{2450} = \dfrac{2}{5}$

**出处**：抽签问题

### 题 8

**题干**：设两两相互独立的三事件 $A, B, C$ 满足条件：$ABC = \varnothing$，$P(A) = P(B) = P(C) < \dfrac{1}{2}$，且已知 $P(A \cup B \cup C) = \dfrac{9}{16}$，则 $P(A) = $ \_\_\_\_\_\_

**标准答案**：$\boxed{\dfrac{1}{4}}$

**答案解析**：

设 $P(A) = P(B) = P(C) = p$

$P(A \cup B \cup C) = P(A) + P(B) + P(C) - P(AB) - P(AC) - P(BC) + P(ABC)$

$= 3p - 3p^2 + 0 = 3p(1-p) = 9/16$

$p(1-p) = 3/16$

$p^2 - p + 3/16 = 0$

$p = \dfrac{1 \pm \sqrt{1 - 3/4}}{2} = \dfrac{1 \pm 1/2}{2}$

$p = 3/4$ 或 $p = 1/4$

由 $p < 1/2$，取 $p = 1/4$

**出处**：事件概率计算

### 题 9

**题干**：设工厂 A 和工厂 B 的产品的次品率分别为 1% 和 2%，现从由 A 和 B 的产品分别占 60% 和 40% 的一批产品中随机抽取一件，发现是次品，则该次品属 A 生产的概率是 \_\_\_\_\_\_

**标准答案**：$\boxed{\dfrac{3}{7}}$

**答案解析**：

设 $A = \{$来自厂 A$\}$，$B = \{$来自厂 B$\}$，$D = \{$次品$\}$

$P(A) = 0.6, P(B) = 0.4$

$P(D|A) = 0.01, P(D|B) = 0.02$

$P(D) = P(D|A)P(A) + P(D|B)P(B) = 0.006 + 0.008 = 0.014$

$P(A|D) = \dfrac{P(D|A)P(A)}{P(D)} = \dfrac{0.006}{0.014} = \dfrac{3}{7}$

**出处**：贝叶斯公式

### 题 10

**题干**：在区间 $(0, 1)$ 中随机地取两个数，则这两个数之差的绝对值小于 $1/2$ 的概率为 \_\_\_\_\_\_

**标准答案**：$\boxed{\dfrac{3}{4}}$

**答案解析**：

设两数为 $X, Y$，均服从 $U(0, 1)$ 独立

$P(|X - Y| < 1/2)$

几何概率：单位正方形中满足 $|x - y| < 1/2$ 的区域面积

两三角形面积之和 = $2 \cdot \dfrac{1}{2} \cdot \dfrac{1}{2} \cdot \dfrac{1}{2} = \dfrac{1}{4}$

故 $P(|X - Y| < 1/2) = 1 - 1/4 = 3/4$

**出处**：几何概率

### 题 11

**题干**：已知 $P(A) = P(B) = P(C) = 1/4$，$P(AB) = 0$，$P(AC) = P(BC) = 1/6$，则事件 $A, B, C$ 全不发生的概率为 \_\_\_\_\_\_

**标准答案**：$\boxed{\dfrac{7}{12}}$

**答案解析**：

$P(\bar{A} \bar{B} \bar{C}) = 1 - P(A \cup B \cup C)$

$P(A \cup B \cup C) = P(A) + P(B) + P(C) - P(AB) - P(AC) - P(BC) + P(ABC)$

由 $P(AB) = 0$，故 $P(ABC) \le P(AB) = 0$

$P(A \cup B \cup C) = 3 \cdot 1/4 - 0 - 2 \cdot 1/6 + 0 = 3/4 - 1/3 = 5/12$

$P(\bar{A} \bar{B} \bar{C}) = 1 - 5/12 = 7/12$

**出处**：全概率与对偶律

### 题 12

**题干**：设 $X$ 和 $Y$ 为两个随机变量，且 $P\{X \ge 0, Y \ge 0\} = 3/7$，$P\{X \ge 0\} = P\{Y \ge 0\} = 4/7$，则 $P\{\max(X, Y) \ge 0\} = $ \_\_\_\_\_\_

**标准答案**：$\boxed{\dfrac{5}{7}}$

**答案解析**：

$P\{\max(X, Y) \ge 0\} = P\{X \ge 0 \text{ 或 } Y \ge 0\} = P\{X \ge 0\} + P\{Y \ge 0\} - P\{X \ge 0, Y \ge 0\}$

$= 4/7 + 4/7 - 3/7 = 5/7$

**出处**：最大值事件
