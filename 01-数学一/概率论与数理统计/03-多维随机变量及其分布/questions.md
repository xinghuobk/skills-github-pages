# 多维随机变量及其分布 — 题库

## 一、单项选择题

### 题 1

**题干**：设两个随机变量 $X$ 与 $Y$ 相互独立且同分布：$P\{X = -1\} = P\{Y = -1\} = 1/2$，$P\{X = 1\} = P\{Y = 1\} = 1/2$，则下列各式中成立的是

**选项**：
(A) $P\{X = Y\} = 1/2$
(B) $P\{X = Y\} = 1$
(C) $P\{X + Y = 0\} = 1/4$
(D) $P\{XY = 1\} = 1/4$

**标准答案**：$\boxed{A}$

**答案解析**：

$P(X = Y) = P(X = -1, Y = -1) + P(X = 1, Y = 1) = P(X = -1)P(Y = -1) + P(X = 1)P(Y = 1)$

$= 1/2 \cdot 1/2 + 1/2 \cdot 1/2 = 1/4 + 1/4 = 1/2$

**出处**：独立随机变量联合分布

### 题 2

**题干**：设随机变量 $X_i$ 满足 $X_i \sim \begin{pmatrix} -1 & 0 & 1 \\ 1/4 & 1/2 & 1/4 \end{pmatrix}$（$i = 1, 2$），且 $P\{X_1 X_2 = 0\} = 1$，则 $P\{X_1 = X_2\} = $

**选项**：
(A) 0
(B) 1/4
(C) 1/2
(D) 1

**标准答案**：$\boxed{A}$

**答案解析**：

由 $P(X_1 X_2 = 0) = 1$，即 $X_1 X_2 \neq 0$ 的概率为 0

故 $P(X_1 = -1, X_2 = -1) = P(X_1 = -1, X_2 = 1) = P(X_1 = 1, X_2 = -1) = P(X_1 = 1, X_2 = 1) = 0$

由边缘分布 $P(X_1 = -1) = 1/4 = P(X_1 = -1, X_2 = -1) + P(X_1 = -1, X_2 = 0) + P(X_1 = -1, X_2 = 1) = P(X_1 = -1, X_2 = 0)$

同理 $P(X_1 = 1) = 1/4 = P(X_1 = 1, X_2 = 0)$

$P(X_2 = -1) = 1/4 = P(X_1 = 0, X_2 = -1)$

$P(X_2 = 1) = 1/4 = P(X_1 = 0, X_2 = 1)$

$P(X_1 = 0) = 1/2 = P(X_1 = 0, X_2 = -1) + P(X_1 = 0, X_2 = 0) + P(X_1 = 0, X_2 = 1) = 1/4 + P(X_1 = 0, X_2 = 0) + 1/4$

故 $P(X_1 = 0, X_2 = 0) = 0$

$P(X_1 = X_2) = P(X_1 = -1, X_2 = -1) + P(X_1 = 0, X_2 = 0) + P(X_1 = 1, X_2 = 1) = 0 + 0 + 0 = 0$

**出处**：联合分布确定

### 题 3

**题干**：设随机变量 $X$ 与 $Y$ 相互独立，其概率分布为

$X \sim \begin{pmatrix} 0 & 1 \\ 1/2 & 1/2 \end{pmatrix}$，$Y \sim \begin{pmatrix} 0 & 1 \\ 1/2 & 1/2 \end{pmatrix}$

则必有

**选项**：
(A) $X = Y$
(B) $P\{X = Y\} = 0$
(C) $P\{X = Y\} = 1/2$
(D) $P\{X = Y\} = 1$

**标准答案**：$\boxed{C}$

**答案解析**：

$P(X = Y) = P(X = 0, Y = 0) + P(X = 1, Y = 1) = P(X = 0)P(Y = 0) + P(X = 1)P(Y = 1) = 1/4 + 1/4 = 1/2$

**出处**：独立同分布随机变量相等概率

### 题 4

**题干**：设 $(X, Y)$ 服从二维正态分布，则随机变量 $U = X + Y$ 与 $V = X - Y$ 不相关的充分必要条件为

**选项**：
(A) $E(X) = E(Y)$
(B) $E(X^2) - [E(X)]^2 = E(Y^2) - [E(Y)]^2$
(C) $E(X^2) = E(Y^2)$
(D) $E(X^2) + [E(X)]^2 = E(Y^2) + [E(Y)]^2$

**标准答案**：$\boxed{B}$

**答案解析**：

$U, V$ 不相关 $\iff \text{Cov}(U, V) = 0$

$\text{Cov}(U, V) = \text{Cov}(X+Y, X-Y) = \text{Cov}(X, X) - \text{Cov}(X, Y) + \text{Cov}(Y, X) - \text{Cov}(Y, Y) = D(X) - D(Y)$

故不相关 $\iff D(X) = D(Y) \iff E(X^2) - [E(X)]^2 = E(Y^2) - [E(Y)]^2$

选 (B)。

**出处**：二维正态不相关条件

### 题 5

**题干**：设随机变量 $X$ 和 $Y$ 都服从正态分布，则

**选项**：
(A) $X + Y$ 服从正态分布
(B) $(X, Y)$ 服从二维正态分布
(C) $X$ 和 $Y$ 不相关，则 $X$ 和 $Y$ 相互独立
(D) 以上三个选项都不对

**标准答案**：$\boxed{D}$

**答案解析**：

(A) 不对，需 $X, Y$ 独立或联合正态

(B) 不对，边缘正态不保证联合正态

(C) 不对，不相关 $\implies$ 独立仅对联合正态成立

故选 (D)。

**出处**：正态分布性质辨析

### 题 6

**题干**：设二维随机变量 $(X, Y)$ 的概率分布为

$P\{X = 0, Y = 0\} = 0.4$，$P\{X = 0, Y = 1\} = a$，$P\{X = 1, Y = 0\} = b$，$P\{X = 1, Y = 1\} = 0.1$

已知随机事件 $\{X = 0\}$ 与 $\{X + Y = 1\}$ 相互独立，则

**选项**：
(A) $a = 0.2, b = 0.3$
(B) $a = 0.4, b = 0.1$
(C) $a = 0.3, b = 0.2$
(D) $a = 0.1, b = 0.4$

**标准答案**：$\boxed{B}$（需验证）

**答案解析**：

$0.4 + a + b + 0.1 = 1 \implies a + b = 0.5$

$P(X = 0) = 0.4 + a$

$P(X + Y = 1) = P(X = 0, Y = 1) + P(X = 1, Y = 0) = a + b = 0.5$

$P(X = 0, X + Y = 1) = P(X = 0, Y = 1) = a$

由独立性：$a = (0.4 + a) \cdot 0.5$

$2a = 0.4 + a$，$a = 0.4$，$b = 0.1$

选 (B)。

**出处**：二维分布独立性

### 题 7

**题干**：设平面区域 $D$ 由曲线 $y = 1/x$ 及直线 $y = 0, x = 1, x = e^2$ 所围成，二维随机变量 $(X, Y)$ 在区域 $D$ 上服从均匀分布，则 $(X, Y)$ 关于 $X$ 的边缘概率密度在 $x = 2$ 处的值为 \_\_\_\_\_\_

**标准答案**：$\boxed{\dfrac{1}{4}}$

**答案解析**：

$D$ 的面积 $= \int_1^{e^2} \dfrac{1}{x} dx = [\ln x]_1^{e^2} = 2$

联合密度 $f(x, y) = \begin{cases} 1/2, & (x, y) \in D \\ 0, & \text{其他} \end{cases}$

对 $x \in (1, e^2)$，$f_X(x) = \int_0^{1/x} \dfrac{1}{2} dy = \dfrac{1}{2x}$

在 $x = 2$ 处，$f_X(2) = \dfrac{1}{4}$

**出处**：均匀分布边缘密度

### 题 8

**题干**：设 $X$ 和 $Y$ 为两个随机变量，且 $P\{X \ge 0, Y \ge 0\} = 3/7$，$P\{X \ge 0\} = P\{Y \ge 0\} = 4/7$，则 $P\{\max(X, Y) \ge 0\} = $ \_\_\_\_\_\_

**标准答案**：$\boxed{\dfrac{5}{7}}$

**答案解析**：

$P(\max(X, Y) \ge 0) = P(X \ge 0 \text{ 或 } Y \ge 0) = P(X \ge 0) + P(Y \ge 0) - P(X \ge 0, Y \ge 0)$

$= 4/7 + 4/7 - 3/7 = 5/7$

**出处**：最大值事件概率

### 题 9

**题干**：设随机变量 $X$ 与 $Y$ 相互独立，且均服从区间 $[0, 3]$ 上的均匀分布，则 $P\{\max(X, Y) \le 1\} = $ \_\_\_\_\_\_

**标准答案**：$\boxed{\dfrac{1}{9}}$

**答案解析**：

$P(\max(X, Y) \le 1) = P(X \le 1, Y \le 1) = P(X \le 1)P(Y \le 1)$

$P(X \le 1) = \int_0^1 \dfrac{1}{3} dx = 1/3$

故 $P(\max \le 1) = 1/3 \cdot 1/3 = 1/9$

**出处**：独立均匀分布最大值

### 题 10

**题干**：设相互独立的两个随机变量 $X, Y$ 具有同一分布律，且 $X \sim \begin{pmatrix} 0 & 1 \\ 1/2 & 1/2 \end{pmatrix}$，则随机变量 $Z = \max(X, Y)$ 的分布律为 \_\_\_\_\_\_

**标准答案**：$\boxed{Z \sim \begin{pmatrix} 0 & 1 \\ 1/4 & 3/4 \end{pmatrix}}$

**答案解析**：

$P(Z = 0) = P(X = 0, Y = 0) = P(X = 0)P(Y = 0) = 1/2 \cdot 1/2 = 1/4$

$P(Z = 1) = 1 - P(Z = 0) = 3/4$

**出处**：离散随机变量最大值分布

### 题 11

**题干**：设二维随机变量 $(X, Y)$ 的联合概率密度为 $f(x, y) = \begin{cases} 6x, & 0 \le x \le y \le 1 \\ 0, & \text{其他} \end{cases}$，则 $P\{X + Y \le 1\} = $ \_\_\_\_\_\_

**标准答案**：$\boxed{\dfrac{1}{4}}$

**答案解析**：

$P(X + Y \le 1) = \iint_{x+y \le 1, 0 \le x \le y \le 1} 6x dx dy$

$= \int_0^{1/2} \int_x^{1-x} 6x dy dx = \int_0^{1/2} 6x(1 - 2x) dx = \int_0^{1/2} (6x - 12x^2) dx = [3x^2 - 4x^3]_0^{1/2} = 3/4 - 4/8 = 3/4 - 1/2 = 1/4$

**出处**：二维连续随机变量概率计算

### 题 12

**题干**：设 $X$ 和 $Y$ 是两个相互独立的随机变量，$X$ 在区间 $(0, 1)$ 上服从均匀分布，$Y$ 的概率密度为 $f_Y(y) = \begin{cases} \dfrac{1}{2} e^{-y/2}, & y > 0 \\ 0, & y \le 0 \end{cases}$，则二次方程 $t^2 + 2X t + Y = 0$ 有实根的概率 $p = $ \_\_\_\_\_\_（用标准正态函数值表示）

**标准答案**：$\boxed{1 - \sqrt{2\pi} [\Phi(1) - \Phi(0)]}$（约 0.1445）

**答案解析**：

$X \sim U(0, 1)$，$f_X(x) = 1, 0 < x < 1$

$Y \sim \text{Exp}(1/2)$

$X, Y$ 独立

方程有实根当且仅当 $(2X)^2 - 4 \cdot 1 \cdot Y \ge 0$，即 $X^2 \ge Y$

$p = P(Y \le X^2) = \int_0^1 \int_0^{x^2} f_X(x) f_Y(y) dy dx = \int_0^1 \int_0^{x^2} \dfrac{1}{2} e^{-y/2} dy dx$

$= \int_0^1 [1 - e^{-x^2/2}] dx = 1 - \int_0^1 e^{-x^2/2} dx$

又 $\int_0^1 e^{-x^2/2} dx = \sqrt{2\pi} [\Phi(1) - \Phi(0)]$（$\varphi(x) = \dfrac{1}{\sqrt{2\pi}} e^{-x^2/2}$）

故 $p = 1 - \sqrt{2\pi} [\Phi(1) - \Phi(0)]$

**出处**：独立连续型函数概率
