### 题 1

**题干**：设 $X \sim N(\mu, 4^2)$，$Y \sim N(\mu, 5^2)$，$p_1 = P\{X \le \mu - 4\}$，$p_2 = P\{Y \ge \mu + 5\}$，则

**选项**：
(A) 对任何实数 $\mu$，都有 $p_1 = p_2$
(B) 对任何实数 $\mu$，都有 $p_1 < p_2$
(C) 对任何实数 $\mu$，都有 $p_1 > p_2$
(D) 只对 $\mu$ 的个别值才有 $p_1 = p_2$

**标准答案**：$\boxed{A}$

**答案解析**：

$X \sim N(\mu, 16)$，$Z_1 = \dfrac{X - \mu}{4} \sim N(0, 1)$

$p_1 = P(X \le \mu - 4) = P\left(\dfrac{X-\mu}{4} \le -1\right) = \Phi(-1) = 1 - \Phi(1)$

$Y \sim N(\mu, 25)$，$Z_2 = \dfrac{Y - \mu}{5} \sim N(0, 1)$

$p_2 = P(Y \ge \mu + 5) = P\left(\dfrac{Y-\mu}{5} \ge 1\right) = 1 - \Phi(1)$

故 $p_1 = p_2 = 1 - \Phi(1)$

**出处**：正态分布标准化

### 题 2

**题干**：设随机变量 $X$ 的密度函数为 $\varphi(x)$，且 $\varphi(-x) = \varphi(x)$，$F(x)$ 是 $X$ 的分布函数，则对任意实数 $a$，有

**选项**：
(A) $F(-a) = 1 - \int_0^a \varphi(x) dx$
(B) $F(-a) = \dfrac{1}{2} - \int_0^a \varphi(x) dx$
(C) $F(-a) = F(a)$
(D) $F(-a) = 2F(a) - 1$

**标准答案**：$\boxed{B}$

**答案解析**：

$\varphi$ 为偶函数，$\int_{-\infty}^{\infty} \varphi(x) dx = 1$，$\int_0^{\infty} \varphi(x) dx = 1/2$

$F(-a) = \int_{-\infty}^{-a} \varphi(x) dx = \int_{a}^{\infty} \varphi(x) dx$（换元 $t = -x$）

$= \int_{-\infty}^{\infty} \varphi(x) dx - \int_{-\infty}^{a} \varphi(x) dx = 1 - F(a)$

又 $F(a) = \int_{-\infty}^{a} \varphi(x) dx = \int_{-\infty}^{0} \varphi(x) dx + \int_{0}^{a} \varphi(x) dx = 1/2 + \int_0^a \varphi(x) dx$

故 $F(-a) = 1 - F(a) = 1/2 - \int_0^a \varphi(x) dx$

选 (B)。

**出处**：对称分布函数性质

### 题 3

**题干**：设随机变量 $X$ 服从正态分布 $N(0, 1)$，对给定的 $\alpha \in (0, 1)$，数 $u_{\alpha}$ 满足 $P\{X > u_{\alpha}\} = \alpha$，若 $P\{|X| < x\} = \alpha$，则 $x$ 等于

**选项**：
(A) $u_{\alpha/2}$
(B) $u_{1-\alpha/2}$
(C) $u_{(1-\alpha)/2}$
(D) $u_{1-\alpha}$

**标准答案**：$\boxed{C}$

**答案解析**：

$P(|X| < x) = P(-x < X < x) = \Phi(x) - \Phi(-x) = 2\Phi(x) - 1 = \alpha$

故 $\Phi(x) = \dfrac{1+\alpha}{2}$

又 $\Phi(u_{\alpha}) = 1 - \alpha$（因 $P(X > u_{\alpha}) = \alpha$）

即 $u_{\alpha} = \Phi^{-1}(1 - \alpha)$

由 $\Phi(x) = (1+\alpha)/2$，$1 - (1-\alpha)/2 = (1+\alpha)/2$，即 $x = u_{(1-\alpha)/2}$

**出处**：标准正态分位数

### 题 4

**题干**：设 $F_1(x)$ 与 $F_2(x)$ 分别为随机变量 $X_1$ 与 $X_2$ 的分布函数。为使 $F(x) = aF_1(x) - bF_2(x)$ 是某一随机变量的分布函数，在下列给定的各组数值中应取

**选项**：
(A) $a = 3/5, b = -2/5$
(B) $a = 2/3, b = 2/3$
(C) $a = -1/2, b = 3/2$
(D) $a = 1/2, b = -3/2$

**标准答案**：$\boxed{A}$

**答案解析**：

分布函数性质：$\lim_{x \to +\infty} F(x) = 1$，$\lim_{x \to -\infty} F(x) = 0$，$0 \le F(x) \le 1$，单调不减

由 $F(+\infty) = a \cdot 1 - b \cdot 1 = a - b = 1$

验证 (A) $a = 3/5, b = -2/5$，$a - b = 3/5 + 2/5 = 1$ ✓

(B) $2/3 - 2/3 = 0$ ✗

(C) $-1/2 - 3/2 = -2$ ✗

(D) $1/2 + 3/2 = 2$ ✗

**出处**：分布函数性质

### 题 5

**题干**：设随机变量 $X$ 的分布律为 $P\{X = k\} = b \lambda^k$，$k = 1, 2, \cdots$，且 $b > 0$，则 $\lambda$ 为

**选项**：
(A) 任意实数
(B) $\lambda = b + 1$
(C) $\lambda = \dfrac{1}{1+b}$
(D) $\lambda = \dfrac{1}{b-1}$

**标准答案**：$\boxed{C}$

**答案解析**：

$\sum_{k=1}^{\infty} P(X = k) = b \sum_{k=1}^{\infty} \lambda^k = b \cdot \dfrac{\lambda}{1 - \lambda} = 1$（等比级数，$|\lambda| < 1$）

故 $\dfrac{b\lambda}{1 - \lambda} = 1$，$b\lambda = 1 - \lambda$，$\lambda(b + 1) = 1$，$\lambda = \dfrac{1}{1+b}$

选 (C)。

**出处**：离散分布律归一化

### 题 6

**题干**：设随机变量 $X$ 的概率密度为 $f(x) = \begin{cases} Ae^{-x}, & x > 0 \\ 0, & x \le 0 \end{cases}$，则常数 $A = $

**选项**：
(A) 1
(B) 2
(C) $1/2$
(D) $e$

**标准答案**：$\boxed{A}$

**答案解析**：

$\int_0^{\infty} A e^{-x} dx = A = 1$

故 $A = 1$，$X \sim \text{Exp}(1)$

**出处**：指数分布

### 题 7

**题干**：设随机变量 $X$ 的分布函数为 $F(x) = \begin{cases} 0, & x < 0 \\ A \sin x, & 0 \le x \le \pi/2 \\ 1, & x > \pi/2 \end{cases}$，则 $A = $ \_\_\_\_\_\_，$P\{|X| < \pi/6\} = $ \_\_\_\_\_\_

**标准答案**：$A = \boxed{1}$，$P\{|X| < \pi/6\} = \boxed{1/2}$

**答案解析**：

$F$ 右连续：$F(\pi/2+) = 1 = F(\pi/2) = A \sin(\pi/2) = A$，故 $A = 1$

$P(|X| < \pi/6) = P(-\pi/6 < X < \pi/6) = F(\pi/6) - F(-\pi/6) = \sin(\pi/6) - 0 = 1/2$

**出处**：分布函数的连续性

### 题 8

**题干**：设随机变量 $X$ 服从参数为 1 的指数分布，则 $E(X + e^{-2X}) = $ \_\_\_\_\_\_

**标准答案**：$\boxed{\dfrac{4}{3}}$

**答案解析**：

$X \sim \text{Exp}(1)$，$f(x) = e^{-x}, x > 0$

$E(X) = 1$

$E(e^{-2X}) = \int_0^{\infty} e^{-2x} e^{-x} dx = \int_0^{\infty} e^{-3x} dx = \dfrac{1}{3}$

故 $E(X + e^{-2X}) = 1 + 1/3 = 4/3$

**出处**：指数分布数字特征

### 题 9

**题干**：设随机变量 $X$ 的概率密度为 $f(x) = \begin{cases} 2x, & 0 < x < 1 \\ 0, & \text{其他} \end{cases}$，以 $Y$ 表示对 $X$ 的三次独立重复观察中事件 $\{X \le 1/2\}$ 出现的次数，则 $P\{Y = 2\} = $ \_\_\_\_\_\_

**标准答案**：$\boxed{\dfrac{9}{64}}$

**答案解析**：

$p = P(X \le 1/2) = \int_0^{1/2} 2x dx = [x^2]_0^{1/2} = 1/4$

$Y \sim B(3, 1/4)$

$P(Y = 2) = \binom{3}{2} (1/4)^2 (3/4) = 3 \cdot 3/64 = 9/64$

**出处**：二项分布应用

### 题 10

**题干**：设随机变量 $X$ 服从均值为 10，均方差为 0.02 的正态分布，则 $X$ 落在区间 $(9.95, 10.05)$ 上的概率为 \_\_\_\_\_\_（用标准正态分布函数值表示）

**标准答案**：$\boxed{2\Phi(2.5) - 1}$ 或 $\boxed{2\Phi\left(\dfrac{5}{2}\right) - 1}$

**答案解析**：

$X \sim N(10, 0.02^2)$

$P(9.95 < X < 10.05) = P\left(\dfrac{9.95-10}{0.02} < \dfrac{X-10}{0.02} < \dfrac{10.05-10}{0.02}\right) = P(-2.5 < Z < 2.5)$

$= \Phi(2.5) - \Phi(-2.5) = 2\Phi(2.5) - 1$

**出处**：正态分布标准化

### 题 11

**题干**：设随机变量 $X$ 服从二项分布 $B(2, p)$，随机变量 $Y$ 服从二项分布 $B(3, p)$。若 $P\{X \ge 1\} = 5/9$，则 $P\{Y \ge 1\} = $ \_\_\_\_\_\_

**标准答案**：$\boxed{\dfrac{19}{27}}$

**答案解析**：

$P(X \ge 1) = 1 - P(X = 0) = 1 - (1-p)^2 = 5/9$

$(1-p)^2 = 4/9$，$1-p = 2/3$（$p = 1/3$）

$P(Y \ge 1) = 1 - P(Y = 0) = 1 - (1-p)^3 = 1 - (2/3)^3 = 1 - 8/27 = 19/27$

**出处**：二项分布

### 题 12

**题干**：若随机变量 $\xi$ 在 $(1, 6)$ 上服从均匀分布，则方程 $x^2 + \xi x + 1 = 0$ 有实根的概率是 \_\_\_\_\_\_

**标准答案**：$\boxed{\dfrac{4}{5}}$

**答案解析**：

$\xi \sim U(1, 6)$，$f(x) = 1/5, 1 < x < 6$

方程有实根当且仅当 $\xi^2 - 4 \ge 0$，即 $|\xi| \ge 2$，即 $\xi \ge 2$

$P(\xi \ge 2) = \int_2^6 \dfrac{1}{5} dx = 4/5$

**出处**：均匀分布应用
