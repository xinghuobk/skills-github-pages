## 📝 题库说明

每个子目录的 `questions.md` 文件包含：

- **单项选择题**（约10题）：考查基础知识点的记忆和理解
- **多项选择题**（约6题）：考查知识点的融会贯通，易设干扰项
- **分析题**（约3题）：考查综合运用能力，与历年真题命题思路一致

每道题均包含：
- 题干
- 选项
- 标准答案
- 答案解析（含详细的知识点讲解）
- 出处标注（参考历年真题、肖秀荣1000题、考研政治核心考案等）

## 💡 复习建议

### 第一阶段：基础复习（3-6月）

- **任务：** 通读教材，理解核心概念
- **重点：** 马克思主义哲学原理的理解、政治经济学的基础概念
- **方法：** 配合练习题巩固基础

### 第二阶段：强化提高（7-9月）

- **任务：** 系统刷题，整理错题
- **重点：** 多项选择题的训练、分析题的答题思路培养
- **方法：** 做肖秀荣1000题、徐涛冲刺背诵笔记

### 第三阶段：冲刺模拟（10-12月）

- **任务：** 模拟训练、背诵分析题素材
- **重点：** 时政热点的掌握、肖四肖八的深入研究
- **方法：** 每周至少做一套完整模拟题

### 各模块复习要点

| 模块 | 复习要点 |
|---|---|
| 马原 | 重在理解原理，不要死记硬背。哲学部分要学会运用原理分析问题 |
| 毛中特 | 结合时政复习，注意党的重要会议和最新理论成果 |
| 史纲 | 注意时间线和重大历史事件的意义，善于纵向横向对比 |
| 思修法基 | 重点在人生观、价值观和法治思维，易出分析题 |
| 形势与政策 | 关注重大时政热点，特别是党和国家的重要会议 |
