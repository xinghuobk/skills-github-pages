# 福州大学 复试流程与分值结构

---

## 一、2026 年复试最新变化

### ⚠️ 重要变化：新增机试环节

福州大学计算机与大数据学院 / 软件学院 **2026 年硕士研究生复试将新增机试（上机编程）环节**！

这意味着复试考核将更加全面，对考生的编程实战能力提出了更高要求。

## 二、复试总体流程

### 复试时间安排

| 阶段 | 时间 | 说明 |
| :--: | :--: | :--: |
| 初试成绩公布 | 次年 2 月中下旬 | 公布单科和总分 |
| 国家线公布 | 次年 3 月中旬 | 34 所自划线学校除外 |
| 复试分数线公布 | 次年 3 月下旬 | 学院公布复试名单和分数线 |
| 复试报到 | 次年 3 月底 / 4 月初 | 线下到校报到，资格审查 |
| 复试考核 | 次年 3 月底 / 4 月初 | 机试 + 笔试 + 面试（具体顺序以当年通知为准） |
| 成绩公布 | 复试后 3-5 个工作日 | 学院公布复试成绩和拟录取名单 |
| 调剂 | 次年 4 月 | 未录取考生可参与调剂 |

### 复试流程图示

```
初试成绩公布 → 复试分数线公布 → 考生确认参加复试 → 到校报到 → 资格审查
    ↓
上机编程测试（2026 新增）→ 专业笔试 → 综合面试（含英语）→ 体检
    ↓
成绩公布 → 拟录取名单公示 → 录取通知书发放
```

## 三、分值结构与计算方法

### 复试各环节分值分布

| 环节 | 分值 | 占复试比例 | 说明 |
| :--: | :--: | :--: | :--: |
| **专业知识考核** | 40 分 | 40% | 笔试或面试形式，考察计算机核心课程 |
| **英语听说能力** | 20 分 | 20% | 自我介绍 + 英语问答 |
| **综合素质面试** | 40 分 | 40% | 项目经历、科研潜力、综合素质 |
| **（新增）上机编程** | 计入专业知识 | 具体以当年通知为准 | C 语言算法题，考察编程能力 |
| **复试总分** | **100 分** | 100% | |

### 总成绩计算方法

```
总成绩 = （初试成绩 ÷ 5） × 70% + 复试成绩 × 30%
```

**权重对比**：
- **初试权重：70%** ⭐
- **复试权重：30%**

> **重要结论**：初试高分在福大录取中具有压倒性优势！复试主要起"筛选合格者"的作用，除非复试不及格，否则初试高分基本稳录。

## 四、2026 年新增机试环节详解

### 机试说明

| 项目 | 说明 |
| :--: | :--: |
| **考试形式** | 在线编程（OJ 评测系统） |
| **编程语言** | C 语言 / C++（以 C 为主） |
| **考试时长** | 预计 120-180 分钟 |
| **题目数量** | 预计 3-5 道题 |
| **评分方式** | 根据通过的测试用例数量给分 |
| **考察重点** | 数据结构、算法设计、编程实现能力 |

### 机试参考教材

1. **《程序设计导引及在线实践》** —— 李文新
   - ACM 程序设计竞赛经典入门教材
   - 内容覆盖：基础语法、常用算法、在线实践

2. **《数据结构（C 语言版）》** —— 王晓东
   - 经典数据结构教材
   - 适合算法题训练基础

3. **《算法竞赛入门经典》** —— 刘汝佳
   - 算法竞赛入门经典教材
   - 覆盖常见算法题型

4. **《数据结构与算法分析》** —— Mark Allen Weiss

### 机试练习平台

- **POJ（北京大学在线评测系统）**：http://poj.org
- **HDU OJ（杭电在线评测）**：http://acm.hdu.edu.cn
- **LeetCode**：https://leetcode.com
- **Codeforces**：https://codeforces.com
- **牛客网**：https://www.nowcoder.com
- **福大本校 OJ**：（如有）

### 机试备考建议

1. **基础语法**：熟练掌握 C 语言的基本语法，包括输入输出、数组、字符串、指针、结构体、动态内存等
2. **数据结构**：熟练掌握链表、栈、队列、树、图、哈希表等数据结构的实现
3. **基础算法**：掌握排序、查找、递归、分治、贪心、动态规划、回溯等基础算法
4. **题目练习**：在 OJ 平台刷题，从简单题开始，循序渐进
5. **时间管理**：机试时间有限，需要在有限时间内完成编程和调试
6. **代码规范**：注意代码可读性，适当注释，变量命名规范
7. **福大 ACM 优势**：福大具有 10 次晋级 ACM-ICPC 全球总决赛的传统，机试要求相对较高，需充分准备

## 七、英语听说能力考核

### 考核形式

| 形式 | 说明 | 分值建议 |
| :--: | :--: | :--: |
| 英语自我介绍 | 1-2 分钟自我简介 | 5 分 |
| 英语问答 | 考官用英语提问，考生用英语回答 2-3 个问题 | 10 分 |
| 专业英语 | 可能涉及专业术语、专业话题讨论 | 5 分 |

### 常见问题类型

1. **个人背景**：家庭、家乡、大学、专业
2. **兴趣爱好**：课余活动、喜欢的书籍/电影
3. **学习经历**：本科学习、课程、项目经历
4. **研究兴趣**：为什么选择福大、对什么方向感兴趣
5. **未来规划**：研究生期间计划、职业规划
6. **生活类**：描述一次难忘的经历、最喜欢的城市等
7. **专业类**：用英语解释某个计算机概念（简单版）

### 英语备考建议

1. **准备自我介绍**：写好 1-2 分钟的英文自我介绍，反复练习
2. **准备 10-15 个常见问题的答案**：每个问题准备 3-5 句话的回答
3. **练习发音和语速**：通过录音回放检查自己的发音和语速
4. **积累专业词汇**：了解计算机相关英文术语（algorithm、database、network 等）
5. **模拟面试**：找同学或家人模拟英语面试场景
6. **关注语法**：不必追求完美语法，表达清楚、有自信更重要

### 英语自我介绍模板

```
Good morning/afternoon, respected professors.

My name is XXX. I am XX years old and come from XX city, XX province.
I graduated from XX University with a bachelor's degree in XX.

During my undergraduate years, I have been working hard. My major is
XX and I have a strong interest in XX direction. I have participated
in XX projects and competitions. My programming skills include XX.

In my spare time, I enjoy XX (reading, sports, etc.). These hobbies
help me maintain a healthy work-life balance.

If I am fortunate enough to be admitted to Fuzhou University, I will
work hard to deepen my research capabilities in the field of XX.

Thank you for your time and consideration.
```

## 八、综合素质面试

### 面试流程

| 步骤 | 内容 | 时间 |
| :--: | :--: | :--: |
| 1 | 入场、问候、提交材料 | 1 分钟 |
| 2 | 中文自我介绍 | 1-2 分钟 |
| 3 | 简历项目提问 | 5-10 分钟 |
| 4 | 专业知识问答 | 5-8 分钟 |
| 5 | 科研潜力/学习态度评估 | 3-5 分钟 |
| 6 | 英语问答 | 3-5 分钟 |
| 7 | 考生提问 | 1-2 分钟 |
| **合计** | | **15-25 分钟** |

### 面试考察要点

| 考察维度 | 具体内容 | 占比 |
| :--: | :--: | :--: |
| **专业基础** | 数据结构、操作系统、网络、数据库等核心知识 | 30% |
| **编程能力** | 算法思维、代码实现、问题分析 | 20% |
| **项目经验** | 项目参与度、项目理解、技术深度 | 15% |
| **科研潜力** | 科研兴趣、创新思维、文献阅读能力 | 15% |
| **综合素质** | 沟通表达、逻辑思维、团队协作、学习态度 | 10% |
| **英语能力** | 听说能力、专业词汇 | 10% |

### 面试注意事项

1. **着装得体**：建议穿着整洁、大方，不必过于正式但也不可随意
2. **礼貌待人**：进门前敲门、问好，面试结束后感谢、轻轻关门
3. **态度诚恳**：不会的问题坦诚说明，不要不懂装懂
4. **逻辑清晰**：回答问题有条理，可以用"第一、第二、第三"等结构
5. **突出优势**：引导老师提问自己擅长的领域和项目
6. **眼神交流**：与各位老师都有眼神交流，不要只盯着一位老师
7. **语速适中**：控制语速，给老师思考和记录的时间
8. **心态平和**：保持平常心，展现真实的自己

## 十、复试常见问题解答

### Q1：福大复试公平吗？会不会歧视本科出身？

**A**：福州大学复试公平透明，不歧视本科出身。导师更看重的是你的专业能力、学习态度和科研潜力。每年都有不少来自普通本科院校的考生被录取。

### Q2：初试高分（如 380+）还需要认真准备复试吗？

**A**：初试高分基本具有极大优势（初试权重 70%），但仍需认真准备：
- 复试成绩不及格者不予录取
- 奖学金评定可能参考总成绩
- 导师选择时可能更看重复试表现

### Q3：2026 年新增机试，难度如何？

**A**：作为首次新增环节，预计难度不会太高，但需要认真准备：
- 考察基础数据结构和算法
- 建议完成 LeetCode Top 100 热门题目
- 熟练 C 语言编程和常见算法实现

### Q4：如果初试成绩处于分数线边缘，应该如何准备？

**A**：边缘考生应：
1. **全力准备复试**，复试每 1 分的提升价值相当于初试约 4.7 分
2. **同时关注调剂信息**，做好两手准备
3. **重点提升上机编程和专业知识**，这是最容易拉开差距的部分

### Q5：福大复试是否有笔试？

**A**：根据近年情况，可能采用笔试或面试形式考察专业知识。2026 年新增机试后，专业知识考核形式以当年学院通知为准。建议两种形式都准备。

### Q6：联系导师有必要吗？何时联系？

**A**：建议联系导师，但注意方式方法：
- **时间**：初试成绩公布后，确认可以进入复试时联系
- **方式**：发送简短、专业的邮件（附简历和成绩单）
- **内容**：表达对导师研究方向的兴趣，展示自身能力
- **注意**：不要同时联系过多导师，不要给导师造成困扰

## 十一、复试心态调整

1. **正确认识复试**：复试是"资格考试"而非"淘汰赛"，初试高分已有极大优势
2. **保持学习状态**：初试结束后不要完全松懈，保持一定学习节奏
3. **合理预期**：不要过度焦虑，也不要完全放松
4. **模拟训练**：多进行几次模拟面试，适应面试场景
5. **健康第一**：保证睡眠、适度运动，以最佳状态迎接复试
