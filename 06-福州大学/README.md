# 福州大学 计算机考研复试资料合集

---

## 一、学校简介

**福州大学（Fuzhou University，简称福大/FZU）**

- **学校属性**：211 工程 / 双一流建设高校 / 省属重点大学
- **所在地**：福建省福州市（旗山校区为主校区，另有怡山、铜盘、厦门工艺美术学院等校区）
- **创办时间**：1958 年
- **学校定位**：以工为主、理工结合，多学科协调发展的重点大学
- **学校特色**：福建省"双一流"建设的核心高校，工科实力雄厚

---

## 二、计算机与大数据学院 / 软件学院介绍

### 计算机与大数据学院

福州大学**计算机与大数据学院**是福建省计算机学科的重要基地之一。

**学科优势**：
- **教育部第五轮学科评估：B 类**（计算机科学与技术）
- **ESI 全球前 3‰**：计算机学科进入 ESI 全球排名前 3‰
- **一级学科博士点**：计算机科学与技术
- **一级学科硕士点**：计算机科学与技术、软件工程
- **专业学位硕士点**：电子信息（计算机技术、软件工程、人工智能方向）

### 软件学院

福州大学**软件学院**是国家示范性软件学院之一，专注于软件工程人才培养。

**研究方向**：
- 人工智能与机器学习
- 大数据分析与处理
- 网络与信息安全
- 软件工程理论与实践
- 计算机视觉与图像处理
- 自然语言处理
- 分布式系统与云计算
- 物联网与嵌入式系统

## 四、ACM 竞赛优势

福州大学在 ACM 程序设计竞赛方面具有突出优势：

- **ACM-ICPC 全球总决赛**：累计 **10 次**晋级全球总决赛
- **亚洲区域赛**：多次获得金奖

> **重要提示**：福大 2026 年复试新增机试环节，ACM 训练背景的学生将具有明显优势！

### 复试形式（2026 最新）

| 环节 | 分值 | 说明 |
| :--: | :--: | :--: |
| **专业知识笔试/面试** | 40 分 | 计算机核心课程基础知识 |
| **英语听说** | 20 分 | 英语自我介绍、专业英语问答 |
| **综合素质面试** | 40 分 | 项目经历、科研潜力、综合素养 |
| **（新增）上机编程** | 机试成绩计入复试 | 2026 年新增！ |

### 总成绩计算

```
总成绩 = （初试成绩 ÷ 5）× 70% + 复试成绩 × 30%
```

## 十二、报考建议

1. **重视初试（权重 70%）**：福大初试占比极高，应将主要精力放在初试备考，争取高分
2. **关注机试（2026 新增）**：提前准备编程能力，利用 ACM 训练资源
3. **福大复试公平透明**：不歧视本科出身，注重实际能力
4. **地理位置优越**：位于福州，靠近厦门、泉州等经济发达地区，就业机会丰富
5. **学科实力稳步提升**：计算机学科 B 类、ESI 前 3‰，发展势头良好
6. **学费性价比高**：8000 元/年的学费标准在 211 高校中具有竞争力
7. **奖学金覆盖面广**：绝大多学生可获得各类奖学金资助
