### 5. 关系的性质与闭包
**题目**：设 R 是 A = {1, 2, 3, 4} 上的关系，R = {(1,1), (1,3), (2,1), (3,3), (4,1), (4,2), (4,3), (4,4)}。
(1) 判断 R 的性质（自反、反自反、对称、反对称、传递）并说明理由；
(2) 求 R 的传递闭包 t(R)。

**解答**：

**(1) 性质判断**

**自反性**：需要 (2,2) ∈ R，但 (2,2) ∉ R ✗

**反自反性**：(1,1) ∈ R，存在自环 ✗

**对称性**：若对称，(1,3)∈R 则应有 (3,1)∈R，但 (3,1)∉R ✗

**反对称性**：检查是否存在 (x,y) 和 (y,x) 同时在 R 中且 x≠y：
- (2,1)∈R，但 (1,2)∉R
- (4,1)∈R，但 (1,4)∉R
- (4,2)∈R，但 (2,4)∉R
- (4,3)∈R，但 (3,4)∉R

没有反对称性的反例 ✓

**传递性**：若 (x,y)∈R 且 (y,z)∈R，是否一定有 (x,z)∈R？
- 找到反例：(2,1)∈R, (1,3)∈R，但 (2,3)∉R ✗

**结论**：R 是**反对称**的，不是自反、反自反、对称、传递的。

**(2) 传递闭包 t(R)**

方法：R⁺ = R ∪ R² ∪ R³ ∪ R⁴

R = {(1,1), (1,3), (2,1), (3,3), (4,1), (4,2), (4,3), (4,4)}

R² = R∘R：
- (1,1)∘(1,1) = (1,1), (1,1)∘(1,3) = (1,3)
- (1,3)∘(3,3) = (1,3)
- (2,1)∘(1,1) = (2,1), (2,1)∘(1,3) = (2,3) ← **新**
- (3,3)∘(3,3) = (3,3)
- (4,1)∘(1,1) = (4,1), (4,1)∘(1,3) = (4,3)
- (4,2)∘(2,1) = (4,1)
- (4,3)∘(3,3) = (4,3)
- (4,4)∘(4,1) = (4,1), 等等
R² = {(1,1), (1,3), (2,1), (2,3), (3,3), (4,1), (4,2), (4,3), (4,4)}

R³ = R²∘R：检查是否有新边，主要检查 (2,3)∘...，没有新增
R⁴ 也没有新增

```
t(R) = R ∪ R² ∪ R³ ∪ R⁴ = {(1,1), (1,3), (2,1), (2,3), (3,3), (4,1), (4,2), (4,3), (4,4)}
```

**即 t(R) 比 R 多了 (2,3) 一条边。**

### 6. 等价关系与划分
**题目**：设 R 是整数集 ℤ 上的关系，定义为：aRb 当且仅当 3 | (a-b)（即 a 和 b 模 3 同余）。
证明 R 是等价关系，并求 R 的所有等价类和商集 ℤ/R。

**解答**：

**证明 R 是等价关系**

**自反性**：对任意 a ∈ ℤ，a - a = 0，显然 3 | 0，故 aRa ✓

**对称性**：若 aRb，即 3 | (a-b)，则 a-b = 3k，于是 b-a = -3k = 3(-k)，即 3 | (b-a)，故 bRa ✓

**传递性**：若 aRb 且 bRc，则 a-b = 3k₁，b-c = 3k₂，两式相加：a-c = 3(k₁+k₂)，即 3 | (a-c)，故 aRc ✓

**R 是等价关系**。

**等价类**：

```
[0] = { x ∈ ℤ | x ≡ 0 (mod 3) } = { ..., -6, -3, 0, 3, 6, ... }
[1] = { x ∈ ℤ | x ≡ 1 (mod 3) } = { ..., -5, -2, 1, 4, 7, ... }
[2] = { x ∈ ℤ | x ≡ 2 (mod 3) } = { ..., -4, -1, 2, 5, 8, ... }
```

**商集**（ℤ 在 R 下的划分）：
```
ℤ/R = { [0], [1], [2] }
```

### 7. 基数与可数性
**题目**：(1) 证明有理数集 ℚ 是可数集；
(2) 证明实数集 ℝ 是不可数集（用 Cantor 对角线法）。

**解答**：

**(1) ℚ 可数的证明**

**证明思路**：先建立 ℕ×ℕ 到 ℕ 的双射（或单射），再将 ℚ 嵌入 ℕ×ℕ 的某个子集。

**方法**：对每个有理数 q，写成既约分数 q = ±a/b（a > 0, b > 0 互素）。

**第一步**：证明 ℕ×ℕ 可数。
将 ℕ×ℕ 按对角线顺序排列：
```
(1,1), 
(1,2), (2,1), 
(1,3), (2,2), (3,1), 
(1,4), (2,3), (3,2), (4,1), 
...
```
这给出了 ℕ×ℕ 与 ℕ 的一个显式双射，故 ℕ×ℕ 可数。

**第二步**：将 ℚ⁺ 映射到 ℕ×ℕ 的子集。
对正有理数 q = a/b（既约分数），映射为有序对 (a, b) ∈ ℕ×ℕ。
这是单射（因为分数表示唯一）。
可数集的子集仍可数，故 ℚ⁺ 可数。

**第三步**：ℚ = ℚ⁻ ∪ {0} ∪ ℚ⁺，其中 ℚ⁻ 与 ℚ⁺ 之间有双射（q ↔ -q），故 ℚ⁻ 也可数。
可数个可数集之并仍可数，因此 ℚ 可数。∎

**(2) ℝ 不可数的证明（Cantor 对角线法）**

**反证法**：假设 ℝ 可数，则其子集 (0,1) 也可数。
因此存在序列 r₁, r₂, r₃, ... 穷尽 (0,1) 中所有实数。

将每个 r_i 表示为无限十进制小数（约定不用 9 循环表示）：
```
r₁ = 0.d₁₁ d₁₂ d₁₃ d₁₄ ...
r₂ = 0.d₂₁ d₂₂ d₂₃ d₂₄ ...
r₃ = 0.d₃₁ d₃₂ d₃₃ d₃₄ ...
...
```

构造新数 x = 0.x₁ x₂ x₃ ...，其中：
```
x_i = { 5, 若 d_ii ≠ 5
      { 3, 若 d_ii = 5
```

则 x ∈ (0, 1)，但 x 与每个 r_i 在第 i 位不同，故 x 不在序列中。
矛盾！因此 (0, 1) 不可数，从而 ℝ 不可数。∎

## 第三部分：图论

### 8. 握手定理与图的连通性
**题目**：(1) 证明握手定理；
(2) 判断序列 3, 3, 3, 1 是否可图，若可图则构造一个图；
(3) 证明：n 阶图若 δ ≥ n/2，则图连通。

**解答**：

**(1) 握手定理**：任何图 G = (V, E) 中，Σ_{v∈V} deg(v) = 2|E|

**证明**：每条边有两个端点，每条边对总度数的贡献为 2。
按顶点计数：每个顶点 v 贡献 deg(v)。
按边计数：每条边贡献 2。
两者相等，故 Σ deg(v) = 2|E|。∎

**推论**：奇数度顶点的个数必为偶数。

**(2) 序列 3, 3, 3, 1 是否可图？**

总度数 = 3+3+3+1 = 10（偶数，可能可图）

**用 Havel-Hakimi 算法**：
排序：3, 3, 3, 1
去掉第一个 3，后面 3 个各减 1：2, 2, 0
排序：2, 2, 0
去掉第一个 2，后面 2 个各减 1：1, -1 ✗ 出现负数！

**结论**：序列 3, 3, 3, 1 **不可图**。

**另一个验证**：度数为 1 的顶点只能连向一个顶点，但它连向的顶点度数必须是 3（它自己占 1，还需连 2 个其他顶点）。剩余 2 个顶点度数都是 3，但是它们的总度数为 6，而边贡献的度数需要平衡。具体地，设顶点 A(deg 1) 连到 B(deg 3)，则 B 还需要再连 2 条边到 C、D。但 C、D 各自度数都是 3，它们除了连 B 之外，还需要各自连 2 条边。但只有 3 个顶点了（A 不能再连），C-D 之间加一条边（贡献 2 度），C 和 D 还差 1 度，但没有其他顶点了——矛盾。

**(3) 度条件下的连通性证明**

**定理**：n 阶图 G，若 δ(G) ≥ n/2，则 G 连通。

**证明（反证法）**：假设 G 不连通，则至少有 2 个连通分支。
设最小的连通分支有 k 个顶点，则 1 ≤ k ≤ n/2（否则另一分支更小）。

在这个 k 顶点的分支中，每个顶点最多只能与分支内的 k-1 个顶点相邻（不能连到其他分支）。
故每个顶点度数 ≤ k-1。

但 k ≤ n/2，故 k-1 ≤ n/2 - 1 < n/2。
因此 δ ≤ k-1 < n/2，与 δ ≥ n/2 矛盾！

故 G 必连通。∎

### 9. 欧拉图与最小生成树
**题目**：(1) 叙述并证明：连通无向图是欧拉图当且仅当每个顶点度数为偶数；
(2) 用 Kruskal 算法求顶点集 {a,b,c,d,e}，边权 (a,b)=1, (a,c)=3, (b,c)=2, (c,d)=4, (b,d)=5, (d,e)=2 的图的最小生成树。

**解答**：

**(1) 欧拉图充要条件证明**

**必要性（"⇒"）**：设 C 是欧拉回路（遍历每条边恰好一次的回路）。
沿 C 行走，每次进入一个顶点必从另一条边离开。起点/终点也是同一顶点（回路），故进入=离开。
对每个顶点 v，进入次数 = 离开次数，因此 deg(v) = 2 × 进入次数，是偶数。∎

**充分性（"⇐"）**：连通图 G 中每个顶点度数为偶数，要证存在欧拉回路。

**对边数 m 归纳**：
- m = 0：G 是单个顶点，空回路是欧拉回路 ✓
- 假设边数 < m 时成立，考虑边数 = m 的图 G：
  从任意顶点 v₀ 出发沿未走过的边行走，由于每个顶点是偶数度，每次进入一个顶点必能从另一条边离开，故必然能回到 v₀（不会在非起点处卡住），形成一个回路 C。
  去掉 C 中所有边，得到图 G'，G' 的每个顶点仍为偶数度（在 C 中每个顶点用掉偶数条边）。
  G' 的每个连通分支满足归纳假设，有欧拉回路。
  将这些分支的欧拉回路"插入"到 C 的相应顶点，即得到 G 的欧拉回路。∎

**(2) Kruskal 算法求 MST**

**图**：顶点 {a,b,c,d,e}，边权 (a,b)=1, (a,c)=3, (b,c)=2, (c,d)=4, (b,d)=5, (d,e)=2

**图示**：
```
a ──1── b ──5── d ──2── e
 \      |       |
  \     2       |
   3    |       4
    \   |       |
     └── c ─────┘
```

**按权排序所有边**：
1: (a,b), 2: (b,c), 2: (d,e), 3: (a,c), 4: (c,d), 5: (b,d)

**用并查集逐步加入边**：

| 步骤 | 候选边 | 权重 | 检查是否成环 | 操作 | 已选边 |
|------|--------|------|-------------|------|--------|
| 1 | (a,b) | 1 | 否（a, b 不同集合） | 加入 | {(a,b)} |
| 2 | (b,c) | 2 | 否（{a,b}, c 不同） | 加入 | {(a,b), (b,c)} |
| 3 | (d,e) | 2 | 否（{d}, {e} 不同） | 加入 | {(a,b), (b,c), (d,e)} |
| 4 | (a,c) | 3 | 是（a, c 已连通） | 跳过 | 不变 |
| 5 | (c,d) | 4 | 否（{a,b,c}, {d,e} 不同） | 加入 | {(a,b), (b,c), (d,e), (c,d)} |
| 6 | (b,d) | 5 | 是（所有顶点已连通） | 跳过 | 结束 |

已选 4 条边（5 顶点 MST 需要 4 条边），算法结束。

**MST 边集**：{(a,b), (b,c), (d,e), (c,d)}

**MST 总权重**：1 + 2 + 2 + 4 = **9**

**MST 图示**：
```
a ──1── b ──2── c ──4── d ──2── e
```

### 10. 平面图与欧拉公式
**题目**：(1) 证明欧拉公式：对连通平面图，V - E + F = 2；
(2) 证明：n ≥ 3 的简单平面图中，E ≤ 3n - 6；
(3) 利用(2)证明 K₅ 不是平面图；
(4) 说明如何证明 K_{3,3} 不是平面图（提示：二分图无奇回路，可推出更强不等式）。

**解答**：

**(1) 欧拉公式证明**

**对面数 F 归纳**：

- **基例 F = 1**：只有一个面（外部面），说明图中没有回路（否则会围成有限面），即图是树。
  树满足 E = V - 1，故 V - E + F = V - (V-1) + 1 = 2 ✓

- **归纳步骤**：假设对面数 ≤ k 的连通平面图公式成立。
  考虑面数 = k+1 的连通平面图 G。由于 F ≥ 2，G 不是树，必有回路。
  取回路中任意一条边 e，从 G 中去掉 e 得到 G'。
  去掉 e 后：V' = V（顶点数不变），E' = E - 1，F' = F - 1（被 e 分隔的两个面合并）。
  G' 仍连通（去掉回路的边不破坏连通性），且有 F' = k 个面。
  由归纳假设：V' - E' + F' = 2
  即 V - (E-1) + (F-1) = V - E + F = 2 ✓

故欧拉公式成立。∎

**(2) 证明 E ≤ 3V - 6**

**证明**：对简单平面图，每个面至少由 3 条边围成（无重边和自环），即 deg(f) ≥ 3。

对所有面求和：Σ deg(f) ≥ 3F

但每条边最多属于 2 个面（每条边在两个面边界上），故 Σ deg(f) ≤ 2E

因此 3F ≤ 2E，即 F ≤ 2E/3

代入欧拉公式 V - E + F = 2：
2 = V - E + F ≤ V - E + 2E/3 = V - E/3

两边乘 3：6 ≤ 3V - E，即 **E ≤ 3V - 6**。∎

**(3) K₅ 不是平面图的证明**

K₅（5 顶点完全图）：V = 5，E = C(5,2) = 10

若 K₅ 是平面图，由 (2) 应有 E ≤ 3V - 6 = 3×5 - 6 = 9
但 10 > 9，矛盾！

故 **K₅ 不是平面图**。∎

**(4) K_{3,3} 不是平面图的证明**

K_{3,3} 是二分图，二分图无奇回路（所有回路长度为偶数），故每个面至少由 4 条边围成。

对 K_{3,3}：V = 6，E = 3×3 = 9

**更强不等式（对二分图）**：
每个面 deg(f) ≥ 4，故 Σ deg(f) ≥ 4F，即 2E ≥ 4F，得 F ≤ E/2

代入欧拉公式：
2 = V - E + F ≤ V - E + E/2 = V - E/2

即 4 ≤ 2V - E，故 **E ≤ 2V - 4**（对 V ≥ 3 的简单平面二分图）

检查 K_{3,3}：E = 9，2V - 4 = 12 - 4 = 8
但 9 > 8，矛盾！

故 **K_{3,3} 不是平面图**。∎

**Kuratowski 定理**：图是平面图当且仅当它不含与 K₅ 或 K_{3,3} 同胚的子图。
