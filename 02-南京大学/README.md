## 📖 学校简介

**南京大学（Nanjing University, NJU）**，简称"南大"，坐落于**江苏省南京市**，是：

- **985工程** / **211工程** / **双一流A类** 高校
- **C9联盟** 成员（九校联盟）
- 国家教育部直属的综合性全国重点大学
- 历史悠久，学科实力雄厚

南京大学计算机学科在国内处于领先地位，学科评估为 **A**，软件工程也是 **A**。

---

## 🏛️ 各学院区别

### 计算机学院

- 南京大学最传统的计算机学院，历史悠久
- 招生专业：计算机科学与技术（学硕）、计算机技术（专硕）
- 复试形式：**笔试（离散数学+编译原理）+ 上机编程 + 面试**
- 竞争激烈，分数线较高
- 师资力量雄厚，科研方向全面

### 智能软件与工程学院（软件工程学院）

- 专注于软件工程方向
- 招生专业：软件工程（专硕），2026年起从 **22408** 改为 **11408**（两年改三年）
- 招生人数相对较多，性价比高
- 复试形式：笔试 + 上机 + 面试

### 人工智能学院

- 较新成立的学院，专注于AI方向
- 2025年起专业课从自命题改为 **408统考**（重要改革）
- 招生专业：人工智能（学硕）、人工智能（专硕）
- 方向热门，竞争逐年加剧

## 💡 备考重点提示

1. **专业课改革**：人工智能学院2025年改考408，软件工程专硕2026年从英二数二改英一数一
2. **笔试科目**：离散数学和编译原理是计算机学院复试的核心，南大特别重视证明题
3. **上机编程**：难度中等，经典题型（N皇后、约瑟夫环、字符串处理等）
4. **面试准备**：专业知识、项目经历、英语能力都需要充分准备
