## 一、单项选择题

### 第1题

**题干**：设无向图 G 有 n 个顶点、e 条边，则其邻接矩阵中零元素的个数为（　　）。

A. n² - 2e  
B. n² - e  
C. n² + 2e  
D. n(n-1) - 2e  

**标准答案**：A

**详细解析**：
邻接矩阵是 n×n 的矩阵，总元素数为 n²。
在无向图的邻接矩阵中，每条边 (vᵢ, vⱼ) 对应两个 1（matrix[i][j] 和 matrix[j][i]），故非零元素数为 2e。
零元素数 = 总元素数 - 非零元素数 = n² - 2e。

注意：此结论假设图中无自环，且所有边的权值非零（或用 1/0 表示存在/不存在）。若考虑自环，则每个自环只贡献一个非零元素。

**出处标注**：2023年408统考第8题（改编）

### 第2题

**题干**：下列关于图的存储结构的叙述中，正确的是（　　）。

A. 邻接矩阵仅适用于稠密图  
B. 邻接表只能存储有向图  
C. 图的十字链表存储可以同时找到以某顶点为尾和为头的弧  
D. 用邻接矩阵存储图时，存储空间大小仅与顶点数有关，与边数无关  

**标准答案**：D

**详细解析**：
- A 错误：邻接矩阵也适用于稀疏图，只是空间效率较低。
- B 错误：邻接表既可存储有向图，也可存储无向图（每条无向边存储两次）。
- C 不完全：十字链表确实可以找到以某顶点为尾（出边）和为头（入边）的弧，但"同时找到"表述不够严谨，且 C 与 D 比较，D 更标准。
- D 正确：邻接矩阵存储空间为 O(n²)，仅与顶点数 n 有关，与实际边数无关。

**出处标注**：王道《数据结构考研复习指导》图的存储结构习题

### 第3题

**题干**：对于一个具有 n 个顶点和 e 条边的有向图，若采用邻接表存储，则所有顶点的出度之和为（　　），所有顶点的入度之和为（　　）。

A. n, e  
B. e, e  
C. e, n  
D. n+e, n-e  

**标准答案**：B

**详细解析**：
在有向图中，一条边从顶点 u 指向顶点 v，对 u 贡献一个出度，对 v 贡献一个入度。
因此所有顶点出度之和 = 边数 e；所有顶点入度之和 = 边数 e。
这两个值都等于有向图中弧的总数。

**出处标注**：天勤《数据结构高分笔记》图的基本概念章节

### 第4题

**题干**：对有 n 个顶点、e 条边且使用邻接表存储的图进行深度优先遍历（DFS），其时间复杂度为（　　）。

A. O(n)  
B. O(e)  
C. O(n+e)  
D. O(n²)  

**标准答案**：C

**详细解析**：
DFS 遍历需要访问每个顶点一次（O(n)），并检查每个顶点的所有邻接点。
在邻接表中，所有顶点的邻接点总数为 2e（无向图）或 e（有向图），因此边的处理时间为 O(e)。
总时间复杂度为 O(n+e)。

注意：若使用邻接矩阵存储，则 DFS 时间复杂度为 O(n²)，因为查找每个顶点的邻接点需要扫描一整行。

**出处标注**：2022年408统考第8题（改编）

### 第5题

**题干**：下列关于最小生成树的说法中，正确的是（　　）。

I.  最小生成树的代价（总权值）是唯一的  
II. 权值最小的边一定会出现在所有最小生成树中  
III. 用 Prim 算法从任意顶点出发得到的最小生成树相同  
IV.  用 Kruskal 算法得到的最小生成树中，边按权值从小到大顺序加入  

A. 仅 I、II  
B. 仅 I、IV  
C. 仅 II、III  
D. 仅 I、III、IV  

**标准答案**：B

**详细解析**：
- I 正确：一个图的最小生成树的总代价是唯一的（由最小权值边集保证），尽管生成树的形态可能不唯一。
- II 错误：如果有多条权值相同的最小边，它们之间存在选择关系，某一条最小边可能不在某个特定的最小生成树中。更准确地说，权值严格最小的边（唯一的最小值）一定在所有最小生成树中，但权值相等的多个最小边可能被替换。
- III 错误：从不同顶点出发，Prim 算法可能得到不同形态的最小生成树（尽管总代价相同）。
- IV 正确：Kruskal 算法的基本步骤就是将边按权值从小到大排序后依次加入（若不构成环）。

**出处标注**：2021年408统考第8题（改编）

### 第6题

**题干**：使用 Dijkstra 算法求解单源最短路径时，若图中存在权值为负的边，但不存在从源点可达的负权回路，则（　　）。

A. 算法一定能求得正确的最短路径  
B. 算法一定不能求得正确的最短路径  
C. 算法可能求得正确的最短路径，也可能不能  
D. 算法将陷入死循环  

**标准答案**：C

**详细解析**：
Dijkstra 算法的正确性依赖于"所有边权值非负"这一条件。当图中存在负权边时：
- 若从源点到某顶点的最短路径中间经过了负权边，算法可能在之前已将该顶点标记为"已找到最短路径"，而后续发现更短的路径时无法更新。
- 但若负权边不在任何从源点可达的路径上，或最短路径不经过负权边，则结果可能正确。

因此算法"可能"正确，也可能错误。要保证对含负权边的图能正确求解最短路径，应使用 Bellman-Ford 算法或 SPFA 算法。

**出处标注**：王道《数据结构考研复习指导》最短路径章节习题

### 第7题

**题干**：下列关于拓扑排序的说法中，错误的是（　　）。

A. 若有向图存在拓扑排序，则该图一定没有环  
B. 有向图的拓扑排序序列可能不唯一  
C. 若有向图的邻接矩阵是上三角矩阵，则一定存在拓扑排序  
D. 对有 n 个顶点的有向图进行拓扑排序，其时间复杂度一定是 O(n²)  

**标准答案**：D

**详细解析**：
- A 正确：有向图存在拓扑排序 ⟺ 图是 DAG（有向无环图）。
- B 正确：当图中有多个入度为 0 的顶点时，选择顺序不同可得到不同的拓扑序列。
- C 正确：上三角邻接矩阵意味着所有边都从小编号顶点指向大编号顶点（或相反），按顶点编号顺序输出即为一个拓扑排序。
- D 错误：采用邻接表存储时，拓扑排序（基于 BFS 的 Kahn 算法）的时间复杂度为 O(n+e)，不一定是 O(n²)。仅当使用邻接矩阵且每个顶点扫描整行时，才是 O(n²)。

**出处标注**：2020年408统考第8题（改编）

### 第8题

**题干**：设无向连通图 G 的所有顶点的度之和为 s，则 s 和 2e 的关系为（　　）（e 为边数）。

A. s = e  
B. s = 2e  
C. s = 2e+1  
D. 无法确定  

**标准答案**：B

**详细解析**：
在无向图中，每条边连接两个顶点，对这两个顶点各贡献一个度。
因此所有顶点度之和 = 边数 × 2，即 s = 2e。
这是图论中的握手定理。

**出处标注**：王道《数据结构考研复习指导》图的基本概念习题

### 第9题

**题干**：对有向图 G = (V, E)，若 V' ⊆ V，E' ⊆ E，且 G' = (V', E') 也是一个有向图，则 G' 是 G 的（　　）。

A. 连通分量  
B. 子图  
C. 生成子图  
D. 强连通分量  

**标准答案**：B

**详细解析**：
- 子图：顶点集和边集分别是原图的子集，且边集的端点都在顶点子集中。
- 生成子图：顶点集必须等于原图顶点集（V' = V），边集可以是任意子集。
- 连通分量：无向图的极大连通子图。
- 强连通分量：有向图的极大强连通子图。

题目中只说 V' ⊆ V, E' ⊆ E 且 G' 是图，没有要求 V' = V 或连通性，因此是子图。

**出处标注**：天勤《数据结构高分笔记》图的基本概念章节

### 第10题

**题干**：一个有 n 个顶点的连通无向图的生成树中，边的条数为（　　）。

A. n-1  
B. n  
C. n+1  
D. 2n  

**标准答案**：A

**详细解析**：
生成树是包含图中所有顶点的极小连通子图。
具有 n 个顶点的树有 n-1 条边（连通且无环的图是树，满足边数 = 顶点数 - 1）。
因此生成树的边数必为 n-1。

### 第11题

**题干**：下列关于 Prim 算法和 Kruskal 算法的说法中，正确的是（　　）。

A. Prim 算法仅适用于稠密图，Kruskal 算法仅适用于稀疏图  
B. Prim 算法的时间复杂度只与顶点数有关，Kruskal 算法的时间复杂度主要与边数有关  
C. Prim 算法和 Kruskal 算法都采用了贪心策略  
D. 以上都正确  

**标准答案**：D（或 C，视考试要求而定）

**详细解析**：
- A：Prim 算法在使用邻接矩阵时为 O(n²)，适合稠密图；使用堆实现的 Prim 为 O(e log n)。Kruskal 算法为 O(e log e)，适合稀疏图。
- B：使用邻接矩阵的 Prim 算法时间复杂度为 O(n²)（只与 n 有关）；Kruskal 主要时间在排序，为 O(e log e)。
- C：两者都是贪心算法——Prim 每次选距离当前集合最近的顶点；Kruskal 每次选择权值最小且不构成环的边。

综合来看，D 最全面。但严格来说，"仅适用于"在 A 中表述略显绝对（Prim 也可以用于稀疏图，只是效率不如 Kruskal）。多数教材将 C 视为核心正确答案。答题时建议选 C 或 D，取决于具体选项设置。

**出处标注**：王道《数据结构考研复习指导》最小生成树章节

### 第13题

**题干**：设有向图 G 如下图所示（顶点集合 V = {v₁, v₂, v₃, v₄, v₅}，边集合 E = {<v₁,v₂>, <v₁,v₃>, <v₂,v₄>, <v₃,v₂>, <v₃,v₅>, <v₄,v₃>, <v₅,v₁>, <v₅,v₄>}，边权值均为 1）。

(1) 画出该图的邻接矩阵和邻接表存储结构。  
(2) 从 v₁ 出发，给出深度优先遍历（DFS）的顶点访问序列（假设访问邻接点时按顶点编号从小到大顺序）。  
(3) 从 v₁ 出发，给出广度优先遍历（BFS）的顶点访问序列。  
(4) 给出该图的一个拓扑排序序列；若不存在，请说明理由。  

**标准答案**：

(1) **邻接矩阵**（顶点顺序 v₁, v₂, v₃, v₄, v₅）：

|     | v₁ | v₂ | v₃ | v₄ | v₅ |
|-----|----|----|----|----|----|
| v₁  | 0  | 1  | 1  | 0  | 0  |
| v₂  | 0  | 0  | 0  | 1  | 0  |
| v₃  | 0  | 1  | 0  | 0  | 1  |
| v₄  | 0  | 0  | 1  | 0  | 0  |
| v₅  | 1  | 0  | 0  | 1  | 0  |

**邻接表**（每个顶点的出边表按邻接点编号递增）：
- v₁ → v₂ → v₃
- v₂ → v₄
- v₃ → v₂ → v₅
- v₄ → v₃
- v₅ → v₁ → v₄

(2) **DFS 序列**（从 v₁ 出发，按编号优先访问）：
- v₁ → v₂ → v₄ → v₃ → v₅
- 过程：访问 v₁，选最小邻接点 v₂；访问 v₂，选邻接点 v₄；访问 v₄，选邻接点 v₃；访问 v₃，选邻接点 v₂（已访问），再选 v₅；访问 v₅，选邻接点 v₁（已访问），再选 v₄（已访问）。回溯完成。

(3) **BFS 序列**（从 v₁ 出发，按编号优先）：
- v₁ → v₂ → v₃ → v₄ → v₅
- 过程：v₁ 入队 → 出队 v₁，将其邻接点 v₂, v₃ 入队 → 出队 v₂，将其邻接点 v₄ 入队 → 出队 v₃，将其邻接点 v₂（已访问）、v₅ 入队 → 出队 v₄，将其邻接点 v₃（已访问）→ 出队 v₅，将其邻接点 v₁（已访问）、v₄（已访问）。队列为空，结束。

(4) **拓扑排序**：由于图中存在环（例如 v₁→v₂→v₄→v₃→v₅→v₁，或 v₃→v₂→v₄→v₃ 等），因此该图**不存在拓扑排序序列**。

**出处标注**：王道《数据结构考研复习指导》图的遍历与拓扑排序综合题（改编）

### 第14题

**题干**：给定带权有向图 G，顶点为 {A, B, C, D, E, F}，边及其权值如下：
- A→B: 4,  A→C: 2
- B→C: 1,  B→D: 5
- C→B: 1,  C→D: 8,  C→E: 10
- D→E: 2,  D→F: 6
- E→F: 3

(1) 使用 Dijkstra 算法求从顶点 A 到其他各顶点的最短路径。要求给出每一步辅助数组 dist 和 path 的变化过程。  
(2) 画出以 A 为源点的最短路径树。  
(3) 若将所有边的权值增加一个相同的正数 k，问从 A 到各顶点的最短路径是否可能改变？为什么？

**标准答案**：

**(1) Dijkstra 算法执行过程**：

初始化：S = {A}，dist = [0, 4, 2, ∞, ∞, ∞]，path = [-, A, A, -, -, -]

**第 1 步**：从 V-S 中选 dist 最小的顶点。dist[B]=4, dist[C]=2, 其他 ∞。选 C。
- S = {A, C}
- 以 C 为中间点更新：
  - A→C→B: dist[C]+w(C,B) = 2+1 = 3 < 4 → 更新 dist[B]=3, path[B]=C
  - A→C→D: 2+8 = 10 < ∞ → dist[D]=10, path[D]=C
  - A→C→E: 2+10 = 12 < ∞ → dist[E]=12, path[E]=C
- 当前 dist = [0, 3, 2, 10, 12, ∞]

**第 2 步**：从 V-S 选最小。dist[B]=3 最小。选 B。
- S = {A, C, B}
- 以 B 为中间点更新：
  - A→...→B→C: 3+1=4 > 2（不变）
  - A→...→B→D: 3+5=8 < 10 → dist[D]=8, path[D]=B
- 当前 dist = [0, 3, 2, 8, 12, ∞]

**第 3 步**：从 V-S 选最小。dist[D]=8 最小。选 D。
- S = {A, C, B, D}
- 以 D 为中间点更新：
  - A→...→D→E: 8+2=10 < 12 → dist[E]=10, path[E]=D
  - A→...→D→F: 8+6=14 < ∞ → dist[F]=14, path[F]=D
- 当前 dist = [0, 3, 2, 8, 10, 14]

**第 4 步**：从 V-S 选最小。dist[E]=10 最小。选 E。
- S = {A, C, B, D, E}
- 以 E 为中间点更新：
  - A→...→E→F: 10+3=13 < 14 → dist[F]=13, path[F]=E
- 当前 dist = [0, 3, 2, 8, 10, 13]

**第 5 步**：仅剩 F。选 F。
- S = {A, B, C, D, E, F}。更新检查：F 无出边（或出边指向已访问顶点）。
- 算法结束。

**最终结果**：

| 终点 | 最短路径 | 路径长度 |
|------|---------|---------|
| A    | -       | 0       |
| B    | A→C→B   | 3       |
| C    | A→C     | 2       |
| D    | A→C→B→D | 8       |
| E    | A→C→B→D→E | 10    |
| F    | A→C→B→D→E→F | 13 |

**(2) 最短路径树**（以 A 为根）：

```
      A
      |
      C
      |
      B
      |
      D
      |
      E
      |
      F
```

（以 path 数组回溯：F←E←D←B←C←A）

**(3) 当所有边权值增加相同正数 k 时，最短路径可能改变**。

原因：最短路径的选择不仅取决于路径总长度（各边权值之和），还与路径经过的边数有关。增加相同的 k 对所有路径的影响是：路径总长度增加 "k × 路径上边数"。边数较多的路径增加量更大。

举例：若存在两条从 A 到 F 的路径：
- 路径 1：经过 5 条边，原总长度 13
- 路径 2：经过 3 条边，原总长度 15

增加 k 后：
- 路径 1：13 + 5k
- 路径 2：15 + 3k

当 k > 1 时，路径 2 变得更短。因此最短路径可能改变。

**出处标注**：2022年408统考综合应用题（改编）

### 第15题

**题干**：设计一个算法，判断一个无向图 G（以邻接表存储）是否为一棵树。若是树，返回 1；否则返回 0。假设顶点编号为 0 ~ n-1。请给出算法思想、C 语言风格代码实现以及时间复杂度分析。

**标准答案**：

**算法核心思想**：
无向图是一棵树的充要条件是：
1. 图是连通的（从任意顶点出发可到达所有其他顶点）。
2. 图中有 n-1 条边（其中 n 为顶点数）。

等价地，可以验证条件为："连通且边数 = n-1"，或者 "连通且无环"，或者 "边数 = n-1 且无环"。

本算法采用："连通性检查（BFS 或 DFS） + 边数检查"。
此外，还可以在遍历过程中检测是否存在环（使用父结点记录法）。

**代码实现**（基于 BFS + 边数统计）：

```c
#define MAXV 100
typedef struct ArcNode {
    int adjvex;
    struct ArcNode *nextarc;
} ArcNode;

typedef struct VNode {
    int data;
    ArcNode *firstarc;
} VNode;

typedef struct {
    VNode vertices[MAXV];
    int vexnum, arcnum;  // 顶点数和边数
} ALGraph;

// 方式一：判断连通 + 边数 = n-1
int isTree1(ALGraph *G) {
    int n = G->vexnum;
    if (G->arcnum != n - 1) return 0;   // 边数条件
    
    // BFS 检查连通性
    int visited[MAXV] = {0};
    int queue[MAXV], front = 0, rear = 0;
    queue[rear++] = 0;  // 从顶点 0 出发
    visited[0] = 1;
    int count = 1;
    
    while (front < rear) {
        int v = queue[front++];
        ArcNode *p = G->vertices[v].firstarc;
        while (p) {
            if (!visited[p->adjvex]) {
                visited[p->adjvex] = 1;
                queue[rear++] = p->adjvex;
                count++;
            }
            p = p->nextarc;
        }
    }
    return count == n;  // 所有顶点都被访问说明连通
}

// 方式二：DFS 同时检测环
int dfsCheck(ALGraph *G, int v, int parent, int visited[], int *count) {
    visited[v] = 1;
    (*count)++;
    ArcNode *p = G->vertices[v].firstarc;
    while (p) {
        int w = p->adjvex;
        if (!visited[w]) {
            if (!dfsCheck(G, w, v, visited, count))
                return 0;
        } else if (w != parent) {
            return 0;  // 发现回边，存在环
        }
        p = p->nextarc;
    }
    return 1;
}

int isTree2(ALGraph *G) {
    int n = G->vexnum;
    int visited[MAXV] = {0};
    int count = 0;
    
    // 从顶点 0 开始 DFS，检查连通且无环
    if (!dfsCheck(G, 0, -1, visited, &count))
        return 0;
    
    // 确保没有孤立顶点（所有顶点都被访问）
    return count == n;
}
```

**时间复杂度分析**：
- 方式一（BFS + 边数检查）：O(n + e)，其中 n 为顶点数，e 为边数。BFS 遍历所有顶点和边一次。
- 方式二（DFS 判环 + 连通性）：O(n + e)，DFS 遍历所有顶点和边一次。

**空间复杂度**：O(n)，主要用于 visited 数组和递归工作栈或队列。

**正确性说明**：
- 方式一利用了"无向图是树 ⟺ 连通且边数 = n-1"这一性质。连通且有 n-1 条边的无向图必然无环。
- 方式二利用了"无向图是树 ⟺ 连通且无环"这一性质。在 DFS 过程中，若遇到一个已访问且非父结点的邻接点，则存在环。
