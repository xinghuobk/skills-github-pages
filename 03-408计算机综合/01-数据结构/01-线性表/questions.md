# 第01章 线性表

## 一、单项选择题

### 题1

**题干**：以下关于线性表的叙述中，正确的是（　　）。

A. 线性表的逻辑顺序与物理顺序总是一致的  
B. 线性表中每个元素都有前驱和后继  
C. 顺序表的存储密度小于链表的存储密度  
D. 在线性表的顺序存储结构中，可以随机访问任意元素

**答案**：D

**解析**：线性表的顺序存储结构（数组）支持 O(1) 的随机访问。A 选项顺序表逻辑顺序与物理顺序一致，但链表不一致；B 选项线性表的首元素无前驱、尾元素无后继；C 选项顺序表存储密度为 1，大于链表（链表需额外存储指针）。

**出处**：王道《数据结构》课后题改编

### 题2

**题干**：在长度为 n 的顺序表中删除第 i 个元素（1 ≤ i ≤ n），需要移动的元素个数为（　　）。

A. n - i  
B. n - i + 1  
C. i  
D. i - 1

**答案**：A

**解析**：删除第 i 个元素后，其后的元素（共 n - i 个）需要向前移动一位。平均情况下删除一个元素需移动约 n/2 个元素，时间复杂度 O(n)。

**出处**：2011年408真题改编

### 题3

**题干**：在长度为 n 的顺序表的第 i 个位置（1 ≤ i ≤ n+1）插入一个新元素，需要移动的元素个数为（　　）。

A. n - i  
B. n - i + 1  
C. i  
D. i - 1

**答案**：B

**解析**：在第 i 个位置插入元素时，原来第 i 到第 n 个元素（共 n - i + 1 个）都需要向后移动一位。

**出处**：王道《数据结构》同步练习

### 题4

**题干**：对于一个单链表，若要在 p 所指结点之后插入 s 所指结点，正确的操作序列是（　　）。

A. `p->next = s; s->next = p->next;`  
B. `s->next = p->next; p->next = s;`  
C. `s->next = p; p->next = s;`  
D. `p->next = s; p = s;`

**答案**：B

**解析**：先让 s 的 next 指向原 p 的后继，再让 p 的 next 指向 s。顺序不能颠倒，否则会丢失原链表其余部分。

**出处**：2012年408真题第2题

### 题5

**题干**：在一个具有 n 个结点的单链表中，已知指针 q 指向某结点，则在 q 所指结点之后插入一个新结点的时间复杂度是（　　）。

A. O(1)  
B. O(log₂n)  
C. O(n)  
D. O(n²)

**答案**：A

**解析**：已知 q 指针指向某结点时，在其之后插入只需修改两个指针，为 O(1)。但如改为在 q 之前插入，则必须从头找到 q 的前驱，时间复杂度为 O(n)。

**出处**：王道《数据结构》

### 题6

**题干**：设将 n(n>1) 个整数存放到一维数组 R 中。设计一个在时间和空间两方面都尽可能高效的算法，将 R 中保存的序列循环左移 p(0<p<n) 个位置。该算法的时间复杂度为（　　）。

A. O(n)  
B. O(n·p)  
C. O(n·log₂n)  
D. O(p)

**答案**：A

**解析**：经典三步翻转法：先将前 p 个元素逆转，再将剩余 n-p 个元素逆转，最后整体逆转。三次逆转共 O(n)。

**出处**：2010年408综合应用题第42题改编

### 题7

**题干**：设线性表 L = (a₁, a₂, a₃, …, aₙ) 采用带头结点的单链表存储，若要删除 L 中值为 x 的第一个结点（设该结点存在且不是尾结点），下列步骤中关键操作是（　　）。

A. 找到值为 x 的结点直接释放  
B. 找到值为 x 结点的前驱结点，修改其 next 指针  
C. 找到尾结点，修改其 next 指针  
D. 只需从首结点开始遍历一次

**答案**：B

**解析**：单链表删除结点必须先找到其前驱，否则无法断开与前驱的链接。删除关键步骤：`pre->next = p->next; free(p);`

**出处**：王道模拟卷

### 题8

**题干**：下列关于顺序表和链表的比较，错误的是（　　）。

A. 顺序表支持随机访问，链表支持顺序访问  
B. 顺序表的存储密度高，链表的存储密度低  
C. 顺序表按值查找的平均时间复杂度优于链表  
D. 在表的中间插入和删除操作，链表比顺序表更有优势

**答案**：C

**解析**：顺序表和链表的按值查找平均复杂度都是 O(n)。只有在有序表上用折半查找才能达到 O(log n)，而这与存储结构无关。

**出处**：王道《数据结构》

### 题9

**题干**：在一个长度为 n 的循环双链表中，删除最后一个结点并释放空间的操作所需的时间复杂度为（　　），若该链表仅设尾指针 rear。

A. O(1)  
B. O(n)  
C. O(log₂n)  
D. O(n²)

**答案**：A

**解析**：循环双链表设尾指针 rear 时，尾结点的前驱即为 `rear->prior`，其后继指向首结点，因此删除尾结点仅需修改 `rear->prior->next` 和首结点的 `prior`，时间复杂度为 O(1)。

**出处**：2015年408真题相关考点

### 题10

**题干**：若某线性表常用到的操作是「存取第 i 个元素及其前驱和后继的值」，则采用（　　）存储方式最节省时间。

A. 顺序表  
B. 单链表  
C. 双链表  
D. 循环单链表

**答案**：A

**解析**：顺序表随机访问第 i 个元素为 O(1)。虽然双链表访问前驱/后继方便，但访问第 i 个元素必须从表头遍历 O(n)，在"存取第 i 个元素"这一主要需求下顺序表最优。

**出处**：天勤《高分笔记》

### 题11

**题干**：已知一个带头结点的单链表，结点结构为 data + next。若想删除该链表的第一个数据结点，下列正确的操作序列是（　　）。（设 head 为头指针，p 为临时指针）

A. `p = head; head = head->next; free(p);`  
B. `p = head->next; head->next = p->next; free(p);`  
C. `p = head; free(p); head = head->next;`  
D. `p = head->next; free(p); head->next = p->next;`

**答案**：B

**解析**：带头结点时，第一个数据结点是 `head->next`。先让 p 指向它，然后断开它与链表的连接（头结点的 next 指向其下一个），最后释放 p。

**出处**：王道《数据结构》

### 题12

**题干**：在顺序表中查找元素 x，若采用顺序查找，设查找成功和失败的概率相等，且表中每个元素被查找的概率相等，则平均比较次数约为（　　）。（设表长为 n）

A. n  
B. n/2  
C. (n+1)/2  
D. (n+2)/2

**答案**：D

**解析**：查找成功时的平均比较次数为 (1+2+…+n)/n = (n+1)/2；查找失败时比较 n 次。题目条件下成功与失败概率相等（各占 1/2），平均比较次数 = (n+1)/2 × 1/2 + n × 1/2 ≈ (3n+1)/4。但如题目隐含只考虑查找成功情况，常见参考答案为 (n+1)/2。此题若仅考虑查找成功，答案为 C；若成功失败各占 1/2，则约为 (3n+1)/4。结合教材习惯，选 C 更常见。

**出处**：王道《数据结构》综合练习

### 题13

**题干**：设将 n(n>1) 个整数存放到一维数组 R 中。设计一个在时间和空间两方面都尽可能高效的算法，将 R 中保存的序列循环左移 p(0<p<n) 个位置，即将 R 中的数据由 (X₀, X₁, …, Xₙ₋₁) 变换为 (Xₚ, Xₚ₊₁, …, Xₙ₋₁, X₀, X₁, …, Xₚ₋₁)。

要求：
1. 给出算法的基本设计思想。
2. 根据设计思想，采用 C 或 C++ 语言描述算法，关键之处给出注释。
3. 说明所设计算法的时间复杂度和空间复杂度。

**答案**：

**1. 设计思想**：  
利用三次翻转（逆置）实现循环左移。步骤如下：
- 第一步：将前 p 个元素 (X₀, X₁, …, Xₚ₋₁) 逆置，得到 (Xₚ₋₁, …, X₀)。
- 第二步：将剩余 n-p 个元素 (Xₚ, …, Xₙ₋₁) 逆置，得到 (Xₙ₋₁, …, Xₚ)。
- 第三步：将整个数组 (Xₚ₋₁, …, X₀, Xₙ₋₁, …, Xₚ) 逆置，得到 (Xₚ, Xₚ₊₁, …, Xₙ₋₁, X₀, X₁, …, Xₚ₋₁)。

**2. C 语言实现**：

```c
#include <stdio.h>

// 将数组 R[low..high] 的元素逆置
void Reverse(int R[], int low, int high) {
    int temp, i;
    for (i = 0; i < (high - low + 1) / 2; i++) {
        temp = R[low + i];
        R[low + i] = R[high - i];
        R[high - i] = temp;
    }
}

// 循环左移 p 位
void LeftShift(int R[], int n, int p) {
    if (p > 0 && p < n) {
        Reverse(R, 0, p - 1);      // 逆置前 p 个元素
        Reverse(R, p, n - 1);      // 逆置后 n-p 个元素
        Reverse(R, 0, n - 1);      // 整体逆置
    }
}

int main() {
    int R[] = {1, 2, 3, 4, 5, 6, 7};
    int n = 7, p = 3;
    LeftShift(R, n, p);  // 结果应为 {4, 5, 6, 7, 1, 2, 3}
    for (int i = 0; i < n; i++) printf("%d ", R[i]);
    return 0;
}
```

**3. 复杂度分析**：三次 Reverse 操作总共对 n 个元素做了交换操作，时间复杂度 O(n)；仅使用常数个辅助变量，空间复杂度 O(1)。

**出处**：2010年408综合应用题第42题（原题）

### 题14

**题干**：一个长度为 L(L≥1) 的升序序列 S，处在第 ⌈L/2⌉ 个位置的数称为 S 的中位数。例如，若序列 S₁=(11, 13, 15, 17, 19)，则 S₁ 的中位数是 15。两个序列的中位数是含它们所有元素的升序序列的中位数。例如，若 S₂=(2, 4, 6, 8, 20)，则 S₁ 和 S₂ 的中位数是 11。现有两个等长升序序列 A 和 B，试设计一个在时间和空间两方面都尽可能高效的算法，找出两个序列 A 和 B 的中位数。

要求：
1. 给出算法的基本设计思想。
2. 根据设计思想，使用 C 或 C++ 语言描述算法，关键之处给出注释。
3. 说明你所设计算法的时间复杂度和空间复杂度。

**答案**：

**1. 设计思想**：  
采用"二分排除"策略。设 A、B 长度均为 n，分别取 a = A[mid_A]、b = B[mid_B]。若 a = b，则 a(或 b) 即为中位数；若 a < b，说明中位数不可能在 A 的前半段或 B 的后半段，分别抛弃这两段；若 a > b，相反。递归处理。

**2. C 语言实现**：

```c
int M_Search(int A[], int B[], int n) {
    int s1 = 0, d1 = n - 1, m1;   // A 的首、尾、中间点
    int s2 = 0, d2 = n - 1, m2;   // B 的首、尾、中间点
    while (s1 < d1) {
        m1 = (s1 + d1) / 2;
        m2 = (s2 + d2) / 2;
        if (A[m1] == B[m2]) return A[m1];
        if (A[m1] < B[m2]) {       // 舍弃 A 前半段、B 后半段
            if ((s1 + d1) % 2 == 0) { // 长度为奇数
                s1 = m1;
                d2 = m2;
            } else {                 // 长度为偶数
                s1 = m1 + 1;
                d2 = m2;
            }
        } else {                     // A[m1] > B[m2]
            if ((s1 + d1) % 2 == 0) {
                d1 = m1;
                s2 = m2;
            } else {
                d1 = m1;
                s2 = m2 + 1;
            }
        }
    }
    return A[s1] < B[s2] ? A[s1] : B[s2];
}
```

**3. 复杂度**：时间复杂度 O(log₂n)，空间复杂度 O(1)。

**出处**：2011年408综合应用题第41题（原题）

### 题15

**题干**：线性表 L = (a₁, a₂, …, aₙ) 采用带头结点的单链表存储，请设计算法：删除表中所有数据元素值为 x 的结点，并释放其空间，假设值为 x 的结点不唯一。

要求：
1. 给出算法基本设计思想。
2. 写出算法实现（C 语言风格）。
3. 分析时间复杂度。

**答案**：

**1. 设计思想**：  
设置工作指针 p 从首数据结点开始遍历，同时使用前驱指针 pre 跟随其后。当 p->data == x 时，断开 p 的链接：`pre->next = p->next; free(p); p = pre->next;`；否则 pre = p，p 继续前进。

**2. 代码实现**：

```c
typedef struct LNode {
    int data;
    struct LNode *next;
} LNode, *LinkList;

void Del_X_node(LinkList head, int x) {
    LNode *pre = head;      // pre 指向当前结点的前驱
    LNode *p = head->next;  // p 为工作指针
    while (p != NULL) {
        if (p->data == x) {
            pre->next = p->next;
            free(p);
            p = pre->next;
        } else {
            pre = p;
            p = p->next;
        }
    }
}
```

**3. 复杂度**：每个结点仅被扫描一次，时间复杂度 O(n)；仅使用常数辅助空间，空间复杂度 O(1)。

**出处**：王道《数据结构》综合练习

### 题16

**题干**：已知两个单链表 A 和 B，其中元素按值非递减排列（即升序且允许重复）。请设计一个算法将 A 和 B 归并为一个新的单链表 C，C 的元素仍按值非递减排列，并要求算法不额外开辟新结点空间，只利用 A、B 的原有结点。

要求：
1. 给出算法思想。
2. 写出算法实现。
3. 分析时间复杂度。

**答案**：

**1. 设计思想**：  
采用二路归并（类似归并排序的 merge）。设三个指针 pa、pb 分别指向 A、B 的当前数据结点，pc 指向 C 的当前尾结点。每次将 pa、pb 中较小者链接到 pc 之后，相应指针前进。若某一链先遍历完，则将另一链的剩余部分直接链接到 C 末尾。

**2. 代码实现**：

```c
typedef struct LNode {
    int data;
    struct LNode *next;
} LNode, *LinkList;

LinkList Merge(LinkList A, LinkList B) {
    // A、B 为带头结点的单链表
    LinkList C = A;                       // 复用 A 的头结点作为 C 的头结点
    LNode *pa = A->next, *pb = B->next;
    LNode *pc = C;                        // pc 始终指向 C 的尾结点
    pc->next = NULL;
    while (pa != NULL && pb != NULL) {
        if (pa->data <= pb->data) {
            pc->next = pa;
            pa = pa->next;
        } else {
            pc->next = pb;
            pb = pb->next;
        }
        pc = pc->next;
    }
    pc->next = (pa != NULL) ? pa : pb;    // 剩余部分直接接上
    free(B);                              // 释放 B 的头结点
    return C;
}
```

**3. 复杂度**：pa、pb 合起来遍历的结点总数为 len(A) + len(B)，时间复杂度 O(m + n)；未额外开辟新结点，空间复杂度 O(1)。

**出处**：王道模拟卷

### 题17

**题干**：设顺序表 L 中的数据元素为整数且递增有序，试写一算法，将 x 插入到 L 的适当位置上，以保持 L 的有序性。

要求：
1. 给出算法思想。
2. 写出算法实现（使用数组模拟顺序表）。
3. 分析时间复杂度。

**答案**：

**1. 设计思想**：  
从表尾向前遍历，凡是大于 x 的元素都向后移动一格，直到找到第一个小于等于 x 的元素的位置，将 x 插入其后。

**2. 代码实现**：

```c
#define MaxSize 100
typedef struct {
    int data[MaxSize];
    int length;
} SqList;

void InsertSorted(SqList *L, int x) {
    if (L->length >= MaxSize) return;  // 表满则退出
    int i;
    // 从后向前找，凡是大于 x 的元素后移
    for (i = L->length - 1; i >= 0 && L->data[i] > x; i--) {
        L->data[i + 1] = L->data[i];
    }
    L->data[i + 1] = x;
    L->length++;
}
```

**3. 复杂度**：最坏情况下（x 比所有元素小）需要移动全部 n 个元素，平均约移动 n/2 个元素，时间复杂度 O(n)，空间复杂度 O(1)。

**出处**：严蔚敏《数据结构》课后习题

### 题18

**题干**：已知线性表 (a₁, a₂, a₃, …, aₙ) 按顺序存储。请写一个算法将该线性表就地逆置，即利用原表的存储空间将线性表 (a₁, a₂, …, aₙ) 逆置为 (aₙ, aₙ₋₁, …, a₁)。

要求：
1. 给出算法思想。
2. 写出算法实现。
3. 分析复杂度。

**答案**：

**1. 设计思想**：  
设置两个指针，一个 low 指向首元素，一个 high 指向尾元素，交换两者指向的元素后 low++、high--，直到 low ≥ high。

**2. 代码实现**：

```c
void Reverse_Sq(SqList *L) {
    int i, temp;
    for (i = 0; i < L->length / 2; i++) {
        temp = L->data[i];
        L->data[i] = L->data[L->length - 1 - i];
        L->data[L->length - 1 - i] = temp;
    }
}
```

**3. 复杂度**：共进行 n/2 次交换，时间复杂度 O(n)；仅使用常数个辅助变量，空间复杂度 O(1)。

**出处**：严蔚敏《数据结构》例题

### 题19

**题干**：设有一个带头结点的单链表，结点的值均为整数，且按绝对值从小到大链接。试设计一个算法把该链表按值从小到大排序（即把负数放在前面，正数按升序放在后面）。

要求：
1. 算法思想。
2. 代码实现。
3. 复杂度分析。

**答案**：

**1. 设计思想**：  
链表已经按绝对值升序排列，遍历链表时：
- 正数和零保持在原位置不动；
- 负数使用头插法插入到头结点之后。

最终链表自然从小到大排列。

**2. 代码实现**：

```c
typedef struct LNode {
    int data;
    struct LNode *next;
} LNode, *LinkList;

void SortByValue(LinkList head) {
    LNode *pre = head;            // 前驱
    LNode *p = head->next;        // 工作指针
    LNode *q;                     // 临时
    while (p != NULL) {
        if (p->data < 0) {
            // 负数，从原位置摘下，头插到 head 之后
            q = p->next;          // 记录下一个
            pre->next = q;        // 断开
            p->next = head->next; // 头插
            head->next = p;
            p = q;                // 继续
        } else {
            pre = p;
            p = p->next;
        }
    }
}
```

**3. 复杂度**：只需一次遍历，时间复杂度 O(n)；仅使用常数个辅助指针，空间复杂度 O(1)。

**出处**：王道《数据结构》

### 题20

**题干**：设有一个循环单链表，其结点值为整数。设头指针为 head，指向表中某个元素值为 x 的结点的指针为 p。请给出：
(1) 在 p 所指结点之前插入一个新结点 s 的操作步骤。  
(2) 删除 p 所指结点的操作步骤。

**答案**：

(1) **在 p 之前插入 s**。由于是单链表，无法直接找到 p 的前驱，可采用"先在 p 之后插入 s，然后交换 s 和 p 中的数据值"的技巧：
```
s->next = p->next;
p->next = s;
swap(s->data, p->data);
```
时间复杂度 O(1)。

(2) **删除 p 所指结点**。同理：将 p 的后继结点的值拷入 p，再删除 p 的后继：
```
q = p->next;
p->data = q->data;
p->next = q->next;
free(q);
```
（注意：若 p 是表中唯一结点，需将 head 置为 NULL。）

**出处**：王道《数据结构》常考技巧题
