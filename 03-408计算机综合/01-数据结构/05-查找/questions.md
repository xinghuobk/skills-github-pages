## 一、单项选择题

### 第1题

**题干**：对有 n 个数据元素的顺序表进行顺序查找，在等概率情况下，查找成功时的平均查找长度为（　　）。

A. n  
B. n/2  
C. (n+1)/2  
D. (n-1)/2  

**标准答案**：C

**详细解析**：
顺序查找从第一个元素开始依次比较，直到找到目标或遍历结束。
对于第 i 个元素（i = 1, 2, ..., n），查找成功需要比较 i 次。
平均查找长度 ASL = Σ(概率 × 比较次数) = (1/n) × (1+2+...+n) = (1/n) × n(n+1)/2 = (n+1)/2。

**出处标注**：2023年408统考第10题（改编）

### 第2题

**题干**：对长度为 n 的有序表进行折半查找（二分查找），其时间复杂度为（　　），对应的判定树的高度为（　　）（设高度从1开始）。

A. O(n), ⌊log₂n⌋  
B. O(log₂n), ⌊log₂n⌋+1  
C. O(n log n), ⌈log₂(n+1)⌉  
D. O(log₂n), ⌈log₂(n+1)⌉  

**标准答案**：D

**详细解析**：
折半查找每次将查找范围缩小一半，最多比较 ⌈log₂(n+1)⌉ 次（对应判定树的高度）。
时间复杂度为 O(log₂n)。

折半查找的判定树是一棵平衡二叉树（所有叶子结点在同一层或相差不超过一层），其高度为 ⌈log₂(n+1)⌉（高度从1开始计数）。

**出处标注**：王道《数据结构考研复习指导》折半查找章节

### 第3题

**题干**：下列关于二叉排序树（BST）的说法中，正确的是（　　）。

A. 二叉排序树的中序遍历序列一定是有序的  
B. 在二叉排序树中插入一个新结点时，新结点一定成为某个叶子结点  
C. 对一棵二叉排序树进行层次遍历，所得到的结点序列一定是有序的  
D. 含有 n 个结点的二叉排序树的高度为 ⌊log₂n⌋  

**标准答案**：A

**详细解析**：
- A 正确：二叉排序树的定义决定了中序遍历（左→根→右）得到递增有序序列。
- B 错误：新插入的结点一定作为叶子结点插入（这是二叉排序树插入算法的性质），但不是"成为某个叶子结点"（它本身就是新的叶子）。这个表述有争议，但在考试中 B 通常被视为"新结点一定是叶子结点"而被认为正确。严谨分析：B 说"成为某个叶子结点"语义不清，准确应说"新结点一定作为叶子结点插入"。
- C 错误：层次遍历（BFS）按层输出，结果一般不是有序的。例如根 3，左孩子 1，右孩子 5，层次遍历序列为 {3, 1, 5}，不是递增有序。
- D 错误：只有平衡的二叉排序树（如 AVL）高度约为 O(log n)，普通 BST 最坏情况为单支树，高度为 n。

**出处标注**：2022年408统考第9题（改编）

### 第4题

**题干**：对关键字序列 {50, 30, 70, 20, 40, 60, 80} 按该顺序插入一棵初始为空的二叉排序树，下列关于该树的说法中，错误的是（　　）。

A. 根结点的值是 50  
B. 关键字 20 和 40 都是叶子结点  
C. 中序遍历序列为 {20, 30, 40, 50, 60, 70, 80}  
D. 删除关键字 50 后，新的根结点只能是 60  

**标准答案**：D

**详细解析**：

插入过程：
- 插入 50：根结点
- 插入 30：50 的左孩子
- 插入 70：50 的右孩子
- 插入 20：30 的左孩子
- 插入 40：30 的右孩子
- 插入 60：70 的左孩子
- 插入 80：70 的右孩子

树形：
```
       50
      /  \
     30   70
    /  \ /  \
   20  40 60 80
```

- A 正确：根是 50。
- B 正确：20 和 40 都没有子女。
- C 正确：中序遍历为递增有序序列。
- D 错误：删除根结点 50 时，可以用其左子树的最大值 40（或右子树的最小值 60）作为替代。因此新根不一定是 60，也可以是 40。

**出处标注**：王道《数据结构考研复习指导》二叉排序树习题

### 第5题

**题干**：在一棵平衡二叉树（AVL 树）中，每个结点的平衡因子的取值范围为（　　）。

A. 0 ~ 1  
B. -1 ~ 1  
C. -2 ~ 2  
D. 0 ~ 2  

**标准答案**：B

**详细解析**：
平衡因子 BF = 左子树高度 - 右子树高度。
AVL 树的定义是任意结点的平衡因子绝对值不超过 1，即 BF ∈ {-1, 0, 1}。

当插入或删除操作导致某个结点的 BF 变为 ±2 时，需要进行旋转调整（LL、RR、LR、RL 四种类型）。

**出处标注**：2021年408统考第9题

### 第6题

**题干**：设哈希（Hash）表的地址空间为 0 ~ m-1，关键字个数为 n，装填因子为 α，则 α 等于（　　）。

A. m × n  
B. n / m  
C. m / n  
D. n + m  

**标准答案**：B

**详细解析**：
装填因子 α = 表中记录数 / 哈希表长度 = n / m。
装填因子越大，表示哈希表越"拥挤"，发生冲突的概率越高。
哈希查找的平均查找长度一般与 α 有关（而与 n 无关），这是哈希查找的重要特点。

**出处标注**：王道《数据结构考研复习指导》哈希表章节

### 第7题

**题干**：使用链地址法解决哈希冲突时，下列关于平均查找长度的说法中，正确的是（　　）。

A. 装填因子 α 越大，平均查找长度越小  
B. 装填因子 α 越小，平均查找长度越小  
C. 平均查找长度与 α 无关  
D. 当 α > 1 时，哈希表无法工作  

**标准答案**：B

**详细解析**：
链地址法中，每个哈希地址维护一个链表来存放同义词（冲突的关键字）。
- 装填因子 α = n/m 越大，表示每个链表平均长度越长，查找时比较次数越多，平均查找长度越大。
- α 越小，链表越短，查找越快。但过小会浪费存储空间。

对于链地址法，成功查找的平均查找长度约为 1 + α/2，不成功查找约为 α（具体公式因教材而异，但与 α 正相关是共同结论）。

**出处标注**：天勤《数据结构高分笔记》哈希表章节

### 第8题

**题干**：采用线性探测法解决冲突时，可能会产生"二次聚集"（或称为堆积）现象，其主要原因是（　　）。

A. 哈希函数选择不当  
B. 解决冲突的方法导致相邻哈希地址上的记录互相影响  
C. 装填因子太小  
D. 关键字的分布不均匀  

**标准答案**：B

**详细解析**：
线性探测法的冲突处理公式为：Hᵢ(key) = (H(key) + i) % m，i = 0, 1, ..., m-1。

当一个哈希地址发生冲突时，后续关键字会被放置到紧邻的地址上。这意味着：
- 如果关键字不断地在同一区域发生冲突，它们会"堆积"在一起，形成很长的探测序列。
- 即使后续关键字的哈希地址不冲突，但它们被前面的堆积"堵住"，也被迫加入探测队列。

这种现象就是"二次聚集"（与哈希函数选择导致的"一次聚集"不同）。它使得平均查找长度显著增大。

二次探测（Hᵢ = (H(key) ± i²) % m）和再哈希法可以缓解二次聚集问题。

**出处标注**：王道《数据结构考研复习指导》哈希表冲突处理章节

### 第9题

**题干**：设有一组关键字 {19, 01, 13, 23, 56, 75, 37, 27, 08}，采用哈希函数 H(key) = key mod 11，采用线性探测法解决冲突，则关键字 37 需要探测（　　）次才能成功插入。

A. 2  
B. 3  
C. 4  
D. 5  

**标准答案**：B

**详细解析**：

哈希表地址空间：0 ~ 10。

逐个计算：
- H(19) = 19 mod 11 = 8 → 地址 8 空，直接放入。
- H(01) = 1 mod 11 = 1 → 地址 1 空，直接放入。
- H(13) = 13 mod 11 = 2 → 地址 2 空，直接放入。
- H(23) = 23 mod 11 = 1 → 地址 1 冲突。探测 (1+1)%11=2 → 冲突。探测 (1+2)%11=3 → 空，放入。
- H(56) = 56 mod 11 = 1 → 地址 1 冲突。探测 2 → 冲突。探测 3 → 冲突。探测 4 → 空，放入。
- H(75) = 75 mod 11 = 9 → 地址 9 空，直接放入。
- H(37) = 37 mod 11 = 4 → 地址 4 冲突（被 56 占用）。探测 5 → 空，放入。

对于 37：探测地址 4（第 1 次，冲突），地址 5（第 2 次，成功放入）。共探测 2 次地址比较，但"探测次数"的定义包括首次哈希也算一次探测。

重新按标准定义：对 37：
- 探测地址 4（冲突）：第 1 次探测
- 探测地址 5（成功）：第 2 次探测

但如果"探测次数"定义为比较的次数（包括首次哈希），则为 2 次。如果定义为冲突处理次数，则为 1 次。

在统考中，通常将"探测次数"理解为进行哈希地址比较的总次数（首次哈希 + 冲突探测）。对 37：首次探测地址 4（冲突，1 次），再探测地址 5（成功，2 次），共探测 2 次。答案应为 A。

但注意：某些教材定义探测次数仅为"发生冲突后重新探测的次数"，此时对 37 仅 1 次。这种情况答案不在选项中。

综合统考习惯，"探测次数"一般指探测的地址个数（含首次），37 的结果应为 2。

**修正答案**：A

**出处标注**：王道《数据结构考研复习指导》哈希表计算习题

### 第10题

**题干**：设顺序表中存放了 2000 个关键字，现要对其进行分块查找（索引顺序查找），平均查找长度最小的块大小约为（　　），此时的平均查找长度约为（　　）。

A. 20, 21  
B. 45, 46  
C. √2000, 2√2000  
D. 1000, 1001  

**标准答案**：B 或 C（取决于是否要求精确）

**详细解析**：
分块查找的平均查找长度 = 索引查找长度 + 块内查找长度。

设每块大小为 s，共 b = n/s 块。
- 若对索引和块内均采用顺序查找：ASL = (b+1)/2 + (s+1)/2 = (n/s + s)/2 + 1
  对 s 求导，令 ASL' = 0 得：-n/s² + 1 = 0，s = √n
  此时 ASL = √n + 1 ≈ √2000 + 1 ≈ 45 + 1 = 46

- 若对索引采用折半查找而块内顺序查找：ASL = ⌈log₂(b+1)⌉ + (s+1)/2

本题未说明索引查找方式，通常默认均为顺序查找。最优块大小为 √n ≈ 45，ASL ≈ 46。

选项 B 给出具体数值，选项 C 给出通式，两者都正确。

**标准答案**：B（具体数值）或 C（通式）

**出处标注**：王道《数据结构考研复习指导》分块查找章节

### 第11题

**题干**：在一棵 m 阶 B-树中，非根结点的关键字个数至少为（　　），最多为（　　）。

A. ⌈m/2⌉-1, m-1  
B. ⌈m/2⌉, m  
C. m/2, m  
D. ⌊m/2⌋, m-1  

**标准答案**：A

**详细解析**：
B-树是一种多路平衡查找树。m 阶 B-树的性质：
1. 每个结点至多有 m 棵子树，至多有 m-1 个关键字。
2. 根结点至少有 2 棵子树（若非叶子结点）。
3. 除根结点外的所有非叶结点至少有 ⌈m/2⌉ 棵子树，即至少有 ⌈m/2⌉-1 个关键字。
4. 所有叶子结点在同一层上。

因此：非根结点关键字个数范围是 [⌈m/2⌉-1, m-1]。

**出处标注**：2020年408统考第10题（改编）

### 第12题

**题干**：在一棵 3 阶 B-树中插入新关键字，可能引起的结点分裂次数最多为（　　）（设树的高度为 h，根为第 1 层）。

A. 1  
B. h-1  
C. h  
D. h+1  

**标准答案**：C

**详细解析**：
在 3 阶 B-树中，每个结点最多可以有 2 个关键字和 3 棵子树。

插入新关键字时，如果目标结点已经有 2 个关键字（满），则需要分裂：
- 将中间关键字上移到父结点，左右关键字各自成为新结点。
- 如果父结点在接受上移关键字后也变满（已有 2 个关键字），则父结点也要分裂。
- 分裂过程可以沿树向上传播，最多到达根结点。
- 当根结点分裂时，会产生新的根结点，此时树高增加 1。

最坏情况：新关键字的插入路径上每个结点都已满（各有 2 个关键字）。则从叶子到根的每一层都要分裂一次，共 h 次（包括根结点分裂）。

**出处标注**：王道《数据结构考研复习指导》B-树章节

## 二、综合应用题

### 第13题

**题干**：给定关键字序列 {55, 31, 11, 37, 46, 73, 63, 02, 07}，要求：

(1) 按顺序插入一棵初始为空的二叉排序树，画出插入完成后的二叉排序树。  
(2) 计算该二叉排序树在等概率下查找成功的平均查找长度。  
(3) 若对该序列先排序再依次插入空的二叉排序树，得到的树形态如何？求其平均查找长度。  
(4) 说明为什么同样的关键字集合会得到两棵不同的二叉排序树，并讨论其查找性能差异。  

**标准答案**：

**(1) 二叉排序树的构造**

逐个插入过程：
- 插入 55：空树 → 55 为根
- 插入 31：31 < 55 → 55 的左孩子
- 插入 11：11 < 55, 11 < 31 → 31 的左孩子
- 插入 37：37 < 55, 37 > 31 → 31 的右孩子
- 插入 46：46 < 55, 46 > 31, 46 > 37 → 37 的右孩子
- 插入 73：73 > 55 → 55 的右孩子
- 插入 63：63 > 55, 63 < 73 → 73 的左孩子
- 插入 02：02 < 55, 02 < 31, 02 < 11 → 11 的左孩子
- 插入 07：07 < 55, 07 < 31, 07 < 11, 07 > 02 → 11 的右孩子

最终树形：
```
         55
       /    \
      31     73
     /  \   /
    11  37 63
   /  \   \
  02  07  46
```

**(2) 查找成功的平均查找长度**

每个关键字查找成功时的比较次数 = 关键字所在层数（根在第 1 层）：
- 55：第 1 层，1 次比较
- 31：第 2 层，2 次比较
- 11：第 3 层，3 次比较
- 37：第 3 层，3 次比较
- 46：第 4 层，4 次比较
- 73：第 2 层，2 次比较
- 63：第 3 层，3 次比较
- 02：第 4 层，4 次比较
- 07：第 4 层，4 次比较

ASL = (1 + 2 + 3 + 3 + 4 + 2 + 3 + 4 + 4) / 9 = 27 / 9 = 3

**(3) 先排序后插入的情况**

排序后的序列：{02, 07, 11, 31, 37, 46, 55, 63, 73}

按顺序依次插入：
- 插入 02：根
- 插入 07：02 的右孩子
- 插入 11：02 → 07 的右孩子
- 插入 31：02 → 07 → 11 的右孩子
- 插入 37：02 → 07 → 11 → 31 的右孩子
- 插入 46：继续向右下延伸
- 插入 55：继续
- 插入 63：继续
- 插入 73：继续

得到的是一棵向右倾斜的单支树（退化的二叉树）：
```
02
  \
   07
     \
      11
        \
         31
           \
            37
              \
               46
                 \
                  55
                    \
                     63
                       \
                        73
```

平均查找长度：各关键字在第 1 ~ 9 层。
ASL = (1 + 2 + 3 + 4 + 5 + 6 + 7 + 8 + 9) / 9 = 45 / 9 = 5

**(4) 形态差异与性能分析**

二叉排序树的形态依赖于关键字的**插入顺序**：
- 原序列的插入顺序使得树的分布较为均衡，树高为 4。
- 排序后的序列递增插入，导致每个新关键字都大于当前树中的最大值，因此全部成为右链的延伸，树高为 9（即 n）。

性能差异：
- 均衡树的 ASL = 3，接近 O(log n)。
- 单支树的 ASL = 5，等于 O(n)，退化为顺序查找。

这说明二叉排序树的查找性能高度依赖于树的平衡性。为保证 O(log n) 的查找性能，需要使用平衡二叉树（如 AVL 树）或红黑树等结构。

**出处标注**：王道《数据结构考研复习指导》二叉排序树综合应用题（改编）

### 第14题

**题干**：设哈希表长度 m = 12，关键字序列为 {Jan, Feb, Mar, Apr, May, Jun, Jul, Aug, Sep}。哈希函数为 H(key) = i mod m，其中 i 为关键字 key 的首字母在字母表中的序号（A=1, B=2, ..., Z=26）。

(1) 采用线性探测法解决冲突，画出构造后的哈希表，并求等概率下查找成功和查找不成功的平均查找长度。  
(2) 采用链地址法解决冲突，画出构造后的哈希表，并求查找成功和查找不成功的平均查找长度。  
(3) 比较两种冲突处理方法的性能差异。  

**标准答案**：

**哈希函数计算**：各关键字首字母的序号和哈希值

| 关键字 | 首字母 | i（序号） | H(key) = i mod 12 |
|--------|--------|-----------|--------------------|
| Jan    | J      | 10        | 10                 |
| Feb    | F      | 6         | 6                  |
| Mar    | M      | 13        | 1                  |
| Apr    | A      | 1         | 1                  |
| May    | M      | 13        | 1                  |
| Jun    | J      | 10        | 10                 |
| Jul    | J      | 10        | 10                 |

| Sep    | S      | 19        | 7                  |

**(1) 线性探测法**

地址空间：0 ~ 11。

逐个插入（线性探测公式：Hᵢ = (H + i) % 12，i = 0, 1, ...）：

1. Jan：H=10 → 地址 10 空 → 放入。探测次数 = 1
2. Feb：H=6 → 地址 6 空 → 放入。探测次数 = 1
3. Mar：H=1 → 地址 1 空 → 放入。探测次数 = 1
4. Apr：H=1 → 地址 1 冲突。探测 (1+1)%12=2 → 空 → 放入。探测次数 = 2
5. May：H=1 → 地址 1 冲突。探测 2 → 冲突。探测 3 → 空 → 放入。探测次数 = 3
6. Jun：H=10 → 地址 10 冲突。探测 11 → 空 → 放入。探测次数 = 2
7. Jul：H=10 → 地址 10 冲突。探测 11 → 冲突。探测 0 → 空 → 放入。探测次数 = 3
8. Aug：H=1 → 地址 1 冲突。探测 2 → 冲突。探测 3 → 冲突。探测 4 → 空 → 放入。探测次数 = 4
9. Sep：H=7 → 地址 7 空 → 放入。探测次数 = 1

**查找不成功的 ASL**：
对每个可能的哈希地址，计算查找失败时的探测次数（探测到空位置为止）：
- 地址 0：探测 0 → 找到 Jul → 继续探测 1 → 找到 Mar → ... 实际应该探测到空位置。
  查找失败意味着目标不在表中。从每个地址出发，直到遇到空位才算失败：
  - 地址 0：Jul(0)→Mar(1)→Apr(2)→May(3)→Aug(4)→空(5)。5 次比较
  - 地址 1：Mar(1)→Apr(2)→May(3)→Aug(4)→空(5)。4 次比较
  - 地址 2：Apr(2)→May(3)→Aug(4)→空(5)。3 次比较
  - 地址 3：May(3)→Aug(4)→空(5)。2 次比较
  - 地址 4：Aug(4)→空(5)。1 次比较
  - 地址 5：空。1 次比较（首次探测即空）
  - 地址 6：Feb(6)→空(8)。2 次比较
  - 地址 7：Sep(7)→空(8)。1 次比较
  - 地址 8：空。1 次比较
  - 地址 9：空。1 次比较
  - 地址 10：Jan(10)→Jun(11)→Jul(0)→Mar(1)→... 注意：线性探测循环探测。
    Jan(10)→Jun(11)→Jul(0)→Mar(1)→Apr(2)→May(3)→Aug(4)→空(5)。8 次比较

**查找不成功的 ASL**：

- 地址 1：Mar(1), Apr(2), May(3), Aug(4), 空(5) = 5 次

- 地址 7：Sep(1), 空(2) = 2 次

- 地址 9：空指针 = 1 次
- 地址 10：Jan(1), Jun(2), Jul(3), 空(4) = 4 次
- 地址 11：空指针 = 1 次

按简化定义（空地址计 0，非空地址计链表长度）：
ASL(失败) = (0 + 4 + 0 + 0 + 0 + 0 + 1 + 1 + 0 + 0 + 3 + 0) / 12 = 9 / 12 = 0.75

按王道简化版（空地址 1 次，非空地址链表长度）：

### 第15题

**题干**：设计一个算法，判断一棵二叉树是否为二叉排序树（BST）。要求：

(1) 说明算法思想。  
(2) 写出 C 语言风格的代码实现（递归和非递归各一种）。  
(3) 分析算法的时间复杂度和空间复杂度。  

**标准答案**：

**(1) 算法思想**

核心思想：**二叉排序树的中序遍历序列是严格递增的**。

方法一（递归法）：
- 对树进行中序递归遍历。
- 用一个变量 pre 记录前驱结点的值。
- 每次访问一个结点时，检查其值是否大于 pre。
- 若发现当前值 ≤ pre，则不是 BST。
- 初始时 pre 设为极小值（如 INT_MIN）。

方法二（非递归法）：
- 用栈实现中序遍历。
- 每次从栈中弹出一个结点时，比较其与前驱的大小关系。
- 其余同方法一。

**(2) 代码实现**

```c
#include <stdio.h>
#include <stdlib.h>
#include <limits.h>

typedef struct BiTNode {
    int data;
    struct BiTNode *lchild, *rchild;
} BiTNode, *BiTree;

// ===== 方法一：递归 =====
int isBSTRecursive(BiTree T, int *prev) {
    if (T == NULL) return 1;              // 空树视为 BST
    if (!isBSTRecursive(T->lchild, prev)) // 检查左子树
        return 0;
    if (T->data <= *prev)                 // 当前结点应大于前驱
        return 0;
    *prev = T->data;                       // 更新前驱
    return isBSTRecursive(T->rchild, prev); // 检查右子树
}

int judgeBST1(BiTree T) {
    int prev = INT_MIN;
    return isBSTRecursive(T, &prev);
}

// ===== 方法二：非递归（栈实现） =====
#define MAXSIZE 100

int judgeBST2(BiTree T) {
    BiTree stack[MAXSIZE];
    int top = -1;
    int prev = INT_MIN;
    BiTree p = T;
    
    while (p != NULL || top != -1) {
        // 沿左子树向下，压栈
        while (p != NULL) {
            stack[++top] = p;
            p = p->lchild;
        }
        // 弹栈访问
        if (top != -1) {
            p = stack[top--];
            if (p->data <= prev)           // 检查是否大于前驱
                return 0;
            prev = p->data;
            p = p->rchild;                 // 转向右子树
        }
    }
    return 1;
}

// ===== 辅助函数：创建结点 =====
BiTree createNode(int val) {
    BiTree node = (BiTree)malloc(sizeof(BiTNode));
    node->data = val;
    node->lchild = node->rchild = NULL;
    return node;
}

// ===== 测试主函数 =====
int main() {
    // 构造一棵 BST：
    //        50
    //      /    \
    //     30    70
    //    /  \  /
    //   20  40 60
    BiTree root = createNode(50);
    root->lchild = createNode(30);
    root->rchild = createNode(70);
    root->lchild->lchild = createNode(20);
    root->lchild->rchild = createNode(40);
    root->rchild->lchild = createNode(60);
    
    printf("递归判断: %s\n", judgeBST1(root) ? "是BST" : "不是BST");
    printf("非递归判断: %s\n", judgeBST2(root) ? "是BST" : "不是BST");
    
    // 破坏 BST 性质：将 40 改为 60（此时 60 > 50 但在左子树）
    root->lchild->rchild->data = 60;
    printf("修改后递归判断: %s\n", judgeBST1(root) ? "是BST" : "不是BST");
    printf("修改后非递归判断: %s\n", judgeBST2(root) ? "是BST" : "不是BST");
    
    return 0;
}
```

**(3) 复杂度分析**

- **时间复杂度**：O(n)，其中 n 为结点数。每个结点被访问一次，每次访问的局部操作为 O(1)。
- **空间复杂度**：递归法为 O(h)，h 为树高（递归工作栈）。非递归法也为 O(h)（显式栈）。最坏情况（单支树）为 O(n)，平均情况为 O(log n)。

**正确性说明**：
- 中序遍历 BST 得到递增序列 ⟺ BST 性质成立。
- 若中序序列递增，则任意结点的值大于其左子树中所有结点值（因为它们在中序中都在该结点之前），且小于其右子树中所有结点值（它们在中序中都在该结点之后）。
