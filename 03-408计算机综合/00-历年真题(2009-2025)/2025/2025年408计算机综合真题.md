### 41. 二叉树与遍历（10分）

已知一棵二叉树的前序遍历序列为：ABDGCEF；中序遍历序列为：DGBAEC。

**(1)** 画出该二叉树；
**(2)** 写出该二叉树的后序遍历序列；
**(3)** 若采用链式存储结构，编写算法计算该二叉树的深度。

**【解答】**

解：(1) 由前序和中序遍历序列确定二叉树：
- 前序首元素A为根
- 中序中A左侧DG B为左子树，EC为右子树
- 递归构建...

(2) 后序遍历序列为：GDBE FCA

(3) 算法：
```c
int TreeDepth(BiTree T) {
    if (T == NULL) return 0;
    int leftDepth = TreeDepth(T->lchild);
    int rightDepth = TreeDepth(T->rchild);
    return (leftDepth > rightDepth) ? (leftDepth + 1) : (rightDepth + 1);
}
```

**【出处】** 2025年408统考第41题

### 44. Cache主存映射（10分）

某计算机Cache容量为4KB，采用直接映射方式，块大小为16B。

**(1)** 主存地址为24位，计算Cache地址格式（标记位数、组号位数、块内地址位数）；
**(2)** 计算Cache的总容量（不考虑维护位）；
**(3)** 若采用4路组相联映射，Cache的组数为多少？

**【解答】**

解：(1) 块内地址：$\log_2 16=4$位
    组号：Cache块数$=\frac{4KB}{16B}=256=2^8$组，8位
    标记：$24-4-8=12$位

(2) 每一块包含：16B数据+1位有效位+标记位12位=16B+13位
    总容量$=256\times(16B+13bit)=256\times129bit\approx 4.13KB$

(3) 4路组相联时，组数$=\frac{256}{4}=64=2^6$组

**【出处】** 2025年408统考第44题
