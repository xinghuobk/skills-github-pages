### 41. 循环链表操作（10分）

设有一个带头结点的循环链表L，结点类型为：
```c
typedef struct Node {
    ElemType data;
    struct Node *next;
} Node, *LinkList;
```

编写算法实现：
**(1)** 在循环链表L中查找值为x的结点；
**(2)** 在循环链表L尾部插入一个值为y的新结点。

**【解答】**

解：(1) 
```c
Node* FindNode(LinkList L, ElemType x) {
    Node *p = L->next;
    while (p != L) {
        if (p->data == x) return p;
        p = p->next;
    }
    return NULL;
}
```

(2)
```c
void InsertTail(LinkList L, ElemType y) {
    Node *p = L;
    while (p->next != L) p = p->next;
    Node *newNode = (Node*)malloc(sizeof(Node));
    newNode->data = y;
    newNode->next = L;
    p->next = newNode;
}
```

**【出处】** 2023年408统考第41题

### 46. 进程同步与互斥（10分）

三个进程P1、P2、P3共享一个缓冲区B，缓冲区容量为1。P1向缓冲区写入数据，P2从缓冲区读取数据，P3也读取数据（P2和P3不能同时读取）。

请使用信号量机制实现进程同步与互斥。

**【解答】**

解：设置信号量：
- mutex=1（互斥访问缓冲区）
- empty=1（缓冲区空标记）
- full=0（缓冲区满标记）
- readCount=0（读取计数，用于P2/P3互斥）

```c
// P1:
P(empty);
P(mutex);
// 写入数据
V(mutex);
V(full);

// P2:
P(full);
P(mutex);
readCount++;
if (readCount==1) P(readMutex);  // 第一个读者锁定
V(mutex);
// 读取数据
P(mutex);
readCount--;
if (readCount==0) V(readMutex);  // 最后一个读者解锁
V(mutex);
V(empty);
```

**【出处】** 2023年408统考第46题
