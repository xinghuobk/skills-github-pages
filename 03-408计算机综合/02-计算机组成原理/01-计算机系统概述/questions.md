## 一、单项选择题

### 第1题

**题干**：冯·诺依曼（Von Neumann）结构计算机的基本工作方式是（　　）。

A. 多指令流单数据流  
B. 按地址访问并顺序执行指令  
C. 堆栈操作  
D. 存储器按内容选择地址  

**标准答案**：B

**详细解析**：
冯·诺依曼体系结构的核心思想是"存储程序"：将程序（指令序列）和数据一起存放在存储器中，计算机工作时自动、顺序地从存储器中取出指令并执行。

主要特点：
1. 采用二进制表示指令和数据
2. 指令由操作码和地址码组成
3. 指令和数据存放在存储器中，按地址访问
4. 顺序执行指令（在无跳转情况下）

因此选 B。

**出处标注**：2023年408统考第12题（改编）

### 第2题

**题干**：下列关于计算机层次结构的说法中，错误的是（　　）。

A. 微程序机器级位于硬件与传统机器级之间  
B. 操作系统机器级位于汇编语言机器级之上  
C. 高级语言机器级通过编译程序翻译为汇编语言或机器语言  
D. 从不同层次观察计算机，可将其视为语言虚拟机或硬件机器  

**标准答案**：B

**详细解析**：
计算机系统的层次结构（从下往上）：

1. 第0级：硬联逻辑（硬件）
2. 第1级：微程序机器（微程序级）
3. 第2级：传统机器（机器语言级）
4. 第3级：操作系统机器
5. 第4级：汇编语言机器
6. 第5级：高级语言机器
7. 第6级：应用语言机器

操作系统机器级位于**传统机器之上、汇编语言机器之下**，即第3级。它向上提供汇编语言和高级语言可调用的系统功能。因此 B 错误。

**出处标注**：唐朔飞《计算机组成原理》计算机系统概述

### 第3题

**题干**：下列关于计算机性能指标的说法中，正确的是（　　）。

A. CPU 主频越高，运算速度越快  
B. 机器字长决定了运算精度  
C. 存储容量是指主存的容量  
D. MIPS 越大，运算速度越慢  

**标准答案**：B

**详细解析**：
- A 错误：主频只是影响 CPU 速度的因素之一，还需考虑 CPI（每条指令周期数）、指令系统等。不能简单说主频越高速度越快。
- B 正确：机器字长是指运算器一次能处理的二进制位数。字长越长，运算精度越高。
- C 错误：存储容量包括主存和辅存容量，通常主要指主存，但并不局限于主存。
- D 错误：MIPS（每秒百万条指令）越大，说明单位时间执行指令越多，运算速度越快。

**出处标注**：王道《计算机组成原理考研复习指导》性能指标章节

### 第4题

**题干**：某计算机的主存容量为 4GB，字长为 32 位，按字寻址时，其寻址范围为（　　）。

A. 0 ~ 2³²-1  
B. 0 ~ 2³⁰-1  
C. 0 ~ 2²⁸-1  
D. 0 ~ 2²⁹-1  

**标准答案**：B

**详细解析**：
主存容量 4GB = 4 × 1024³ = 2² × (2¹⁰)³ = 2³² Byte。

字长 32 位 = 4 Byte = 2² Byte，即一个字占 4 个字节。

按字寻址时，地址数 = 总字节数 / 每字字节数 = 2³² / 2² = 2³⁰。

寻址范围为 0 ~ 2³⁰-1，选 B。

**出处标注**：2022年408统考第13题（改编）

### 第5题

**题干**：某 CPU 的主频为 1.2GHz，平均每条指令执行需要 4 个时钟周期，则该 CPU 的运算速度约为（　　）。

A. 300 MIPS  
B. 4.8 MIPS  
C. 1.2 MIPS  
D. 4800 MIPS  

**标准答案**：A

**详细解析**：
MIPS（每秒百万条指令数）= 主频 / (CPI × 10⁶)

其中：
- 主频 = 1.2 GHz = 1.2 × 10⁹ Hz
- CPI（每条指令时钟周期数）= 4

MIPS = (1.2 × 10⁹) / (4 × 10⁶) = (1.2 × 10³) / 4 = 1200 / 4 = 300 MIPS

**出处标注**：王道《计算机组成原理考研复习指导》

### 第6题

**题干**：CPU 执行一段程序时，Cache 完成存取的次数为 3800 次，主存完成存取的次数为 200 次。Cache 存取周期为 50ns，主存存取周期为 200ns。则 Cache-主存系统的平均存取时间为（　　），效率约为（　　）。

A. 60ns  
B. 57.5ns  
C. 55ns  
D. 52.5ns  

**标准答案**：B

**详细解析**：
Cache 命中率 h = 3800 / (3800 + 200) = 3800 / 4000 = 0.95

平均存取时间 T = h × T_C + (1-h) × T_M
= 0.95 × 50 + 0.05 × 200
= 47.5 + 10
= 57.5 ns

效率 e = T_C / T = 50 / 57.5 ≈ 0.8696 ≈ 87%

**出处标注**：2021年408统考第14题（改编）

### 第7题

**题干**：计算机的硬件系统由五大部件组成，它们是（　　）。

A. 运算器、控制器、存储器、输入设备、输出设备  
B. ALU、CPU、存储器、I/O设备、总线  
C. 主机、外设、存储器、运算器、控制器  
D. CPU、主存、辅存、输入设备、输出设备  

**标准答案**：A

**详细解析**：
冯·诺依曼计算机由五大基本部件组成：
1. 运算器（ALU）：进行算术运算和逻辑运算
2. 控制器（CU）：控制程序的执行
3. 存储器（Memory）：存储程序和数据
4. 输入设备（Input）：将外部信息输入计算机
5. 输出设备（Output）：将计算结果输出

运算器和控制器合称为 CPU。CPU 和主存合称为主机。

**出处标注**：王道《计算机组成原理考研复习指导》

### 第8题

**题干**：下列描述中，正确的是（　　）。

A. 控制器能理解、解释并执行所有的指令及存储结果  
B. 一台计算机包括输入、输出、控制、存储及算术逻辑运算五个单元  
C. 所有的数据运算都在 CPU 的控制器中完成  
D. 以上答案都正确  

**标准答案**：B

**详细解析**：
- A 错误：控制器能理解和解释指令，但不直接存储结果；结果存储由存储器或寄存器完成。
- B 正确：符合冯·诺依曼五大部件描述。
- C 错误：数据运算在运算器（ALU）中完成，控制器负责控制而非运算。
- D 错误：A 和 C 均不正确。

**出处标注**：唐朔飞《计算机组成原理》第一章习题

### 第9题

**题干**：下列关于计算机字长的描述中，错误的是（　　）。

A. 字长是指运算器一次能处理的二进制数据的位数  
B. 字长通常是字节的整数倍  
C. 字长越长，运算精度越高，运算速度越快  
D. 字长与数据总线宽度无关  

**标准答案**：D

**详细解析**：
- A 正确：字长定义了运算器（ALU）一次能处理的二进制位数。
- B 正确：字长通常为 8、16、32、64 位等，都是字节（8 位）的整数倍。
- C 正确：字长越长，表示数值范围越大、精度越高；同时单次处理的数据量更大，有利于提高速度。
- D 错误：字长通常与数据总线宽度相等（或有对应关系）。数据总线一次能传输的数据位数决定了数据通路宽度，与字长密切相关。

**出处标注**：王道《计算机组成原理考研复习指导》

### 第10题

**题干**：某计算机字长为 16 位，下列数中不能用该字长准确表示的是（　　）。

A. 十进制整数 65535  
B. 十进制整数 -32767  
C. 十进制小数 0.1  
D. 十进制整数 -1  

**标准答案**：C

**详细解析**：
16 位字长下：
- 无符号整数范围：0 ~ 2¹⁶-1 = 0 ~ 65535，A 正确。
- 有符号整数（补码）范围：-2¹⁵ ~ 2¹⁵-1 = -32768 ~ 32767，B（-32767）和 D（-1）在此范围内。
- 对于小数 0.1，二进制表示为无限循环小数 0.0001100110011...，无论用定点还是浮点表示，都无法**准确**表示（只能近似）。

**出处标注**：王道《计算机组成原理考研复习指导》

### 第11题

**题干**：主机与外设之间的接口电路中，状态寄存器的作用是（　　）。

A. 保存 CPU 发送给外设的命令  
B. 保存外设当前的工作状态  
C. 保存 CPU 与外设之间交换的数据  
D. 识别外设的地址  

**标准答案**：B

**详细解析**：
I/O 接口中的寄存器分类：
1. **数据寄存器（Data Register）**：存放 CPU 与外设之间传输的数据（选项 C）。
2. **命令寄存器（Command Register）**：存放 CPU 发送给外设的命令（选项 A）。
3. **状态寄存器（Status Register）**：存放外设当前的工作状态（如"就绪"、"忙"、"错误"等），供 CPU 查询。

**出处标注**：王道《计算机组成原理考研复习指导》I/O接口章节

### 第12题

**题干**：下列说法中，正确的是（　　）。

A. 软件是由程序和文档组成的  
B. CPU 的 CPI 越小，执行速度越快  
C. 存取周期等于存取时间  
D. MIPS 适用于衡量向量机的速度  

**标准答案**：B

**详细解析**：
- A 错误：软件 = 程序 + 数据 + 文档，选项缺少数据。
- B 正确：CPI（Cycles Per Instruction，每条指令所需时钟周期数）越小，平均执行一条指令所需时间越短。MIPS = 主频 / CPI，CPI 越小，MIPS 越大，速度越快。
- C 错误：存取时间是指从启动一次存储器操作到完成该操作的时间；存取周期是指连续两次独立存储器操作之间所需的最小时间间隔。通常存取周期 ≥ 存取时间。
- D 错误：MIPS 适用于衡量标量机的速度，对于向量机（有向量指令），通常用 MFLOPS（每秒百万次浮点运算）来衡量。

**出处标注**：唐朔飞《计算机组成原理》计算机性能指标

### 第13题

**题干**：设有两个浮点数 X = 2⁰¹⁰ × 0.110100，Y = 2¹⁰⁰ × (-0.101010)。阶码 4 位（含 1 位符号位），尾数 8 位（含 1 位符号位）。按浮点运算步骤计算 X + Y。

**标准答案**：

**浮点加法步骤**：

设阶码为补码，尾数为原码/补码。

X = 2⁰¹⁰ × 0.110100  
Y = 2¹⁰⁰ × (-0.101010)

**(1) 对阶**：

ΔE = E_X - E_Y = 010 - 100 = 010 - 100 = -2（十进制 -2）

|ΔE| = 2，X 的阶码小，所以 X 的尾数右移 2 位，阶码加 2。

X 尾数原码：0.110100 → 右移 2 位 → 0.001101（末位按 0 舍 1 入规则处理）
X 新阶码：010 + 2 = 100

即 X' = 2¹⁰⁰ × 0.001101

**(2) 尾数求和**：

将 X 尾数与 Y 尾数相加（Y 的尾数为 -0.101010）：

M_X = 0.001101  
M_Y = -0.101010

M = M_X + M_Y = 0.001101 + (-0.101010) = -0.011101

（用补码计算：
M_X 补 = 0.001101
M_Y 补 = 1.010110（-0.101010 的补码）
和 = 0.001101 + 1.010110 = 1.100011（补码）
转换为原码：-0.011101）

**(3) 规格化**：

尾数 M = -0.011101，为非规格化数（绝对值小于 0.1）。

需要左移 1 位：M = -0.111010
阶码减 1：E = 100 - 1 = 011

规格化结果：X + Y = 2⁰¹¹ × (-0.111010)

**(4) 舍入**：尾数为 6 位（不含符号位），已达到精度，无需舍入。

**(5) 溢出判断**：阶码 011，在 4 位阶码表示范围内（-8 ~ +7），无溢出。

最终结果：X + Y = 2⁰¹¹ × (-0.111010)

**出处标注**：王道《计算机组成原理考研复习指导》浮点数运算综合题

### 第14题

**题干**：某计算机的 CPU 主频为 500MHz，CPI 为 5。

(1) 求该 CPU 的 MIPS。  
(2) 若 CPU 主频提高到 1GHz，要求 MIPS 提高到原来的 1.5 倍，求新的 CPI。  
(3) 若在某应用中，有 40% 的指令为算术运算类（CPI=3），30% 为访存类（CPI=6），20% 为分支类（CPI=4），10% 为其他类（CPI=2），求该机的平均 CPI 和 MIPS。  

**标准答案**：

**(1) 计算 MIPS**：

MIPS = 主频 / (CPI × 10⁶)  
     = 500 × 10⁶ / (5 × 10⁶)  
     = 100 MIPS

**(2) 求新 CPI**：

要求 MIPS 提高到 1.5 倍，即新 MIPS = 100 × 1.5 = 150 MIPS。

新主频 = 1GHz = 1000 MHz。

由 MIPS = 主频 / (CPI × 10⁶)：

150 = 1000 / (CPI_new × 1)  
CPI_new = 1000 / 150 = 6.67

**(3) 加权平均 CPI 和 MIPS**：

CPI = Σ(各类指令比例 × 各类指令 CPI)
    = 0.4 × 3 + 0.3 × 6 + 0.2 × 4 + 0.1 × 2
    = 1.2 + 1.8 + 0.8 + 0.2
    = 4.0

MIPS = 主频 / (CPI × 10⁶) = 500 / 4 = 125 MIPS

**出处标注**：王道《计算机组成原理考研复习指导》

### 第15题

**题干**：某程序在一台时钟频率为 2GHz 的计算机上运行需要 10 秒。

(1) 求该程序执行的时钟周期数。  
(2) 若通过硬件优化，将该程序中占总执行时间 60% 的指令段的 CPI 从原来的 5 降至 3，其他部分不变，求优化后程序的总执行时间。  
(3) 若通过编译器优化，将该程序中的指令数减少了 20%，但每条指令的 CPI 增加了 10%，求优化后程序的执行时间。  

**标准答案**：

**(1) 时钟周期数**：

时钟周期数 = 执行时间 × 时钟频率
            = 10 s × 2 × 10⁹ Hz
            = 2 × 10¹⁰ cycles

**(2) 硬件优化后的执行时间**：

设原总 CPI 平均为 C，原指令数为 N。

原执行时间 t = N × C × T = 10 s，其中 T = 1 / (2 × 10⁹)。

优化部分：
- 占总时间 60%，即原这部分用时 6 s。
- 原 CPI₁ = 5，新 CPI₁' = 3。
- 这部分执行时间变为原来的 3/5 = 0.6 倍，即 6 × 0.6 = 3.6 s。

未优化部分：
- 占总时间 40%，用时 4 s，不变。

优化后总时间 = 3.6 + 4 = 7.6 s。

**(3) 编译器优化后的执行时间**：

设原指令数为 N，原平均 CPI 为 C。

优化后：
- 新指令数 N' = N × (1 - 0.2) = 0.8N
- 新 CPI C' = C × (1 + 0.1) = 1.1C

原执行时间 t = N × C × T = 10 s
新执行时间 t' = N' × C' × T = 0.8N × 1.1C × T = 0.88 × (N × C × T) = 0.88 × 10 = 8.8 s

**出处标注**：王道《计算机组成原理考研复习指导》CPU性能综合题
