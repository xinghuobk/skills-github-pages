## 一、单项选择题

### 第1题

**题干**：计算机的存储器采用分级存储体系（多级存储）的主要目的是（　　）。

A. 便于读写数据  
B. 减小机箱的体积  
C. 便于系统升级  
D. 解决存储容量、存取速度和价格之间的矛盾  

**标准答案**：D

**详细解析**：
存储器分级存储体系通常包括：寄存器 → Cache → 主存 → 磁盘 → 光盘/磁带。

从上层到下层：
- 存储容量越来越大
- 存取速度越来越慢
- 每位价格越来越便宜

分级存储通过"数据局部性原理"（时间局部性和空间局部性），将常用数据放在上层高速存储，实现**接近上层的速度、接近下层的容量和价格**的综合效果。

**出处标注**：2023年408统考第15题（改编）

### 第2题

**题干**：某计算机字长为 32 位，其存储容量为 4MB，若按半字编址，其寻址范围为（　　）。

A. 0 ~ 4M-1  
B. 0 ~ 2M-1  
C. 0 ~ 1M-1  
D. 0 ~ 512K-1  

**标准答案**：B

**详细解析**：
1 MB = 2²⁰ 字节
4 MB = 4 × 2²⁰ = 2²² 字节

字长 32 位 = 4 字节
半字 = 2 字节

地址数 = 总字节数 / 半字字节数 = 2²² / 2 = 2²¹ = 2,097,152 = 2M

寻址范围：0 ~ 2M-1

**出处标注**：王道《计算机组成原理考研复习指导》

### 第3题

**题干**：某 SRAM 芯片，其存储容量为 64K × 16 位，该芯片的地址线和数据线数目分别为（　　）。

A. 64, 16  
B. 16, 64  
C. 16, 16  
D. 64K, 16  

**标准答案**：C

**详细解析**：
存储容量为 64K × 16 位。
- 64K = 2⁶ × 2¹⁰ = 2¹⁶，因此需要 16 位地址线寻址。
- 数据线 16 位（每个地址单元存储 16 位数据）。

**出处标注**：王道《计算机组成原理考研复习指导》

### 第4题

**题干**：某 DRAM 芯片，其存储容量为 512K × 8 位，该芯片的地址线和读写控制线数目分别为（　　）。

A. 19, 1  
B. 512K, 8  
C. 19, 8  
D. 9, 1  

**标准答案**：A 或 D

**详细解析**：
512K × 8 位：
- 512K = 2⁹ × 2¹⁰ = 2¹⁹，因此需要 19 位地址线（或者分两次送：行地址 9 位 + 列地址 10 位，共 19 位）。
- 数据线 8 位。
- 读写控制线：通常只需 1 条（WE# 或 R/W#）区分读和写。

选项 A（19, 1）表示地址线 19 条、控制线 1 条。

注意：DRAM 地址常分行/列地址两次送出，所以外部引脚地址线可能只有 10 条（或 9 条）。但从"地址线总数"角度，应选 19。

**标准答案**：A（19 位地址线，1 条读写控制线）

**出处标注**：王道《计算机组成原理考研复习指导》

### 第5题

**题干**：下列关于 Cache 的说法中，正确的是（　　）。

A. Cache 的容量越大，命中率越高，但超过一定限度后命中率提升缓慢  
B. Cache 存储的是主存中全部数据的副本  
C. Cache 对应用程序员是可见的  
D. Cache 与主存的地址映射由操作系统完成  

**标准答案**：A

**详细解析**：
- A 正确：命中率随容量增大而提高，但存在"边际收益递减"效应。典型容量下，如从 32KB 增大到 64KB 可能使命中率从 90% 提升到 95%，但从 1MB 增大到 2MB 可能只从 99% 提升到 99.5%。
- B 错误：Cache 只是主存中少量数据的副本（通常只有几 KB 到几 MB），远小于主存容量。
- C 错误：Cache 对应用程序员透明，由硬件自动管理。
- D 错误：地址映射完全由硬件（Cache 控制器）完成，与操作系统无关。

**出处标注**：王道《计算机组成原理考研复习指导》

### 第6题

**题干**：某 Cache 容量为 64KB，每块大小为 16B，主存容量为 4MB。若采用直接映射方式，则主存地址格式为（　　）（假设地址从高位到低位分为：Tag、Cache 行号、块内偏移）。

A. Tag(6位), Cache行号(12位), 块内偏移(4位)  
B. Tag(14位), Cache行号(12位), 块内偏移(6位)  
C. Tag(8位), Cache行号(14位), 块内偏移(4位)  
D. Tag(6位), Cache行号(10位), 块内偏移(6位)  

**标准答案**：A

**详细解析**：
主存地址 = 4MB = 2²² 字节，地址共 22 位。

块大小 = 16B = 2⁴，块内偏移 = 4 位（低位）。

Cache 行数 = Cache 容量 / 块大小 = 64KB / 16B = 4K = 2¹²，Cache 行号 = 12 位。

Tag（标记）= 总地址位数 - 行号位数 - 块内偏移位数 = 22 - 12 - 4 = 6 位。

因此主存地址格式：Tag(6位) + 行号(12位) + 块内偏移(4位)。

**出处标注**：2022年408统考第14题（改编）

### 第7题

**题干**：在 Cache 和主存构成的两级存储体系中，Cache 的存取时间是 100ns，主存的存取时间是 1000ns。如果要求平均存取时间不超过 190ns，则 Cache 的命中率至少应为（　　）。

A. 90%  
B. 95%  
C. 97%  
D. 99%  

**标准答案**：A

**详细解析**：
平均存取时间 T = h × T_C + (1-h) × T_M
其中 h 为命中率，T_C 为 Cache 存取时间，T_M 为主存存取时间。

注意：题目未说明是否"同时访问 Cache 和主存"还是"先查 Cache 不命中再访问主存"。按默认（先查 Cache，未命中再访问主存）：

T = h × 100 + (1-h) × (100 + 1000) = 100h + 1100(1-h) = 1100 - 1000h

要求 T ≤ 190ns：
1100 - 1000h ≤ 190
1000h ≥ 910
h ≥ 0.91 = 91%

若按"同时访问 Cache 和主存"（命中率命中则取 Cache，否则取主存）：
T = h × 100 + (1-h) × 1000 = 1000 - 900h ≤ 190
900h ≥ 810
h ≥ 0.9 = 90%

选项中最低的是 90%（A）。按"同时访问"模型选 A 即可。

**出处标注**：王道《计算机组成原理考研复习指导》

### 第8题

**题干**：某 32 位计算机的 Cache 采用 2 路组相联映射方式（LRU 替换策略）。已知 Cache 数据容量为 64KB，块大小为 32B。则 Cache 中容纳的行数（组数 × 每组行数）和 LRU 所需的位数分别为（　　）。

A. 1024行, 1024位  
B. 2048行, 1024位  
C. 2048行, 2048位  
D. 1024行, 10位  

**标准答案**：A

**详细解析**：
Cache 数据容量 = 64KB
块大小 = 32B
Cache 总行数 = 64KB / 32B = 2K = 2048

但采用 2 路组相联：每组 2 行。
组数 = 2048 / 2 = 1024 组。

注意：题目问"Cache中容纳的行数"——总行数 = 2048 行。

但再看选项，A 是 1024 行（可能问的是组数）。重新读题：

题目："Cache中容纳的行数（组数 × 每组行数）"
行数 = 组数 × 每组行数 = 1024 × 2 = 2048 行。

但选项 A 为 1024 行。可能题目中"行数"实际指数。

重新理解：Cache 行数 = 64KB / 32B = 2048 行（即 2¹¹ 行）。
采用 2 路组相联，即每组 2 行，共 1024 组。

题目"Cache中容纳的行数"：总行数 = 2048。
但选项 A = 1024。

再次读题：可能题目"行数"指数 = 1024（即组数），此时选 A。

LRU 位数：每组需 1 位 LRU（2 路组相联中，1 位 LRU 表示哪行更旧）。
共 1024 组，需要 1024 位 LRU。

所以选 A（1024 行（组）, 1024 位）。

注意：严格理解的话，答案应为 Cache 2048 行，LRU 1024 位，无此选项。可能题目表述中"行数"指"组数"。

**标准答案**：A（Cache 总行数 2048，但选项 A 对应组数 1024 和 LRU 1024 位）

**出处标注**：王道《计算机组成原理考研复习指导》组相联Cache

### 第9题

**题干**：在 Cache 的地址映射中，若主存中任意一块只能映射到 Cache 中唯一的某一行上，则这种映射方式称为（　　）。

A. 直接映射  
B. 全相联映射  
C. 组相联映射  
D. 混合映射  

**标准答案**：A

**详细解析**：
- **直接映射**：主存块 i 只能映射到 Cache 行 i mod C（C 为 Cache 总块数）。是一种"一对多"的映射（多块对一行）。
- **全相联映射**：主存任意一块可以映射到 Cache 任意一行。是"多对多"的映射。
- **组相联映射**：主存块 i 只能映射到 Cache 组 i mod G（G 为组数）中的任意一行。是两者的折中。

题目描述"只能映射到唯一的某一行"，符合直接映射的特征。

**出处标注**：王道《计算机组成原理考研复习指导》

### 第10题

**题干**：虚拟存储系统中，页表的作用是实现（　　）。

A. 从物理地址到逻辑地址的转换  
B. 从逻辑地址到物理地址的转换  
C. 从主存到 Cache 的地址映射  
D. 主存和辅存之间的数据交换  

**标准答案**：B

**详细解析**：
虚拟存储系统中，CPU 发出的是逻辑地址（虚拟地址），需要通过页表（Page Table）查找到对应的物理页框号，再拼接页内偏移得到物理地址。

- 逻辑地址 = 页号 | 页内偏移
- 页表中[页号] → 物理页框号
- 物理地址 = 物理页框号 | 页内偏移

选项 A 是反向映射（通常不需要）；选项 C 是 Cache 的映射；选项 D 是缺页处理的功能之一。

**出处标注**：王道《计算机组成原理考研复习指导》虚拟存储

### 第11题

**题干**：一个虚拟存储系统中，设主存容量为 256MB，Cache 容量为 2MB，辅存（磁盘）容量为 8GB，虚拟地址为 32 位，页大小为 4KB。则虚拟地址空间大小和最大物理地址空间分别为（　　）。

A. 4GB, 256MB  
B. 4GB, 8GB  
C. 256MB, 4GB  
D. 8GB, 256MB  

**标准答案**：A

**详细解析**：
虚拟地址 32 位 → 虚拟地址空间 = 2³² = 4GB

主存容量决定了物理地址空间（实际可访问的物理内存）：256MB

辅存容量（8GB）决定了虚拟存储系统可支持的最大虚拟存储，但虚拟地址位数（32 位）限制了虚拟地址空间为 4GB。

注意：虚拟地址空间大小由虚拟地址位数决定（这里 32 位 = 4GB），而不是由辅存容量决定。最大物理地址空间由主存容量决定（这里 256MB）。

**出处标注**：2021年408统考第15题（改编）

### 第12题

**题干**：磁盘的平均存取时间由（　　）组成。

A. 平均寻道时间 + 平均等待时间 + 传输时间  
B. 平均寻道时间 + 旋转延迟  
C. 平均等待时间 + 传输时间  
D. 寻道时间 + 传输时间  

**标准答案**：A

**详细解析**：
磁盘存取（访问）过程：
1. **寻道时间**（Seek Time）：磁头从当前位置移动到目标磁道所需时间。
2. **旋转延迟/等待时间**（Rotational Latency）：磁盘旋转到目标扇区到达磁头下方所需时间。平均为磁盘旋转半周时间。
3. **传输时间**（Transfer Time）：数据实际写入或读出的时间。

**平均存取时间 = 平均寻道时间 + 平均等待时间 + 传输时间**

有时也简化为"寻道时间 + 旋转延迟"（忽略传输时间，或认为传输时间已含在等待时间中）。完整答案应为 A。

**出处标注**：王道《计算机组成原理考研复习指导》磁盘存储

## 二、综合应用题

### 第13题

**题干**：某计算机主存按字节寻址，主存容量为 64KB。Cache 容量为 2KB，每块大小为 32B，采用直接映射方式。

(1) 写出主存地址格式（Tag、Cache行号、块内偏移各占几位）。  
(2) 写出主存地址 2345H（十六进制）的 Tag、Cache行号和块内偏移值。  
(3) 若 Cache 初始为空，CPU 依次读取主存地址 0, 1, 2, ..., 99（十进制）的字节数据，则 Cache 的命中率为多少？  
(4) 若将上述 Cache 改为 2 路组相联映射，其他条件不变，重新分析 (1) 和 (2)。  

**标准答案**：

**(1) 主存地址格式（直接映射）**

主存容量 = 64KB = 2¹⁶ 字节 → 地址 16 位。
Cache 容量 = 2KB = 2¹¹ 字节。
块大小 = 32B = 2⁵ → 块内偏移 = 5 位。
Cache 行数 = 2KB / 32B = 64 = 2⁶ → 行号 = 6 位。
Tag = 16 - 6 - 5 = 5 位。

地址格式：
```
Tag(5位) | 行号(6位) | 块内偏移(5位)
[15..11] |  [10..5]  |    [4..0]
```

**(2) 地址 2345H 分析**

2345H = 0010 0011 0100 0101B

按位拆分：
Tag（高 5 位） = 00100B = 4（十进制）
行号（中间 6 位） = 110100B = 52（十进制）
块内偏移（低 5 位） = 101B = 5（十进制）

**(3) Cache 命中率计算**

Cache 初始为空，CPU 依次读取 0 ~ 99（共 100 个字节）。

每个块 32B，所以访问地址：
- 0 ~ 31：在第 0 块，访问第 0 个地址时不命中（调入），1~31 均命中。
  共 32 次访问，1 次不命中，31 次命中。
- 32 ~ 63：在第 1 块，同样首次不命中。
  共 32 次访问，1 次不命中，31 次命中。
- 64 ~ 95：在第 2 块。
  共 32 次访问，1 次不命中，31 次命中。
- 96 ~ 99：在第 3 块，只有 4 个访问。
  共 4 次访问，1 次不命中，3 次命中。

总访问次数 = 100
不命中次数 = 4（每个块首次访问不命中）
命中次数 = 100 - 4 = 96

命中率 = 96 / 100 = 96%

**(4) 改为 2 路组相联**

Cache 容量仍为 2KB，块大小 32B。
Cache 总块数（行数） = 2KB / 32B = 64 块。

2 路组相联：每组 2 块。
组数 = 64 / 2 = 32 = 2⁵ → 组号 = 5 位。

主存地址格式：
Tag = 16 - 5 - 5 = 6 位
组号 = 5 位
块内偏移 = 5 位

地址 2345H = 0010 0011 0100 0101B
Tag（高 6 位） = 001000B = 8
组号（中间 5 位） = 11010B = 26
块内偏移（低 5 位） = 00101B = 5

**出处标注**：王道《计算机组成原理考研复习指导》Cache映射综合题

### 第14题

**题干**：某计算机主存按字节编址，逻辑地址 32 位，物理地址 24 位，页大小为 4KB。

(1) 写出逻辑地址和物理地址的结构（页号/页内偏移、物理页框号/页内偏移各占几位）。  
(2) 若页表项大小为 4B，问页表最多占多少页？  
(3) 若采用二级页表，第一级页表大小为 1 页，问第二级页表最多有多少项？画出地址映射示意图。  
(4) 若某进程的页表在主存，一次访存时间为 100ns，TLB（快表）的访问时间为 10ns，命中率为 90%，则有效访问时间为多少？  

**标准答案**：

**(1) 地址结构**

页大小 = 4KB = 2¹² → 页内偏移 = 12 位。

逻辑地址 32 位：
- 逻辑页号 = 32 - 12 = 20 位
- 页内偏移 = 12 位

物理地址 24 位：
- 物理页框号 = 24 - 12 = 12 位
- 页内偏移 = 12 位

**(2) 页表最多占多少页**

逻辑页号 20 位 → 最多 2²⁰ = 1M 个页表项。
每个页表项 4B → 页表总大小 = 4B × 2²⁰ = 4MB。

每页 4KB → 页表所占页数 = 4MB / 4KB = 1024 页 = 2¹⁰ 页。

**(3) 二级页表**

第一级页表大小 = 1 页 = 4KB = 4096B。
每页表项 4B → 第一级页表项数 = 4KB / 4B = 1K = 2¹⁰。

即第一级页表占 10 位逻辑页号，剩下 20 - 10 = 10 位为第二级页表索引。

第二级页表最多项数 = 2¹⁰ = 1024 项。

地址映射示意：

```
逻辑地址（32位）：
[一级页号 10位] [二级页号 10位] [页内偏移 12位]

一级页表（页表目录）：
以一级页号为索引 → 得到二级页表的物理页框号

二级页表：
以二级页号为索引 → 得到最终物理页框号

物理地址（24位）：
[物理页框号 12位] [页内偏移 12位]
```

**(4) 有效访问时间**

设 TLB 访问时间 t_TLB = 10ns，主存访问时间 t_M = 100ns，TLB 命中率 h = 90%。

情况分析：
- TLB 命中（90%）：只需访问 TLB + 访问主存 = 10ns + 100ns = 110ns
- TLB 未命中（10%）：需要查页表（访问主存中的页表）+ 再访问主存 = 10ns + 100ns + 100ns = 210ns

有效访问时间 EAT = 0.9 × 110 + 0.1 × 210 = 99 + 21 = 120 ns

另一种算法（假设 TLB 未命中时先查页表再访问数据，但不重复计入 TLB 访问）：
EAT = h × (t_TLB + t_M) + (1-h) × (t_TLB + 2 × t_M)
    = h × t_TLB + h × t_M + (1-h) × t_TLB + 2(1-h) × t_M
    = t_TLB + (2-h) × t_M
    = 10 + (2-0.9) × 100
    = 10 + 110 = 120 ns

**出处标注**：王道《计算机组成原理考研复习指导》虚拟存储综合题

### 第15题

**题干**：某磁盘存储器转速为 7200rpm（转/分），平均寻道时间为 8ms，每条磁道上的存储容量为 4KB，每个扇区存储 512B。

(1) 求该磁盘的平均等待时间（旋转延迟）。  
(2) 求该磁盘的数据传输率（每秒传输字节数）。  
(3) 若读写一个包含 8 个扇区的数据块，求平均存取时间。  
(4) 若磁盘接口数据总线宽度为 32 位，总线时钟频率为 66MHz，每 2 个时钟周期传送一个 32 位字，问总线的数据传输率是多少？能否满足该磁盘的传输需求？  

**标准答案**：

**(1) 平均等待时间**

转速 = 7200 rpm（转/分）= 7200/60 = 120 转/秒
旋转一周时间 = 1/120 s ≈ 8.33 ms

平均等待时间 = 旋转半周时间 = (1/2) × (1/120) s = 1/240 s ≈ 4.17 ms

**(2) 数据传输率**

每条磁道容量 = 4KB = 4096B
每秒转数 = 120 转/秒

传输率 = 每道容量 × 每秒转数 = 4096B × 120 = 491,520 B/s ≈ 480 KB/s ≈ 0.47 MB/s

**(3) 读取 8 个扇区的平均存取时间**

每扇区 512B，8 个扇区 = 4096B = 4KB = 1 条磁道容量

平均存取时间 = 平均寻道时间 + 平均等待时间 + 传输时间

传输时间 = 数据量 / 传输率 = 4KB / 480KB/s ≈ 8.33 ms

总存取时间 = 8ms + 4.17ms + 8.33ms ≈ 20.5 ms

**(4) 总线数据传输率**

总线宽度 = 32 位 = 4 字节
总线时钟频率 = 66 MHz
每 2 个时钟周期传送一个 32 位字

总线传输率 = (总线频率 / 2) × 每次传送字节数
            = (66 MHz / 2) × 4B
            = 33 MHz × 4B
            = 132 MB/s

总线传输率 132 MB/s 远大于磁盘传输率 ~0.47 MB/s，因此总线完全能够满足磁盘的传输需求。
