# 复试流程与分值结构

## 一、复试总体框架

### 1.1 复试组成

广东工业大学计算机学院硕士研究生复试由三部分组成，**总分 100 分**：

| 组成部分 | 分值 | 占比 | 考核形式 |
|---------|------|------|---------|
| **一、专业知识考核** | **40 分** | 40% | 闭卷笔试（离散数学） |
| **二、外语能力考核** | **20 分** | 20% | 英语口语/听力测试 |
| **三、综合素质与能力考核** | **40 分** | 40% | 综合面试（多对一） |
| **合计** | **100 分** | **100%** | |

### 1.2 录取规则

⚠️ **重要**：

1. **复试及格线**：复试总分 **< 60 分**视为不及格，不予录取
2. **各部分最低分**：部分年份可能设置各部分最低分要求（如专业知识笔试 < 24 分即 60% 以下淘汰），以当年复试办法为准
3. **总成绩计算公式**：

$$\text{总成绩} = \frac{\text{初试总分}}{5} \times 50\% + \text{复试总分} \times 50\%$$

**公式解读**：
- 初试总分（500 分制）除以 5 得到 100 分制，占总成绩的 50%
- 复试总分（100 分制）直接占 50%
- 即：初试 1 分 ≈ 复试 0.2 分（注意：初试被大幅稀释，复试权重很大）

**换算示例**：

| 考生 | 初试 | 复试 | 总成绩 |
|------|------|------|--------|
| A | 350 分 | 75 分 | 350/5 × 0.5 + 75 × 0.5 = 35 + 37.5 = **72.5 分** |
| B | 330 分 | 85 分 | 330/5 × 0.5 + 85 × 0.5 = 33 + 42.5 = **75.5 分** |

> 虽然 A 初试高 20 分，但 B 复试高 10 分即可反超。**复试逆袭非常容易！**

## 二、专业知识考核（40 分）

### 2.1 考核形式

| 项目 | 说明 |
|------|------|
| **分值** | 40 分（复试权重最大的部分） |
| **形式** | 闭卷笔试 |
| **时长** | 约 1.5-2 小时 |
| **科目** | **离散数学** |

### 2.2 考试内容范围

**参考教材**：

📚 **傅彦、顾小丰、王庆先等《离散数学及其应用》**（高等教育出版社）—— 广工官方推荐教材

📚 **屈婉玲、耿素云、张立昂《离散数学》**（清华大学出版社）—— 可作补充参考

**考试重点章节**：

| 章节 | 内容 | 大致分值占比 | 重要程度 |
|------|------|-------------|---------|
| 1. 命题逻辑 | 命题、联结词、真值表、命题公式、范式（析取范式/合取范式）、推理理论 | ~15% | ⭐⭐⭐⭐⭐ |
| 2. 谓词逻辑 | 谓词、量词、谓词公式、解释、前束范式、谓词逻辑推理 | ~10% | ⭐⭐⭐⭐ |
| 3. 集合论 | 集合的基本运算、幂集、笛卡尔积、集合恒等式 | ~10% | ⭐⭐⭐⭐ |
| 4. 二元关系 | 关系的定义、性质（自反/反自反/对称/反对称/传递）、关系的运算、关系的闭包 | ~15% | ⭐⭐⭐⭐⭐ |
| 5. 等价关系与序关系 | 等价关系、等价类、划分、偏序关系、全序、哈斯图、极大/极小元、最大/最小元 | ~15% | ⭐⭐⭐⭐⭐ |
| 6. 函数 | 函数的定义、单射、满射、双射、复合函数、逆函数、集合的基数 | ~10% | ⭐⭐⭐⭐ |
| 7. 图论 | 图的基本概念、握手定理、通路与回路、连通性、图的矩阵表示、欧拉图与哈密顿图 | ~15% | ⭐⭐⭐⭐⭐ |
| 8. 树 | 树的定义与性质、生成树、最小生成树（Kruskal/Prim 算法）、根树、二叉树、最优树与前缀码（Huffman） | ~10% | ⭐⭐⭐⭐ |
| 9. 代数系统 | 运算的性质、半群、独异点、群、子群、交换群、环与域（基础概念） | ~5% | ⭐⭐⭐ |
| 10. 组合数学 | 排列组合、鸽巢原理、容斥原理、递推关系 | ~5% | ⭐⭐⭐ |

### 2.3 题型与分值

| 题型 | 题量 | 每题分值 | 总分 | 说明 |
|------|------|---------|------|------|
| 选择题/填空题 | 约 10-15 题 | 1-2 分 | 约 15-20 分 | 考察基本概念和计算 |
| 简答题/证明题 | 约 3-5 题 | 4-6 分 | 约 10-15 分 | 考察理解和推理能力 |
| 综合计算题/应用题 | 约 2-3 题 | 5-10 分 | 约 10-15 分 | 考察应用能力 |

> ⚠️ 以上题型分布为基于历年情况的估算，具体以当年考试为准

### 2.4 备考建议

**核心复习策略**：

1. **以傅彦教材为主线**（3 个月完成）：
   - 第 1 个月：通读教材，理解基本概念，做简单课后题
   - 第 2 个月：重点攻克关系、图论、树等核心章节，做中等难度题目
   - 第 3 个月：综合复习，做本资料中的 30 道精选题目 + 教材综合练习

2. **重点章节优先级**：
   - 最高优先级：命题逻辑、二元关系、等价关系、图论、树
   - 次高优先级：谓词逻辑、集合论、函数
   - 一般优先级：代数系统、组合数学

3. **重点题型训练**：
   - 求关系的性质（自反、对称等）
   - 求关系的闭包（自反闭包、对称闭包、传递闭包）
   - 求命题公式的主析取/主合取范式
   - 构造逻辑推理证明
   - 图的基本计算（握手定理应用、最短路径）
   - 最小生成树算法（Kruskal、Prim）
   - 哈夫曼树与前缀码

4. **练习题来源**：
   - 教材课后习题（必做）
   - 本资料提供的 30+ 道精选笔试真题（重点做）
   - 历年考研真题中的离散数学部分

## 三、外语能力考核（20 分）

### 3.1 基本信息

| 项目 | 说明 |
|------|------|
| **分值** | 20 分 |
| **形式** | 英语口语面试（含听力理解） |
| **时长** | 约 5-8 分钟/人 |
| **考核方式** | 考官用英语提问，考生用英语回答 |

### 3.2 考核内容

| 环节 | 大致时间 | 说明 |
|------|---------|------|
| **自我介绍** | 1-2 分钟 | 英文自我介绍（名字、本科学校、专业、兴趣、考研原因等） |
| **问答对话** | 3-5 分钟 | 考官用英语提问 2-4 个问题，考生回答 |
| **专业话题**（可选） | 1-2 分钟 | 用英语回答简单的专业相关问题 |

### 3.3 评分要点

| 要点 | 权重 | 说明 |
|------|------|------|
| **语言准确性** | ~30% | 语法、词汇、发音的正确性 |
| **流利度与连贯性** | ~30% | 表达流畅、内容连贯 |
| **内容质量** | ~25% | 回答是否切题、是否有深度 |
| **听力理解** | ~15% | 是否能正确理解考官问题 |

### 3.4 备考建议

1. **准备英文自我介绍**（1-2 分钟）：
   - 提前写好并背诵熟练
   - 内容包括：姓名、本科学校与专业、兴趣爱好、为什么报考广工、为什么选择计算机相关专业、研究生期间的计划
   - 可以准备短（1 分钟）和稍长（2 分钟）两个版本

2. **准备高频问题的回答**：
   - 详见《面试常见问题.md》中的英语面试部分
   - 每个问题准备 3-5 句话的回答
   - 不求语法完美，但要求表达清楚、流利

3. **练习方式**：
   - 每天听 30 分钟英语（BBC、VOA、英语演讲）
   - 找同学互相练习英语问答
   - 对着镜子练习自我介绍
   - 录音自测，关注发音和语速

4. **临场技巧**：
   - 没听清问题时可以礼貌地请老师重复："Pardon?" / "Could you please repeat that?"
   - 不会回答时不要慌，可以说："That's an interesting question. I haven't thought about it before. From my perspective..."
   - 语速适中，不要太快，发音清晰最重要

## 四、综合素质与能力考核（40 分）

### 4.1 基本信息

| 项目 | 说明 |
|------|------|
| **分值** | 40 分 |
| **形式** | 多对一面试（3-5 位老师 vs 1 位考生） |
| **时长** | 约 15-20 分钟/人 |
| **语言** | 中文为主（另有单独英语面试环节） |

### 4.2 考核维度

| 维度 | 大致分值 | 考察要点 |
|------|---------|---------|
| **专业基础知识** | ~15 分 | 数据结构、操作系统、计算机网络、数据库、编程语言等核心课程的掌握程度 |
| **编程与工程能力** | ~10 分 | 项目经历、编程水平、对技术的理解 |
| **科研潜力与兴趣** | ~5 分 | 是否有科研经历、对研究方向的理解和兴趣 |
| **逻辑思维与表达** | ~5 分 | 回答问题的条理性、思维清晰度、表达能力 |
| **综合素质** | ~5 分 | 仪表仪态、应变能力、学习态度 |

### 4.3 常见面试问题类别

| 类别 | 说明 | 典型问题示例 |
|------|------|------------|
| **自我介绍** | 1-2 分钟中文介绍 | "请简单介绍一下你自己" |
| **专业基础知识** | 本科核心课程 | "什么是进程和线程的区别？"、"TCP 和 UDP 有什么不同？" |
| **项目经历** | 简历中的项目深度追问 | "介绍一下你做过的 XX 项目，你承担了什么角色？" |
| **科研经历** | 论文、竞赛、科研项目 | "你参加过什么科研项目/竞赛？有什么收获？" |
| **研究方向兴趣** | 研究兴趣与意向导师 | "你对什么研究方向感兴趣？为什么？" |
| **动机与规划** | 考研动机、研究生规划 | "为什么选择报考广工？研究生期间有什么计划？" |
| **技术热点关注** | AI、大数据等 | "你对大模型（如 ChatGPT）有什么了解？" |
| **本科学习** | 成绩单、课程、GPA | "你本科成绩如何？哪门课学得最好？" |
| **综合能力** | 团队合作、学习能力 | "举一个你解决复杂问题的例子" |

### 4.4 面试准备建议

1. **简历准备**：
   - 准备 1-2 页中文简历（建议准备多份纸质版，面试时带给每位老师）
   - 突出项目经历、竞赛获奖、科研经历
   - 对简历中的每一条内容都能深入回答

2. **本科核心课程复习**：
   - 数据结构、操作系统、计算机网络、数据库（这四门是必问）
   - 复习核心概念，不求背诵定义，但求理解和能用自己的话解释清楚
   - 重点关注应用场景：例如"TCP 三次握手为什么不是两次？"

3. **项目梳理**：
   - 对简历中的每个项目，准备好详细的 STAR 回答模板
   - S（Situation）：项目背景是什么
   - T（Task）：你的任务是什么
   - A（Action）：你采取了什么行动
   - R（Result）：取得了什么成果
   - 能用 1-2 分钟清晰讲完一个项目

4. **了解广工与导师**：
   - 了解计算机学院的整体情况（研究方向、知名教授）
   - 浏览学院官网，了解部分教授的研究方向
   - 准备回答"你对什么研究方向感兴趣"的问题

5. **模拟面试**：
   - 找同学、学长学姐进行模拟面试
   - 练习表达能力和应变能力
   - 计时练习自我介绍和项目介绍

### 4.5 面试礼仪与注意事项

| 事项 | 建议 |
|------|------|
| **着装** | 整洁大方，不必穿正装，但避免过于休闲（如拖鞋、短裤） |
| **仪态** | 坐姿端正，眼神自然，面带微笑，适度手势 |
| **语言表达** | 语速适中，条理清晰，分点回答（第一/第二/第三/） |
| **态度** | 诚实谦虚，不懂不要装懂，可以说"这个问题我不太了解，但我会去学习" |
| **时间控制** | 回答问题简洁切题，不要太长也不要太简短 |
| **结束礼节** | 结束后说"谢谢老师"，轻轻关好门 |

## 六、差额复试比例与淘汰率

| 项目 | 情况 |
|------|------|
| **差额比例** | 通常 1 : 1.2 ~ 1 : 1.5（即每录取 1 人，有 1.2-1.5 人进复试） |
| **淘汰率** | 约 17% ~ 33%（即进复试的人中，约 1/5 到 1/3 会被淘汰） |
| **逆袭可能性** | 很高（初试 330 + 复试 85 可反超初试 350 + 复试 75） |

> 复试高分可以大幅提升排名，初试高分也可能因复试表现差而被淘汰。**务必重视复试！**

## 八、跨专业考生特别注意事项

⚠️ **重要**：如果您是跨专业报考（本科非计算机/软件工程等相关专业），请注意以下几点：

1. **补修基础知识**：面试官可能会重点考察你的计算机基础，务必系统学习数据结构、操作系统、计算机网络、数据库等核心课程

2. **准备好"为什么跨考"的回答**：
   - 真诚表达对计算机专业的兴趣和了解
   - 说明你为跨考做了哪些准备（自学课程、做项目等）
   - 展示你已经具备一定的专业基础

3. **用项目/实践证明能力**：
   - 如果有编程相关的项目、练习、竞赛经历，重点展示
   - 可以展示 GitHub、Gitee 代码仓库（如果有）
   - LeetCode 刷题数、在线 MOOC 证书等也可作为证明

4. **展现学习能力**：
   - 跨考生最重要的是学习能力和潜力
   - 用本科学习成绩、快速学习的经历来证明

5. **诚实面对知识盲区**：
   - 如果问到不会的专业问题，诚实回答并说明会去学习
   - 不要假装知道，容易被追问穿帮

6. **复试准备优先级**：
   - 离散数学笔试（最公平、最能拉开差距）
   - 编程能力（可以通过刷题体现）
   - 核心课程基础（数据结构、操作系统优先）
   - 面试表达能力

## 九、复试心态与注意事项

1. **保持平常心**：广工复试淘汰率不算高，认真准备后大部分人能录取
2. **笔试最重要**：离散数学笔试 40 分，是最容易拉开差距的部分
3. **诚实回答**：面试时不要不懂装懂，实在不会可以说"这个问题我不太了解，但我会在研究生阶段重点学习"
4. **展现积极态度**：表达对计算机学科的兴趣和对研究生学习的渴望
5. **关注官方通知**：复试时间、方式等以学校和学院官方通知为准
