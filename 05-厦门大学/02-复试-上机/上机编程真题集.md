### 真题 1：冒泡排序与交换次数统计

**题目描述**

给定一个整数数组，使用冒泡排序算法对其进行升序排序，并统计排序过程中元素的总交换次数。

**输入格式**

第一行：一个整数 n（1 ≤ n ≤ 1000）。
第二行：n 个整数。

**输出格式**

第一行：排序后的数组。
第二行：总交换次数。

**输入样例**

```
5
5 3 8 1 2
```

**输出样例**

```
1 2 3 5 8
7
```

**解题思路**

标准冒泡排序算法，在每次发生元素交换时增加计数器。

**参考代码**

```c
#include <stdio.h>

int main() {
    int n, i, j, temp, count = 0;
    int arr[1005];
    scanf("%d", &n);
    for (i = 0; i < n; i++) scanf("%d", &arr[i]);
    for (i = 0; i < n - 1; i++) {
        for (j = 0; j < n - i - 1; j++) {
            if (arr[j] > arr[j + 1]) {
                temp = arr[j];
                arr[j] = arr[j + 1];
                arr[j + 1] = temp;
                count++;
            }
        }
    }
    for (i = 0; i < n; i++) {
        if (i > 0) printf(" ");
        printf("%d", arr[i]);
    }
    printf("\n%d\n", count);
    return 0;
}
```

### 真题 2：归并排序求逆序对

**题目描述**

给定一个整数序列，计算序列中的逆序对数量。

**输入格式**

第一行：一个整数 n（1 ≤ n ≤ 100000）。
第二行：n 个整数。

**输出格式**

一个整数，表示逆序对的数量。

**输入样例**

```
5
2 3 8 6 1
```

**输出样例**

```
5
```

**解题思路**

使用归并排序，在合并过程中统计逆序对数量。

**参考代码**

```c
#include <stdio.h>

long long count = 0;
int temp[100005];

void merge(int arr[], int l, int mid, int r) {
    int i = l, j = mid + 1, k = l;
    while (i <= mid && j <= r) {
        if (arr[i] <= arr[j]) temp[k++] = arr[i++];
        else {
            temp[k++] = arr[j++];
            count += mid - i + 1;
        }
    }
    while (i <= mid) temp[k++] = arr[i++];
    while (j <= r) temp[k++] = arr[j++];
    for (i = l; i <= r; i++) arr[i] = temp[i];
}

void mergeSort(int arr[], int l, int r) {
    if (l < r) {
        int mid = (l + r) / 2;
        mergeSort(arr, l, mid);
        mergeSort(arr, mid + 1, r);
        merge(arr, l, mid, r);
    }
}

int main() {
    int n, i, arr[100005];
    scanf("%d", &n);
    for (i = 0; i < n; i++) scanf("%d", &arr[i]);
    mergeSort(arr, 0, n - 1);
    printf("%lld\n", count);
    return 0;
}
```

### 真题 3：快速排序与第 K 大数

**题目描述**

给定一个无序的整数数组，找出其中第 K 大的数。

**输入格式**

第一行：两个整数 n 和 K（1 ≤ K ≤ n ≤ 10000）。
第二行：n 个整数。

**输出格式**

一个整数，表示第 K 大的数。

**输入样例**

```
6 3
1 5 3 8 2 9
```

**输出样例**

```
5
```

**解题思路**

使用快速选择算法（基于快排思想），时间复杂度 O(n)。

**参考代码**

```c
#include <stdio.h>

int findKth(int arr[], int l, int r, int k) {
    if (l == r) return arr[l];
    int pivot = arr[l + (r - l) / 2];
    int i = l - 1, j = r + 1;
    while (i < j) {
        do i++; while (arr[i] > pivot);
        do j--; while (arr[j] < pivot);
        if (i < j) {
            int temp = arr[i];
            arr[i] = arr[j];
            arr[j] = temp;
        }
    }
    int len = j - l + 1;
    if (k <= len) return findKth(arr, l, j, k);
    else return findKth(arr, j + 1, r, k - len);
}

int main() {
    int n, k, i, arr[10005];
    scanf("%d %d", &n, &k);
    for (i = 0; i < n; i++) scanf("%d", &arr[i]);
    printf("%d\n", findKth(arr, 0, n - 1, k));
    return 0;
}
```

### 真题 4：单链表的反转

**题目描述**

给定一个单链表，将链表反转，并输出反转后的链表。

**输入格式**

第一行：一个整数 n（0 ≤ n ≤ 1000）。
第二行：n 个整数。

**输出格式**

反转后的链表元素。n=0 时输出 "NULL"。

**输入样例**

```
5
1 2 3 4 5
```

**输出样例**

```
5 4 3 2 1
```

**解题思路**

使用三个指针逐步反转链表。

**参考代码**

```c
#include <stdio.h>
#include <stdlib.h>

typedef struct ListNode {
    int val;
    struct ListNode *next;
} Node;

Node* createNode(int val) {
    Node* node = (Node*)malloc(sizeof(Node));
    node->val = val;
    node->next = NULL;
    return node;
}

Node* reverseList(Node* head) {
    Node *prev = NULL, *curr = head, *next;
    while (curr != NULL) {
        next = curr->next;
        curr->next = prev;
        prev = curr;
        curr = next;
    }
    return prev;
}

int main() {
    int n, i, val;
    Node *head = NULL, *tail = NULL;
    scanf("%d", &n);
    if (n == 0) { printf("NULL\n"); return 0; }
    for (i = 0; i < n; i++) {
        scanf("%d", &val);
        Node* node = createNode(val);
        if (head == NULL) { head = node; tail = node; }
        else { tail->next = node; tail = node; }
    }
    head = reverseList(head);
    Node* p = head;
    int first = 1;
    while (p != NULL) {
        if (!first) printf(" ");
        printf("%d", p->val);
        first = 0;
        p = p->next;
    }
    printf("\n");
    return 0;
}
```

### 真题 5：链表的合并与去重

**题目描述**

给定两个有序单链表（升序），合并为一个新的有序链表，且不含重复元素。

**输入格式**

第一行：两个整数 m 和 n。
第二行：m 个整数。
第三行：n 个整数。

**输出格式**

合并且去重后的有序链表。

**输入样例**

```
4 3
1 3 5 7
2 3 6
```

**输出样例**

```
1 2 3 5 6 7
```

**解题思路**

双指针分别遍历两个链表，合并到新链表，遇到重复只保留一个。

**参考代码**

```c
#include <stdio.h>

int main() {
    int m, n, i, j, k = 0;
    int a[1005], b[1005], res[2005];
    scanf("%d %d", &m, &n);
    for (i = 0; i < m; i++) scanf("%d", &a[i]);
    for (i = 0; i < n; i++) scanf("%d", &b[i]);
    i = 0, j = 0;
    while (i < m && j < n) {
        int val;
        if (a[i] < b[j]) val = a[i++];
        else val = b[j++];
        if (k == 0 || val != res[k - 1]) res[k++] = val;
    }
    while (i < m) {
        if (k == 0 || a[i] != res[k - 1]) res[k++] = a[i];
        i++;
    }
    while (j < n) {
        if (k == 0 || b[j] != res[k - 1]) res[k++] = b[j];
        j++;
    }
    for (i = 0; i < k; i++) {
        if (i > 0) printf(" ");
        printf("%d", res[i]);
    }
    printf("\n");
    return 0;
}
```

### 真题 6：二叉树的前序、中序、后序遍历

**题目描述**

给定前序遍历和中序遍历序列，构造二叉树并输出后序遍历序列。

**输入格式**

第一行：整数 n。
第二行：n 个整数（前序）。
第三行：n 个整数（中序）。

**输出格式**

后序遍历序列。

**输入样例**

```
6
1 2 4 5 3 6
4 2 5 1 6 3
```

**输出样例**

```
4 5 2 6 3 1
```

**解题思路**

前序第一个元素是根，在中序中找到根，递归构造。

**参考代码**

```c
#include <stdio.h>
#include <stdlib.h>

typedef struct TreeNode {
    int val;
    struct TreeNode *left;
    struct TreeNode *right;
} TNode;

int pre[1005], in[1005];
int postIdx;

TNode* buildTree(int preL, int preR, int inL, int inR) {
    if (preL > preR) return NULL;
    TNode* root = (TNode*)malloc(sizeof(TNode));
    root->val = pre[preL];
    int k;
    for (k = inL; k <= inR; k++)
        if (in[k] == root->val) break;
    int numLeft = k - inL;
    root->left = buildTree(preL + 1, preL + numLeft, inL, k - 1);
    root->right = buildTree(preL + numLeft + 1, preR, k + 1, inR);
    return root;
}

void postOrder(TNode* root, int res[]) {
    if (root == NULL) return;
    postOrder(root->left, res);
    postOrder(root->right, res);
    res[postIdx++] = root->val;
}

int main() {
    int n, i, res[1005];
    scanf("%d", &n);
    for (i = 0; i < n; i++) scanf("%d", &pre[i]);
    for (i = 0; i < n; i++) scanf("%d", &in[i]);
    TNode* root = buildTree(0, n - 1, 0, n - 1);
    postIdx = 0;
    postOrder(root, res);
    for (i = 0; i < n; i++) {
        if (i > 0) printf(" ");
        printf("%d", res[i]);
    }
    printf("\n");
    return 0;
}
```

### 真题 7：判断二叉搜索树

**题目描述**

给定二叉树的前序遍历序列，判断是否为二叉搜索树（BST）。

**输入样例 1**

```
5
8 5 3 6 10
```

**输出样例 1**

```
YES
```

**输入样例 2**

```
5
10 5 3 8 6
```

**输出样例 2**

```
NO
```

**解题思路**

BST 性质：每个节点左子树所有节点都小于它，右子树都大于它。

**参考代码**

```c
#include <stdio.h>

int pre[1005];

int isBST(int l, int r, int minVal, int maxVal) {
    if (l > r) return 1;
    int root = pre[l];
    if (root <= minVal || root >= maxVal) return 0;
    int i;
    for (i = l + 1; i <= r; i++)
        if (pre[i] > root) break;
    int split = i;
    for (i = split; i <= r; i++)
        if (pre[i] < root) return 0;
    return isBST(l + 1, split - 1, minVal, root) &&
           isBST(split, r, root, maxVal);
}

int main() {
    int n, i;
    scanf("%d", &n);
    for (i = 0; i < n; i++) scanf("%d", &pre[i]);
    if (n == 0) { printf("YES\n"); return 0; }
    if (isBST(0, n - 1, -1000000, 1000000)) printf("YES\n");
    else printf("NO\n");
    return 0;
}
```

### 真题 8：二叉树的层序遍历

**输入格式**

第一行：整数 n。
第二行：n 个整数（-1 表示空）。

**输出格式**

非空节点的层序遍历。

**输入样例**

```
7
1 2 3 -1 -1 4 5
```

**输出样例**

```
1 2 3 4 5
```

**解题思路**

使用队列进行层序遍历，跳过值为 -1 的节点。

**参考代码**

```c
#include <stdio.h>

int main() {
    int n, i, arr[1005];
    int queue[1005], front = 0, rear = 0;
    int res[1005], cnt = 0;
    scanf("%d", &n);
    for (i = 0; i < n; i++) scanf("%d", &arr[i]);
    if (arr[0] != -1) queue[rear++] = 0;
    while (front < rear) {
        int idx = queue[front++];
        res[cnt++] = arr[idx];
        int left = 2 * idx + 1;
        int right = 2 * idx + 2;
        if (left < n && arr[left] != -1) queue[rear++] = left;
        if (right < n && arr[right] != -1) queue[rear++] = right;
    }
    for (i = 0; i < cnt; i++) {
        if (i > 0) printf(" ");
        printf("%d", res[i]);
    }
    printf("\n");
    return 0;
}
```

### 真题 9：图的深度优先搜索（DFS）

**题目描述**

给定无向图邻接矩阵，从指定节点出发输出 DFS 遍历序列。有多个相邻节点时优先访问编号较小的节点。

**输入格式**

第一行：两个整数 n 和 start。
接下来 n 行：每行 n 个整数（0 或 1）。

**输出格式**

DFS 遍历顺序。

**输入样例**

```
4 1
0 1 1 0
1 0 1 1
1 1 0 0
0 1 0 0
```

**输出样例**

```
1 2 3 4
```

**解题思路**

标准 DFS，使用 visited 数组标记已访问节点。

**参考代码**

```c
#include <stdio.h>

int graph[105][105];
int visited[105];
int res[105], cnt = 0;
int n;

void dfs(int u) {
    visited[u] = 1;
    res[cnt++] = u;
    for (int v = 1; v <= n; v++)
        if (graph[u][v] && !visited[v]) dfs(v);
}

int main() {
    int start, i, j;
    scanf("%d %d", &n, &start);
    for (i = 1; i <= n; i++)
        for (j = 1; j <= n; j++)
            scanf("%d", &graph[i][j]);
    dfs(start);
    for (i = 0; i < cnt; i++) {
        if (i > 0) printf(" ");
        printf("%d", res[i]);
    }
    printf("\n");
    return 0;
}
```

### 真题 10：图的广度优先搜索（BFS）

**题目描述**

给定有向图，从指定起点出发输出 BFS 遍历序列。

**输入格式**

第一行：三个整数 n, m, start。
接下来 m 行：每行两个整数 u, v。

**输出格式**

BFS 遍历顺序。

**输入样例**

```
5 6 1
1 2
1 3
2 4
3 4
4 5
2 5
```

**输出样例**

```
1 2 3 4 5
```

**解题思路**

用队列实现 BFS，邻接表排序保证按编号访问。

**参考代码**

```c
#include <stdio.h>
#include <stdlib.h>

typedef struct Edge {
    int to;
    struct Edge* next;
} Edge;

Edge* adj[1005];
int visited[1005];

void addEdge(int u, int v) {
    Edge* e = (Edge*)malloc(sizeof(Edge));
    e->to = v;
    e->next = adj[u];
    adj[u] = e;
}

int main() {
    int n, m, start, u, v, i, j;
    scanf("%d %d %d", &n, &m, &start);
    for (i = 0; i < m; i++) {
        scanf("%d %d", &u, &v);
        addEdge(u, v);
    }
    int queue[1005], front = 0, rear = 0;
    int res[1005], cnt = 0;
    queue[rear++] = start;
    visited[start] = 1;
    while (front < rear) {
        int curr = queue[front++];
        res[cnt++] = curr;
        int neighbors[1005], numN = 0;
        Edge* p = adj[curr];
        while (p != NULL) { neighbors[numN++] = p->to; p = p->next; }
        for (i = 0; i < numN - 1; i++)
            for (j = 0; j < numN - i - 1; j++)
                if (neighbors[j] > neighbors[j + 1]) {
                    int temp = neighbors[j];
                    neighbors[j] = neighbors[j + 1];
                    neighbors[j + 1] = temp;
                }
        for (i = 0; i < numN; i++)
            if (!visited[neighbors[i]]) {
                visited[neighbors[i]] = 1;
                queue[rear++] = neighbors[i];
            }
    }
    for (i = 0; i < cnt; i++) {
        if (i > 0) printf(" ");
        printf("%d", res[i]);
    }
    printf("\n");
    return 0;
}
```

### 真题 11：连通分量计数

**题目描述**

给定无向图，计算连通分量个数。

**输入格式**

第一行：两个整数 n 和 m。
接下来 m 行：每行两个整数 u, v。

**输出格式**

连通分量个数。

**输入样例**

```
6 3
1 2
2 3
4 5
```

**输出样例**

```
3
```

**解题思路**

使用并查集统计连通分量。

**参考代码**

```c
#include <stdio.h>

int parent[1005];

int find(int x) {
    if (parent[x] != x) parent[x] = find(parent[x]);
    return parent[x];
}

void unionSets(int x, int y) {
    int px = find(x), py = find(y);
    if (px != py) parent[px] = py;
}

int main() {
    int n, m, u, v, i;
    scanf("%d %d", &n, &m);
    for (i = 1; i <= n; i++) parent[i] = i;
    for (i = 0; i < m; i++) {
        scanf("%d %d", &u, &v);
        unionSets(u, v);
    }
    int count = 0;
    for (i = 1; i <= n; i++)
        if (parent[i] == i) count++;
    printf("%d\n", count);
    return 0;
}
```

### 真题 12：Dijkstra 单源最短路径

**题目描述**

给定带权有向图和起点，求从起点到其他所有节点的最短路径长度。

**输入格式**

第一行：三个整数 n, m, s。
接下来 m 行：每行三个整数 u, v, w。

**输出格式**

一行 n 个整数，表示从 s 到各节点的最短距离（不可达输出 -1）。

**输入样例**

```
4 6 1
1 2 2
1 3 5
2 3 1
2 4 3
3 4 1
1 4 10
```

**输出样例**

```
0 2 3 4
```

**解题思路**

标准 Dijkstra 算法。

**参考代码**

```c
#include <stdio.h>

#define INF 1000000000

int graph[1005][1005];
int dist[1005];
int visited[1005];

int main() {
    int n, m, s, u, v, w, i, j;
    scanf("%d %d %d", &n, &m, &s);
    for (i = 1; i <= n; i++) {
        for (j = 1; j <= n; j++) graph[i][j] = INF;
        dist[i] = INF;
    }
    dist[s] = 0;
    for (i = 0; i < m; i++) {
        scanf("%d %d %d", &u, &v, &w);
        if (w < graph[u][v]) graph[u][v] = w;
    }
    for (i = 1; i <= n; i++) {
        int minDist = INF, u = -1;
        for (j = 1; j <= n; j++)
            if (!visited[j] && dist[j] < minDist) {
                minDist = dist[j];
                u = j;
            }
        if (u == -1) break;
        visited[u] = 1;
        for (v = 1; v <= n; v++)
            if (!visited[v] && graph[u][v] < INF &&
                dist[u] + graph[u][v] < dist[v])
                dist[v] = dist[u] + graph[u][v];
    }
    for (i = 1; i <= n; i++) {
        if (i > 1) printf(" ");
        if (dist[i] == INF) printf("-1");
        else printf("%d", dist[i]);
    }
    printf("\n");
    return 0;
}
```

### 真题 13：Floyd 多源最短路径

**题目描述**

给定带权有向图，求任意两点间的最短路径。

**输入样例**

```

1 2 5
2 3 2
1 3 10
3 1 1
```

**输出样例**

```c
int numStack[1005];

int priority(char op) {
    if (op == '+' || op == '-') return 1;
    if (op == '*' || op == '/') return 2;
    return 0;
}

int calc(int a, int b, char op) {
    if (op == '+') return a + b;
    if (op == '-') return a - b;
    if (op == '*') return a * b;
    if (op == '/') return a / b;
    return 0;
}

int main() {
    char s[1005];

    int len = strlen(s), i = 0;
    while (i < len) {
        if (s[i] >= '0' && s[i] <= '9' ||
            (s[i] == '-' && (i == 0 || s[i - 1] < '0'))) {
            int sign = 1, num = 0;
            if (s[i] == '-') { sign = -1; i++; }
            while (i < len && s[i] >= '0' && s[i] <= '9') {
                num = num * 10 + (s[i] - '0');
                i++;

            numStack[++numTop] = sign * num;

                int b = numStack[numTop--];
                int a = numStack[numTop--];
                char op = opStack[opTop--];
                numStack[++numTop] = calc(a, b, op);
            }
            opStack[++opTop] = s[i];
            i++;
        }
    }
    while (opTop >= 0) {
        int b = numStack[numTop--];
        int a = numStack[numTop--];
        char op = opStack[opTop--];
        numStack[++numTop] = calc(a, b, op);
```

```c
    queue[rear++] = (struct Point){0, 0, 1};
    visited[0][0] = 1;
    int ans = -1;
    while (front < rear) {
        struct Point curr = queue[front++];
        if (curr.x == n - 1 && curr.y == m - 1) {
            ans = curr.dist; break;
        }
        for (i = 0; i < 4; i++) {
            int nx = curr.x + dx[i];
            int ny = curr.y + dy[i];
            if (nx >= 0 && nx < n && ny >= 0 && ny < m &&
                !visited[nx][ny] && maze[nx][ny] == 0) {
                visited[nx][ny] = 1;
                queue[rear++] = (struct Point){nx, ny, curr.dist + 1};
            }
        }
    }
    printf("%d\n", ans);
    return 0;
}
```

### 真题 31：十六进制不进位加法

**题目描述**

给定两个十六进制字符串（不含前缀0x），计算它们的不进位加法结果。不进位加法即对应位相加后只取个位（模16），忽略进位。

**输入格式**

两行，每行一个十六进制字符串（长度不超过1000位，可能有前导0）。

**输出格式**

一行，表示不进位加法结果（省略前导0，如果结果为0则输出0）。

**输入样例**

```
FF
1
```

**输出样例**

```
100
```

**解题思路**

按字符逐位转换为数值相加，取个位，结果可能产生新的进位需递归处理。

**参考代码**

```c
#include <stdio.h>
#include <string.h>

int hexCharToInt(char c) {
    if (c >= '0' && c <= '9') return c - '0';
    if (c >= 'A' && c <= 'F') return c - 'A' + 10;
    return c - 'a' + 10;
}

char intToHexChar(int v) {
    if (v < 10) return '0' + v;
    return 'A' + v - 10;
}

int main() {
    char a[1005], b[1005], res[1005];
    scanf("%s %s", a, b);
    int lenA = strlen(a), lenB = strlen(b);
    int maxLen = lenA > lenB ? lenA : lenB;
    int carry = 0, idx = 0;
    for (int i = 0; i < maxLen; i++) {
        int va = (i < lenA) ? hexCharToInt(a[lenA - 1 - i]) : 0;
        int vb = (i < lenB) ? hexCharToInt(b[lenB - 1 - i]) : 0;
        int sum = va + vb + carry;
        res[idx++] = intToHexChar(sum % 16);
        carry = sum / 16;
    }
    while (carry > 0) {
        res[idx++] = intToHexChar(carry % 16);
        carry /= 16;
    }
    int start = idx - 1;
    while (start > 0 && res[start] == '0') start--;
    for (int i = start; i >= 0; i--) printf("%c", res[i]);
    printf("\n");
    return 0;
}
```

### 真题 32：判断回文数

**题目描述**

给定一个正整数 n，判断它是否是回文数。回文数是指正读和反读都相同的数。

**输入格式**

一个整数 n（1 ≤ n ≤ 10^18）。

**输出格式**

如果 n 是回文数，输出 "YES"，否则输出 "NO"。

**输入样例 1**

```
121
```

**输出样例 1**

```
YES
```

**输入样例 2**

```
-121
```

**输出样例 2**

```
NO
```

**解题思路**

将整数转为字符串，用双指针判断。或者将数字反转后比较。

**参考代码**

```c
#include <stdio.h>

int main() {
    long long n;
    scanf("%lld", &n);
    if (n < 0) { printf("NO\n"); return 0; }
    long long original = n, reversed = 0;
    while (n > 0) {
        reversed = reversed * 10 + n % 10;
        n /= 10;
    }
    if (original == reversed) printf("YES\n");
    else printf("NO\n");
    return 0;
}
```

### 真题 33：非素数个数

**题目描述**

给定一个区间 [L, R]，统计该区间内非素数的个数。

**输入格式**

两个整数 L 和 R（1 ≤ L ≤ R ≤ 10^6）。

**输出格式**

一个整数，表示区间 [L, R] 内非素数的个数。

**输入样例**

```
1 10
```

**输出样例**

```
6
```

**解题思路**

埃拉托斯特尼筛法预计算素数，然后统计。注意1既不是素数也不是合数，需单独处理。

**参考代码**

```c
#include <stdio.h>
#include <string.h>

int main() {
    int L, R, i, j;
    scanf("%d %d", &L, &R);
    int maxN = R;
    int isPrime[1000005];
    memset(isPrime, 1, sizeof(isPrime));
    isPrime[0] = isPrime[1] = 0;
    for (i = 2; i * i <= maxN; i++) {
        if (isPrime[i]) {
            for (j = i * i; j <= maxN; j += i)
                isPrime[j] = 0;
        }
    }
    int count = 0;
    for (i = L; i <= R; i++)
        if (!isPrime[i]) count++;
    printf("%d\n", count);
    return 0;
}
```

### 真题 34：进制转换3

**题目描述**

给定一个十进制整数 n 和目标进制 m（2 ≤ m ≤ 16），将 n 转换为 m 进制。如果 n 为负数，输出负号后再转换。

**输入格式**

两个整数 n 和 m，用空格分隔。

**输出格式**

转换后的进制数（用大写字母表示10-15）。

**输入样例 1**

```
3055 16
```

**输出样例 1**

```
BF7
```

**输入样例 2**

```
-10 2
```

**输出样例 2**

```
-1010
```

**解题思路**

反复除以目标进制取余，使用数组存储结果。

**参考代码**

```c
#include <stdio.h>

int main() {
    long long n;
    int base;
    char digits[] = "0123456789ABCDEF";
    char res[100];
    scanf("%lld %d", &n, &base);
    int idx = 0, neg = 0;
    if (n == 0) { printf("0\n"); return 0; }
    if (n < 0) { neg = 1; n = -n; }
    while (n > 0) {
        res[idx++] = digits[n % base];
        n /= base;
    }
    if (neg) printf("-");
    for (int i = idx - 1; i >= 0; i--) printf("%c", res[i]);
    printf("\n");
    return 0;
}
```

### 真题 35：螺旋矩阵

**题目描述**

给定一个 n×n 的螺旋矩阵，按顺时针螺旋填充数字 1 到 n×n，输出第 m 行第 m 列的元素值。

**输入格式**

两个整数 n 和 m（1 ≤ m ≤ n ≤ 100）。

**输出格式**

一个整数，表示螺旋矩阵第 m 行第 m 列的元素值。

**输入样例**

```
4 2
```

**输出样例**

```
11
```

**解题思路**

模拟填充过程或者数学规律推导。n×n螺旋矩阵的中心规律：层数、每层起始值。

**参考代码**

```c
#include <stdio.h>

int main() {
    int n, m;
    scanf("%d %d", &n, &m);
    int layer = m - 1;
    int start = 1;
    for (int i = 1; i <= layer; i++) {
        int len = n - 2 * (i - 1);
        start += (len - 1) * 4;
    }
    printf("%d\n", start);
    return 0;
}
```
