### 🔴 题目1：字符串反转与统计

**题目描述**：
输入一个字符串，首先输出反转后的字符串，然后统计字符串中字母、数字和其他字符的个数。

**输入格式**：
第一行：一个字符串 s（长度不超过1000）

**输出格式**：
第一行：反转后的字符串
第二行：三个整数，分别表示字母、数字、其他字符的个数

**样例输入**：
```
Hello, World! 123
```

**样例输出**：
```
321 !dlroW ,olleH
10 3 5
```

**解题思路**：
- 反转字符串：从后往前遍历或使用双指针法
- 字符统计：遍历字符串，判断每个字符类型

**参考代码（C语言）**：

```c
#include <stdio.h>
#include <string.h>
#include <ctype.h>

int main() {
    char s[1005];
    fgets(s, sizeof(s), stdin);
    int len = strlen(s);
    if (len > 0 && s[len - 1] == '\n') {
        s[len - 1] = '\0';
        len--;
    }

    for (int i = len - 1; i >= 0; i--) {
        printf("%c", s[i]);
    }
    printf("\n");

    int letters = 0, digits = 0, others = 0;
    for (int i = 0; i < len; i++) {
        if (isalpha(s[i])) letters++;
        else if (isdigit(s[i])) digits++;
        else others++;
    }

    printf("%d %d %d\n", letters, digits, others);
    return 0;
}
```

### 🔴 题目2：链表反转

**题目描述**：
定义一个单链表，输入 n 个整数构建链表，然后将链表反转，输出反转后的链表。

**输入格式**：
第一行：一个整数 n（0 ≤ n ≤ 1000）
第二行：n 个整数

**输出格式**：
一行 n 个整数

**样例输入**：
```
5
1 2 3 4 5
```

**样例输出**：
```
5 4 3 2 1
```

**解题思路**：
- 使用三个指针（prev, curr, next）进行原地反转
- 时间复杂度 O(n)，空间复杂度 O(1)

**参考代码（C语言）**：

```c
#include <stdio.h>
#include <stdlib.h>

typedef struct ListNode {
    int val;
    struct ListNode* next;
} ListNode;

ListNode* createNode(int val) {
    ListNode* node = (ListNode*)malloc(sizeof(ListNode));
    node->val = val;
    node->next = NULL;
    return node;
}

ListNode* reverseList(ListNode* head) {
    ListNode* prev = NULL;
    ListNode* curr = head;
    while (curr != NULL) {
        ListNode* nextTemp = curr->next;
        curr->next = prev;
        prev = curr;
        curr = nextTemp;
    }
    return prev;
}

int main() {
    int n;
    scanf("%d", &n);

    ListNode dummy;
    dummy.next = NULL;
    ListNode* tail = &dummy;

    for (int i = 0; i < n; i++) {
        int val;
        scanf("%d", &val);
        tail->next = createNode(val);
        tail = tail->next;
    }

    ListNode* newHead = reverseList(dummy.next);

    ListNode* curr = newHead;
    int first = 1;
    while (curr != NULL) {
        if (!first) printf(" ");
        printf("%d", curr->val);
        first = 0;
        curr = curr->next;
    }
    printf("\n");

    return 0;
}
```

### 🔴 题目3：括号匹配

**题目描述**：
给定一个只包含 `(`, `)`, `{`, `}`, `[`, `]` 的字符串，判断是否有效。

**输入格式**：
第一行：一个字符串 s

**输出格式**：
有效输出 "YES"，否则输出 "NO"

**样例输入1**：
```
()[]{}
```

**样例输出1**：
```
YES
```

**解题思路**：
- 使用栈：遇到左括号入栈，遇到右括号检查栈顶是否匹配

**参考代码（C语言）**：

```c
#include <stdio.h>
#include <string.h>

#define MAX 10005

char stack[MAX];
int top = -1;

void push(char c) { stack[++top] = c; }
char pop() { return stack[top--]; }
char peek() { return stack[top]; }
int isEmpty() { return top == -1; }

int isMatch(char left, char right) {
    if (left == '(' && right == ')') return 1;
    if (left == '{' && right == '}') return 1;
    if (left == '[' && right == ']') return 1;
    return 0;
}

int main() {
    char s[MAX];
    scanf("%s", s);
    int len = strlen(s);

    for (int i = 0; i < len; i++) {
        char c = s[i];
        if (c == '(' || c == '{' || c == '[') {
            push(c);
        } else {
            if (isEmpty()) { printf("NO\n"); return 0; }
            if (isMatch(peek(), c)) pop();
            else { printf("NO\n"); return 0; }
        }
    }

    printf("%s\n", isEmpty() ? "YES" : "NO");
    return 0;
}
```

### 🔴 题目4：约瑟夫环问题

**题目描述**：
n 个人围成一圈，从第一个人开始报数，数到 m 的人出列，求所有人的出列顺序。

**输入格式**：
第一行：两个整数 n 和 m

**输出格式**：
一行 n 个整数

**样例输入**：
```
8 3
```

**样例输出**：
```
3 6 1 5 2 8 4 7
```

**参考代码（C语言）**：

```c
#include <stdio.h>

int main() {
    int n, m;
    scanf("%d %d", &n, &m);

    int people[1005] = {0};
    int result[1005];
    int count = 0, index = 0, step = 0;

    while (count < n) {
        if (people[index] == 0) {
            step++;
            if (step == m) {
                people[index] = 1;
                result[count] = index + 1;
                count++;
                step = 0;
            }
        }
        index = (index + 1) % n;
    }

    for (int i = 0; i < n; i++) {
        if (i > 0) printf(" ");
        printf("%d", result[i]);
    }
    printf("\n");
    return 0;
}
```

### 🔴 题目5：二叉树的层序遍历

**题目描述**：
给定一棵二叉树的前序遍历序列（用 -1 表示空节点），构建二叉树并输出其层序遍历结果。

**输入格式**：
第一行：一个整数 n
第二行：n 个整数

**输出格式**：
一行若干个整数

**样例输入**：
```
13
1 2 4 -1 -1 5 -1 -1 3 -1 6 -1
```

**样例输出**：
```
1 2 3 4 5 6
```

**参考代码（C语言）**：

```c
#include <stdio.h>
#include <stdlib.h>

typedef struct TreeNode {
    int val;
    struct TreeNode* left;
    struct TreeNode* right;
} TreeNode;

int preorder[10005];
int idx = 0;

TreeNode* buildTree() {
    int val = preorder[idx++];
    if (val == -1) return NULL;
    TreeNode* root = (TreeNode*)malloc(sizeof(TreeNode));
    root->val = val;
    root->left = buildTree();
    root->right = buildTree();
    return root;
}

void levelOrder(TreeNode* root) {
    if (root == NULL) return;
    TreeNode* queue[10005];
    int front = 0, rear = 0;
    queue[rear++] = root;
    int first = 1;

    while (front < rear) {
        TreeNode* node = queue[front++];
        if (!first) printf(" ");
        printf("%d", node->val);
        first = 0;
        if (node->left) queue[rear++] = node->left;
        if (node->right) queue[rear++] = node->right;
    }
    printf("\n");
}

int main() {
    int n;
    scanf("%d", &n);
    for (int i = 0; i < n; i++) scanf("%d", &preorder[i]);
    idx = 0;
    TreeNode* root = buildTree();
    levelOrder(root);
    return 0;
}
```

### 🔴 题目6：快速排序实现

**题目描述**：
实现快速排序，输入 n 个整数，输出排序结果。

**输入格式**：
第一行：n
第二行：n 个整数

**输出格式**：
排序后的 n 个整数

**样例输入**：
```
6
5 2 8 1 9 3
```

**样例输出**：
```
1 2 3 5 8 9
```

**参考代码（C语言）**：

```c
#include <stdio.h>

int arr[100005];

void swap(int* a, int* b) {
    int temp = *a; *a = *b; *b = temp;
}

int partition(int low, int high) {
    int pivot = arr[low];
    int i = low, j = high;
    while (i < j) {
        while (i < j && arr[j] >= pivot) j--;
        while (i < j && arr[i] <= pivot) i++;
        if (i < j) swap(&arr[i], &arr[j]);
    }
    swap(&arr[low], &arr[i]);
    return i;
}

void quickSort(int low, int high) {
    if (low < high) {
        int pivotPos = partition(low, high);
        quickSort(low, pivotPos - 1);
        quickSort(pivotPos + 1, high);
    }
}

int main() {
    int n;
    scanf("%d", &n);
    for (int i = 0; i < n; i++) scanf("%d", &arr[i]);
    quickSort(0, n - 1);
    for (int i = 0; i < n; i++) {
        if (i > 0) printf(" ");
        printf("%d", arr[i]);
    }
    printf("\n");
    return 0;
}
```

### 🔴 题目7：二分查找

**题目描述**：
给定有序数组和目标值，使用二分查找找出目标值位置。

**输入格式**：
第一行：n target
第二行：n 个整数（升序）

**输出格式**：
索引（0开始），不存在输出 -1

**样例输入**：
```
6 8
1 3 5 7 8 9
```

**样例输出**：
```
4
```

**参考代码（C语言）**：

```c
#include <stdio.h>

int arr[100005];

int binarySearch(int n, int target) {
    int left = 0, right = n - 1;
    while (left <= right) {
        int mid = left + (right - left) / 2;
        if (arr[mid] == target) return mid;
        else if (arr[mid] < target) left = mid + 1;
        else right = mid - 1;
    }
    return -1;
}

int main() {
    int n, target;
    scanf("%d %d", &n, &target);
    for (int i = 0; i < n; i++) scanf("%d", &arr[i]);
    printf("%d\n", binarySearch(n, target));
    return 0;
}
```

### 🔴 题目8：最长递增子序列（LIS）

**题目描述**：
给定整数数组，求最长递增子序列的长度。

**输入格式**：
第一行：n
第二行：n 个整数

**输出格式**：
最长递增子序列长度

**样例输入**：
```
8

```

**样例输出**：

```
4
```

**参考代码（C语言）**：

```c
#include <stdio.h>

int arr[1005];
int dp[1005];

int max(int a, int b) { return a > b ? a : b; }

int main() {
    int n;
    scanf("%d", &n);
    for (int i = 0; i < n; i++) scanf("%d", &arr[i]);

    for (int i = 0; i < n; i++) dp[i] = 1;

    int maxLen = 1;
    for (int i = 1; i < n; i++) {
        for (int j = 0; j < i; j++) {
            if (arr[j] < arr[i]) {
                dp[i] = max(dp[i], dp[j] + 1);
            }
        }
        maxLen = max(maxLen, dp[i]);
    }

    printf("%d\n", maxLen);
    return 0;
}
```

### 🔴 题目9：0-1背包问题

**题目描述**：
容量为 V 的背包和 n 件物品，每件物品只能选一次，求最大总价值。

**输入格式**：
第一行：n V
接下来 n 行：w[i] v[i]

**输出格式**：
最大总价值

**样例输入**：
```
3 5
2 3
3 4
4 5
```

**样例输出**：
```
7
```

**参考代码（C语言）**：

```c
#include <stdio.h>

int dp[1005];

int max(int a, int b) { return a > b ? a : b; }

int main() {
    int n, V;
    scanf("%d %d", &n, &V);

    int w[1005], v[1005];
    for (int i = 0; i < n; i++) {
        scanf("%d %d", &w[i], &v[i]);
    }

    for (int j = 0; j <= V; j++) dp[j] = 0;

    for (int i = 0; i < n; i++) {
        for (int j = V; j >= w[i]; j--) {
            dp[j] = max(dp[j], dp[j - w[i]] + v[i]);
        }
    }

    printf("%d\n", dp[V]);
    return 0;
}
```

**样例输入**：


**参考代码（C语言）**：

```c
#include <stdio.h>
#include <string.h>

int isPrime[100005];

void sieve(int n) {
    for (int i = 2; i <= n; i++) isPrime[i] = 1;
    for (int i = 2; i * i <= n; i++) {
        if (isPrime[i]) {
            for (int j = i * i; j <= n; j += i) {
                isPrime[j] = 0;
            }
        }
    }
}

int main() {
    int n;
    scanf("%d", &n);
    sieve(n);
    int count = 0;
    for (int i = 2; i <= n; i++) if (isPrime[i]) count++;
    printf("%d\n", count);
```

```c
#include <stdio.h>

long long gcd(long long a, long long b) {

        long long temp = a % b;
        a = b;
        b = temp;

}
```

### 🔴 题目14：图的DFS遍历

**题目描述**：
给定无向图和起点，输出DFS遍历结果（按节点编号从小到大访问）。

**样例输入**：
```
5 5 1
1 2
1 3
2 4
3 4
4 5
```

**样例输出**：
```
1 2 4 3 5
```

**参考代码（C语言）**：

```c
#include <stdio.h>
#include <stdlib.h>

#define MAXN 1005

int graph[MAXN][MAXN];
int edgeCount[MAXN];
int visited[MAXN];
int result[MAXN];
int resultIdx = 0;

int cmp(const void* a, const void* b) {
    return (*(int*)a) - (*(int*)b);
}

void dfs(int u) {
    visited[u] = 1;
    result[resultIdx++] = u;
    qsort(graph[u], edgeCount[u], sizeof(int), cmp);
    for (int i = 0; i < edgeCount[u]; i++) {
        int v = graph[u][i];
        if (!visited[v]) dfs(v);
    }
}

int main() {
    int n, m, start;
    scanf("%d %d %d", &n, &m, &start);
    for (int i = 0; i < m; i++) {
        int u, v;
        scanf("%d %d", &u, &v);
        graph[u][edgeCount[u]++] = v;
        graph[v][edgeCount[v]++] = u;
    }
    dfs(start);
    for (int i = 0; i < resultIdx; i++) {
        if (i > 0) printf(" ");
        printf("%d", result[i]);
    }
    printf("\n");
    return 0;
}
```

**题目描述**：

**样例输入**：

```
5 5 1
1 2
1 3
2 4
3 4
4 5
```

**样例输出**：
```
1 2 3 4 5
```

**参考代码（C语言）**：

```c
#include <stdio.h>
#include <stdlib.h>

#define MAXN 1005

int graph[MAXN][MAXN];
int edgeCount[MAXN];
int visited[MAXN];
int queue[MAXN];
int result[MAXN];
int resultIdx = 0;

int cmp(const void* a, const void* b) {
    return (*(int*)a) - (*(int*)b);
}

void bfs(int start) {
    int front = 0, rear = 0;
    queue[rear++] = start;
    visited[start] = 1;

    while (front < rear) {
        int u = queue[front++];
        result[resultIdx++] = u;
        qsort(graph[u], edgeCount[u], sizeof(int), cmp);
        for (int i = 0; i < edgeCount[u]; i++) {
            int v = graph[u][i];
            if (!visited[v]) {
                visited[v] = 1;
                queue[rear++] = v;
            }
        }
    }
}

int main() {
    int n, m, start;
    scanf("%d %d %d", &n, &m, &start);
    for (int i = 0; i < m; i++) {
        int u, v;
        scanf("%d %d", &u, &v);
        graph[u][edgeCount[u]++] = v;
        graph[v][edgeCount[v]++] = u;
    }
    bfs(start);
    for (int i = 0; i < resultIdx; i++) {
        if (i > 0) printf(" ");
        printf("%d", result[i]);
    }
    printf("\n");
    return 0;
}
```

### 🔴 题目16：最短路径（Dijkstra）

**题目描述**：
给定带权无向图和起点，求到所有节点的最短距离。

**样例输入**：
```
5 6 1
1 2 2
1 3 5
2 3 1
2 4 3
3 4 1
4 5 2
```

**样例输出**：
```
0 2 3 4 6
```

**参考代码（C语言）**：

```c
#include <stdio.h>
#include <string.h>

#define MAXN 1005
#define INF 0x3fffffff

int graph[MAXN][MAXN];
int dist[MAXN];
int visited[MAXN];

void dijkstra(int start, int n) {
    for (int i = 1; i <= n; i++) dist[i] = INF;
    dist[start] = 0;

    for (int i = 0; i < n; i++) {
        int u = -1, minDist = INF;
        for (int j = 1; j <= n; j++) {
            if (!visited[j] && dist[j] < minDist) {
                minDist = dist[j];
                u = j;
            }
        }
        if (u == -1) break;
        visited[u] = 1;

        for (int v = 1; v <= n; v++) {
            if (!visited[v] && graph[u][v] != INF) {
                if (dist[u] + graph[u][v] < dist[v]) {
                    dist[v] = dist[u] + graph[u][v];
                }
            }
        }
    }
}

int main() {
    int n, m, start;
    scanf("%d %d %d", &n, &m, &start);
    for (int i = 1; i <= n; i++)
        for (int j = 1; j <= n; j++)
            graph[i][j] = INF;

    for (int i = 0; i < m; i++) {
        int u, v, w;
        scanf("%d %d %d", &u, &v, &w);
        if (w < graph[u][v]) {
            graph[u][v] = w;
            graph[v][u] = w;
        }
    }

    dijkstra(start, n);
    for (int i = 1; i <= n; i++) {
        if (i > 1) printf(" ");
        printf("%d", dist[i] == INF ? -1 : dist[i]);
    }
    printf("\n");
    return 0;
}
```

### 🔴 题目17：最小生成树（Kruskal）

**题目描述**：
给定带权无向图，求最小生成树总权重。

**样例输入**：
```
4 5
1 2 1
1 3 2
2 3 3
2 4 4
3 4 5
```

**样例输出**：
```
7
```

**参考代码（C语言）**：

```c
#include <stdio.h>
#include <stdlib.h>

#define MAXM 10005

typedef struct { int u, v, w; } Edge;

Edge edges[MAXM];
int parent[MAXM];

int find(int x) {
    if (parent[x] != x) parent[x] = find(parent[x]);
    return parent[x];
}

void unite(int x, int y) {
    int px = find(x), py = find(y);
    if (px != py) parent[px] = py;
}

int cmp(const void* a, const void* b) {
    return ((Edge*)a)->w - ((Edge*)b)->w;
}

int main() {
    int n, m;
    scanf("%d %d", &n, &m);
    for (int i = 0; i < m; i++) {
        scanf("%d %d %d", &edges[i].u, &edges[i].v, &edges[i].w);
    }

    qsort(edges, m, sizeof(Edge), cmp);
    for (int i = 1; i <= n; i++) parent[i] = i;

    long long totalWeight = 0;
    int count = 0;
    for (int i = 0; i < m; i++) {
        if (find(edges[i].u) != find(edges[i].v)) {
            unite(edges[i].u, edges[i].v);
            totalWeight += edges[i].w;
            count++;
            if (count == n - 1) break;
        }
    }
    printf("%lld\n", totalWeight);
    return 0;
}
```

### 🔴 题目19：区间DP - 矩阵连乘

**题目描述**：
给定 n 个矩阵的维度，求最少乘法次数。

**样例输入**：
```
3
10 100 5 50
```

**样例输出**：
```
7500
```

**参考代码（C语言）**：

```c
#include <stdio.h>
#include <string.h>

#define INF 0x3fffffff

int dp[105][105];
int p[105];

int min(int a, int b) { return a < b ? a : b; }

int main() {
    int n;
    scanf("%d", &n);
    for (int i = 0; i <= n; i++) scanf("%d", &p[i]);

    for (int i = 1; i <= n; i++) dp[i][i] = 0;

    for (int len = 2; len <= n; len++) {
        for (int i = 1; i + len - 1 <= n; i++) {
            int j = i + len - 1;
            dp[i][j] = INF;
            for (int k = i; k < j; k++) {
                int cost = dp[i][k] + dp[k+1][j] + p[i-1] * p[k] * p[j];
                dp[i][j] = min(dp[i][j], cost);
            }
        }
    }
    printf("%d\n", dp[1][n]);
    return 0;
}
```

### 🔴 题目20：KMP字符串匹配

**题目描述**：
给定文本串和模式串，找出模式串所有出现位置。

**样例输入**：
```
ABABDABACDABABCABAB
ABABCABAB
```

**样例输出**：
```
1
11
```

**参考代码（C语言）**：

```c
#include <stdio.h>
#include <string.h>

#define MAXN 100005

char text[MAXN], pattern[MAXN];
int nextArr[MAXN];
int positions[MAXN];
int posCount = 0;

void buildNext(int m) {
    nextArr[0] = 0;
    int len = 0, i = 1;
    while (i < m) {
        if (pattern[i] == pattern[len]) {
            len++;
            nextArr[i] = len;
            i++;
        } else {
            if (len != 0) len = nextArr[len - 1];
            else { nextArr[i] = 0; i++; }
        }
    }
}

void kmpSearch(int n, int m) {
    buildNext(m);
    int i = 0, j = 0;
    while (i < n) {
        if (text[i] == pattern[j]) {
            i++; j++;
            if (j == m) {
                positions[posCount++] = i - j + 1;
                j = nextArr[j - 1];
            }
        } else {
            if (j != 0) j = nextArr[j - 1];
            else i++;
        }
    }
}

int main() {
    scanf("%s", text);
    scanf("%s", pattern);
    int n = strlen(text), m = strlen(pattern);
    kmpSearch(n, m);
    printf("%d\n", posCount);
    for (int i = 0; i < posCount; i++) {
        if (i > 0) printf(" ");
        printf("%d", positions[i]);
    }
    printf("\n");
    return 0;
}
```

### 🔴 题目21：搜索回溯 - N皇后问题

**题目描述**：
在 n×n 的棋盘上放置 n 个皇后，使其不能互相攻击（任意两个皇后不能在同一行、同一列或同一斜线上），求所有解的个数。

**样例输入**：
```
4
```

**样例输出**：
```
2
```

**解题思路**：
- 使用回溯搜索，逐行放置皇后
- 维护列、两条对角线的占用状态
- 时间复杂度 O(n!)

**参考代码（C语言）**：

```c
#include <stdio.h>

#define MAXN 20

int col[MAXN];      // col[i]表示第i行皇后所在的列
int usedCol[MAXN];  // 标记某列是否已被占用
int diag1[2*MAXN];  // 标记正对角线（row-col为定值）
int diag2[2*MAXN];  // 标记反对角线（row+col为定值）
int n;
int count = 0;

// 第row行放置皇后
void backtrack(int row) {
    if (row == n) {
        count++;
        return;
    }

    for (int c = 0; c < n; c++) {
        // 检查该列和两条对角线是否可以放置
        if (!usedCol[c] && !diag1[row - c + n] && !diag2[row + c]) {
            col[row] = c;
            usedCol[c] = 1;
            diag1[row - c + n] = 1;
            diag2[row + c] = 1;

            backtrack(row + 1);

            // 回溯
            usedCol[c] = 0;
            diag1[row - c + n] = 0;
            diag2[row + c] = 0;
        }
    }
}

int main() {
    scanf("%d", &n);
    backtrack(0);
    printf("%d\n", count);
    return 0;
}
```

### 🔴 题目22：贪心算法 - 活动安排问题

**题目描述**：
有 n 个活动，每个活动有开始时间和结束时间。选择尽可能多的互不重叠的活动，求最多能安排多少个活动。

**输入格式**：
第一行：n
接下来 n 行：每行两个整数 start, end

**输出格式**：
一个整数，表示最多能安排的活动数

**样例输入**：
```
6
1 3
2 5
4 7
1 8
5 9
8 10
```

**样例输出**：
```
3
```

**解题思路**：
- 按结束时间排序，每次选择最早结束的活动
- 贪心选择性质：最优解一定包含最早结束的活动

**参考代码（C语言）**：

```c
#include <stdio.h>
#include <stdlib.h>

#define MAXN 10005

typedef struct {
    int start;
    int end;
} Activity;

Activity activities[MAXN];

int cmp(const void* a, const void* b) {
    return ((Activity*)a)->end - ((Activity*)b)->end;
}

int main() {
    int n;
    scanf("%d", &n);
    for (int i = 0; i < n; i++) {
        scanf("%d %d", &activities[i].start, &activities[i].end);
    }

    // 按结束时间排序
    qsort(activities, n, sizeof(Activity), cmp);

    int count = 1;  // 第一个活动必选
    int lastEnd = activities[0].end;

    for (int i = 1; i < n; i++) {
        if (activities[i].start >= lastEnd) {
            count++;
            lastEnd = activities[i].end;
        }
    }

    printf("%d\n", count);
    return 0;
}
```
