## 题目格式说明

每道题目包含以下要素：

- **题干** — 完整的题目描述
- **选项** — 选择题提供 A/B/C/D 选项
- **标准答案** — 标注为 `【答案】`
- **答案解析** — 标注为 `【解析】`，包含详细的解题思路、步骤
- **出处** — 标注为 `【出处】`，如「2023年考研数学一第5题」、「王道模拟卷」等

题型示例：

```
题目：设函数 f(x) 在 x=0 处连续，且 lim(x→0) f(x)/x = 1，则

A. f(0)=0
B. f'(0) 存在且等于 1
C. f(0)=1
D. f'(0) 不存在

【答案】B
【解析】由 f(x) 在 x=0 处连续...
【出处】2022年考研数学一第3题（真题改编）
```

## 推荐复习计划

### 第一轮（基础阶段，3-6 个月）

| 科目 | 每日建议 | 目标 |
|------|---------|------|
| 数学一 | 3-4 小时 | 通读教材，配合练习 |
| 英语一 | 1.5-2 小时 | 词汇积累 + 长难句 |
| 408 | 2-3 小时 | 四门专业课一轮过 |
| 政治 | 0.5-1 小时 | 马原基础 + 史纲要 |

### 第二轮（强化阶段，2-3 个月）

- 真题精练为主，配合专项突破高频考点
- 英语开始真题练习
- 408 开始算法题强化
- 政治开始选择题专项训练

### 第三轮（冲刺阶段，1-2 个月）

- 严格按照考试时间完成整套模拟题
- 政治背诵分析题模板
- 英语作文模板训练
- 数学查漏补缺

## 使用建议

1. **题目不是用来"刷"的，而是用来"练"的——每一道错题都是通往高分的阶梯。
2. **建议按知识点做题，而不是按题号顺序做题。
3. **每做完一套题，花同等时间复盘：对的题要知道为什么对，错的题要知道错在哪里。
4. **真题至少练习 2-3 遍，第一遍按章节练习，第二遍按整套模拟，第三遍查漏补缺。
